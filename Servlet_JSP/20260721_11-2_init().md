## 初回リクエスト時

- `init`メソッドはインスタンス作成後に一度だけ呼ばれるメソッド
- インスタンス変数の初期化などに利用

## init()メソッドをオーバーライドするときの注意点

- 引数無しと引数有りのメソッドがある
  - **引数有りの場合**
    ```java
    public void init(ServletConfig config)
    ```
    事前に指定された初期化パラメーターが含まれる。

    > [!IMPORTANT]
    > 引数有のメソッドをオーバーライドする＝初期化に必要なデータを受け取る場合、必ず`super.init(config)`を呼び出す必要がある。

## 初期化パラメーター（web.xml）

対象となるサーブレットを定義する`<servlet>`要素内で`<init-param>`要素を使用して定義する。

### 例

**web.xml**
```xml
<init-param>
    <param-name>greeting</param-name>
    <param-value>こんにちは</param-value>
</init-param>
```

**HelloServlet.java**
```java
public class HelloServlet extends HttpServlet {

    private String greeting;

    @Override
    public void init(ServletConfig config) throws ServletException {
        super.init(config); // 必ず呼び出す

        // web.xmlで指定した初期化パラメーターを取得
        greeting = config.getInitParameter("greeting");
    }

    @Override
    protected void doGet(HttpServletRequest req, HttpServletResponse resp)
            throws ServletException, IOException {
        resp.setContentType("text/html;charset=UTF-8");
        resp.getWriter().println(greeting + "、World！");
    }
}
```

> [!NOTE]
> `init()`は最初のリクエスト時（または`loadOnStartup`指定時）に**1回だけ**実行される。取得した`greeting`はインスタンス変数に保持され、以降の全リクエストで使い回される。


## アノテーション vs web.xml
- 初期化パラメーターを伴う場合、web.xmlを利用することを推奨する。
- 初期化パラメーターは、必ずしもプログラマが編集するとは限らない。
  - アプリを配置、利用するだけの人が編集する可能性もある。
- web.xmlであれば、javaのソースコードを編集する作業に比べれば難易度は低い、かつ、コンパイルも不要である。  
  ※アノテーションはweb.xmlよりも新しい仕組みであるため、優先して利用するべきである、と思うかもしれないが、適材適所に応じて、両者を使い分けるように心がけることをお奨めする。
