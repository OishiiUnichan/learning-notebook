	６－１	MVCモデル

	MVCモデルにおける開発の３つの要素

	・モデル		：	アプリケーションの主たる計算や処理に関わるデータの格納
	・ビュー		：	ユーザーに対しての画面表示
	・コントローラ	：	ユーザーからの要求受け取り、処理の依頼をモデルに依頼し、結果をビューに依頼する。


	┌---------	┐　→リクエスト→	┌ [ Controller(コントローラー) ] ┐	→---	[検索]---→		┌ [ Model（モデル） ] ----	┐ 
	│ブラウザ	│				│	●要求の受け取り		│				　　	│		● 計算処理	│
	└---------	┘				│	● モデルに依頼			│	←---	[結果]---←		│	● データの格納		│
		↑					│	● ビューに依頼			│					└---	[ Javaのクラス ]------	┘	
	[ リクエストの結果 ]			│						│
		↑					└----- [ サーブレットクラス ]----	┘　	→---	[結果]---→		┌---	[ View（ビュー） ]---	┐ 
		↑																│	●画面の表示		│
