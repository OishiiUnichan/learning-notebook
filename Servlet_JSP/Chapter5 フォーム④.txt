	[ P.158 ]
	[ 正規表現 ]	文字列の集合（パターン）を表す汎用的な記法
				→ 「メタ文字」と呼ばれる記号を組み合わせて文字列のパターンを作成する。

		メタ文字	│	文字列			│	例
		-----------	┼---------------------------	┼---------------------------------------------	┤
		  ^		│	行頭				│	^a	：	a で始まる文字列			
		  $		│	行末				│	n$	：	n で終わる文字列			
		[...]		│	論理和			│	[abc]	：	a.b.cのいずれか１文字		
		  +		│	直前の文字が１つ以上	│	c+	：	cが１つ以上連なる文字列	
		{   }		│	繰り返し回数		│	{4}	：	直前の文字を４回繰り返す	
		-----------	┴---------------------------	┴---------------------------------------------	┘
		[ 作成例 ]	[ P.158 ]	正規表現
				パターン：	^[0-9a-zA-Z]{4}$	←	半角英数字4文字

	[ 課題② ]
	　登録情報入力画面において、名前をローマ字入力に制限するように改修する。
	[ ヒント ]	正規表現を指定する属性は、pattern属性である。
	[ 使用例 ]	<input type="text" name="name" pattern="^[a-zA-Z]+$" />
