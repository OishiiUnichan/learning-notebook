## 2-1. Webページの公開

［例］

```text
プロトコル://サーバ名/ディレクトリ名/ファイル名
```

## 2-2.Webを支える通信の仕組み

- ブラウザとWebサーバ間の通信におけるデータのやり取りは、<ins>**HTTP**</ins>という**プロトコル**（通信規約）で決められている。

> [!NOTE]  
> HTTP = Hyper Text Transfer Protocol  
> （詳細）RFC7230~7235

```text
リクエスト：GET /index.html HTTP/1.1
レスポンス：HTTP/1.1 200 OK
~~
Content-Type: text/html; charset = UTF-8
<HTML>
~~
</HTML>
```

- Content-Typeヘッダにより、ボディ部に含まれるデータの種類を知ることができる  
  ［書式］

```text
カテゴリ/種類; 引数=値
```

1. HTMLをレスポンスする場合
   ```text
   Content-Type: text/html; charset = UTF-8
                               <--HTMLの文字コード-->
   ```
2. JPEGをレスポンスする場合
   ```text
   Content-Type: image/jpeg;
   ```

---

### ★リクエストの中身

リクエスト行→ヘッダ部→ボディ部　の流れで構成されている。

```text
<-----リクエストライン----->
GET /index.html HTTP/1.1
1　　　　　2　　　　3
```

1. リクエストの方法
2. リクエストの対象
3. 使用するプロトコル

| リクエスト    | 処理内容                                                                 |
| ------------- | ------------------------------------------------------------------------ |
| GET メソッド  | データ取得<br>（→　Webページの表示）                                     |
| POST メソッド | データの作成<br>（→　掲示板への書き込み）<br>（→　アカウントの新規作成） |

---

### ★レスポンスの中身

ステータス行→ヘッダ部→ボディ部　の流れで構成されている

```text
<--ステータスライン-->
  HTTP/1.1 200 OK
　　　1　　　　2
```

1. 使用するプロトコル
2. 動作結果　ステータスコード　メッセージ

| コード  | メッセージ                                     |
| ------- | ---------------------------------------------- |
| 200     | OK（正常）                                     |
| **404** | Not Found（該当URLなし）                       |
| 405     | Method Not Allowed（許可されていないメソッド） |
| **500** | Internal Server Error（サーバー内部エラー）    |
