# Chapter4　JSPの基本

## 4-1　JSPの基本

### JSPファイルとは？

| 時期 | 名称 | 開発元 |
|---|---|---|
| 以前 | Java Server Pages | Oracle社 |
| 現在（2017年〜） | Jakarta Server Pages | Eclipse社 |

- HTMLタグに似た「JSPタグ」を利用し、HTMLを記述するように作成する。
- ページの中で、**静的なコンテンツ**の部分は「HTML」で記述し、**動的なコンテンツ**の部分を「JSP」で記述する。
- JSPの作成は、静的コンテンツの「HTML」の作成手順と同じである。
- つまり、静的コンテンツを作成するがごとく、動的コンテンツを作成できる。

### JSPファイルはサーブレットクラスに変換される

**② 変換の流れ**

**JSPファイルの変換・実行の流れ**

1. **①JSPの起動（リクエスト）**
   ブラウザがJSPファイルに対してリクエストを送る。

2. **②変換・コンパイル（アプリケーションサーバ内部の処理）**
   1. JSPコンパイラが `JSPファイル` を `Servletクラス（ソースファイル）` に変換する
   2. Javaコンパイラが `Servletクラス（ソースファイル）` を `Servletクラス（クラスファイル）` にコンパイルする
   3. `Servletクラス（クラスファイル）` から `Servletインスタンス` が生成される

3. **③JSPの出力（レスポンス）**
   生成された `Servletインスタンス` が処理を実行し、その結果（HTML）がブラウザにレスポンスとして返される。

> ポイント：JSPは一度Servletに変換されてから実行される。つまり「JSP＝裏側では最終的にServlet」ということ。

### 基本的なJSPファイルの構成要素

| 構文 | 名称 | 説明 |
|---|---|---|
| `<%@ page … %>` | pageディレクティブ | ページの設定を行う |
| `<% Javaのコード %>` | スクリプトレット | Javaのコードを埋め込む |
| `<%-- … --%>` | JSPコメント | JSPファイルにコメントを入れる |
| `<!DOCTYPE html> <html><head></head><body>` | テンプレート | HTMLの記述 |
| `<%= … %>` | スクリプト式 | 変数や、メソッドの戻り値などを出力 |
| `</body></html>` | テンプレート | HTMLの記述 |

> **[比較／P.116 コラム]**　HTMLコメント：`<!-- -->`

## 4-2　JSPの構成要素

### JSPの基本構成要素

- **スクリプト要素**：JSPにJavaのソースコードを記述するために利用
  - ☑ **スクリプト宣言**：`<%! 変数宣言、メソッド宣言 %>`
    - ページ内のJavaコードで使用する変数やメソッドを宣言するために利用
  - ☑ **スクリプトレット**：`<% Javaのコード; %>`
    - Javaのプログラムコード（スクリプトレット）を記述するために利用

| 要素 | 構文 | 用途 | ライフサイクル |
|---|---|---|---|
| スクリプト宣言 | `<%! … %>` | クラス変数、メソッド | ページ全体（永続的） |
| スクリプトレット | `<% … %>` | ローカル変数、ロジック処理 | 各リクエスト（一時的） |

> ※宣言とレットを都度行わないための方法として「式」がある。

- ☑ **スクリプト式**：`<%= 式 %>`
  - スクリプト式をJSPに埋め込むために使用
  - 式は「String」に変換され、ブラウザに送信される
  - **［注意］** 式の末尾にセミコロンは不要！

イメージとしては：
- `<% %>` ：でJavaと同じように書き込む
- `<%= %>` ：で対応した式を使用する

---

### 主なpageディレクティブの属性

**HTMLを出力するJSPファイルの設定**

```
<%@ page contentType = "text/html;charset=文字コード" %>
```
- `contentType`：レスポンスのContent-Typeヘッダ

**JSPファイルでのインポート**

```
<%@ page import = "パッケージ名.クラス名" %>
```
- `import`：インポートするクラス または インターフェイス（完全限定クラス名）
