## JSTLとは

**JSTL（JSP Standard Tag Library）** は、JSPで頻繁に使われる汎用的な処理を標準化した **カスタムタグ** のライブラリ。

> 💡 **カスタムタグとは**
> 開発者が独自に作成できるアクションタグのこと。JSTLは、その中でも「よく使う機能」をあらかじめ標準仕様として定義し、誰でも共通して使えるようにしたもの。
> 現在は Jakarta EE に移管され、パッケージ名も `javax.servlet.jsp.jstl` から `jakarta.servlet.jsp.jstl` に変わっている（Jakarta化）。

### JSTLの目的

JSPで頻繁に利用されるような汎用的な機能について標準仕様を定めることで、開発者が同じような処理を個別にカスタムタグとして自作しなくても済むようにすること。

> 💡 補足
> JSTLがない場合、条件分岐やループ処理をJSP内に `<% %>` のスクリプトレット（Javaコードの直書き）で書く必要があり、HTMLとJavaコードが混在して可読性・保守性が下がる。JSTLを使うことで、ロジックをタグとして記述でき、デザイン（HTML）とロジックの分離がしやすくなる。

## JSTLの構成

JSTLは以下の **5つのタグライブラリ** で構成される。

| タグライブラリ | 主な用途 |
| --- | --- |
| Core | 変数操作・条件分岐・繰り返しなど基本処理 |
| I18N (fmt) | 国際化・書式設定（日付や数値のフォーマットなど） |
| Database (sql) | SQLの実行など、データベース操作 |
| XML | XML文書の操作 |
| Functions | 文字列操作などの関数 |

### taglibディレクティブによるライブラリ指定

JSPでJSTLを使うには、ページ冒頭で `taglib` ディレクティブを宣言する必要がある。指定方法は主に2種類。

- **URL形式**：URIを指定して宣言する方法
- **FQCN形式**：完全修飾クラス名（Fully Qualified Class Name）で指定する方法

> 💡 補足
> 実務では基本的に **URL形式** が使われる。例えばCoreタグライブラリなら以下のように宣言する。
> ```jsp
> <%@ taglib prefix="c" uri="jakarta.tags.core" %>
> ```
> `prefix` で指定した文字（例：`c`）が、タグを呼び出す際の接頭辞になる（例：`<c:if>`）。

### 主なタグライブラリの接頭辞（prefix）

| タグライブラリ | 接頭辞 |
| --- | --- |
| core | c |
| fmt | fmt |
| sql | sql |
| xml | x |
| functions | fn |

## Coreタグライブラリ

JSTLの **Core** タグライブラリを使うと、変数の操作や分岐・繰り返しといった基本的なJavaの処理をタグとして記述できる。

| タグ | 概要 |
| --- | --- |
| `c:set` / `c:remove` / `c:out` | 変数の設定・削除・出力 |
| `c:if` | if文（単一の条件分岐） |
| `c:choose` / `c:when` / `c:otherwise` | if-else文、if-elseif-else文（複数の条件分岐） |
| `c:forEach` | ループ（繰り返し処理） |

> 💡 補足
> - `c:if` には `else` に相当するタグが無いため、複数条件を扱いたい場合は `c:choose` / `c:when` / `c:otherwise` の組み合わせを使う。
> - `c:forEach` は配列やList、Mapなどのコレクションを繰り返し処理する際によく使われ、JSPでDBの検索結果一覧を表示する場面などで頻出する。

### Coreタグライブラリ［変数操作］

#### `c:set`（変数を設定）

```jsp
<c:set var="userName" value="太郎" scope="page" />
```

- `scope` 属性は、変数をどの範囲（暗黙オブジェクト）に保存するかを指定する。
- `scope` の規定値（デフォルト）は **`page`**。

#### `c:remove`（変数を削除）

```jsp
<c:remove var="userName" scope="page" />
```

- こちらも `scope` の規定値は **`page`**。

> 💡 補足
> `scope` に指定できる値は `page` / `request` / `session` / `application` の4種類で、Servletの `pageContext` / `request` / `session` / `application` の各暗黙オブジェクトに対応している。値を省略した場合は最も狭い範囲である `page` スコープが使われる。

#### `c:out`（変数を出力）

```jsp
<c:out value="${userName}" default="ゲスト" />
```

- `value` に指定した値が `null` の場合、代わりに `default` 属性で指定した値が出力される。
- つまり `default` は、**`value` が `null` の場合の出力値** を指定する属性。

> 💡 補足
> `c:out` は `${ }`（EL式）をそのまま `<%= %>` で出力する場合と違い、デフォルトでHTMLエスケープ（`escapeXml`）が有効になっている。そのため、ユーザー入力値などをそのまま画面に出す際にXSS（クロスサイトスクリプティング）対策として使われることが多い。

### Coreタグライブラリ［分岐］

#### `c:if`（単一の条件分岐）

```jsp
<c:if test="${score >= 60}">
    <p>合格です。</p>
</c:if>
```

- `test` 属性にEL式で条件を書き、条件が `true` のときだけタグ内の内容が出力される。

#### `c:choose`（複数の条件分岐）

```jsp
<c:choose>
    <c:when test="${score >= 80}">
        <p>優</p>
    </c:when>
    <c:when test="${score >= 60}">
        <p>可</p>
    </c:when>
    <c:otherwise>
        <p>不可</p>
    </c:otherwise>
</c:choose>
```

- 複数条件を扱う場合は `c:choose` の中に `c:when` を複数並べ、どれにも当てはまらない場合の処理を `c:otherwise` に書く。
- `c:otherwise` は必ず使うこと（Javaの `if-elseif-else` の `else` に相当する部分のため、書き漏らさないようにする）。

> ※ `c:choose` / `c:when` / `c:otherwise` タグを入れ子にして使用する。

> 💡 補足
> `c:choose` はJavaの `switch` 文や `if-elseif-else` に近いイメージ。`c:when` は複数書けるが、`c:otherwise` は1つの `c:choose` につき最大1つしか書けない。

### Coreタグライブラリ［繰り返し］

#### `c:forEach`（繰り返し）

`c:forEach` の使い方は大きく分けて2パターンある。

**① 回数指定による繰り返し**

```jsp
<c:forEach var="i" begin="1" end="5">
    <p>${i} 回目の出力です。</p>
</c:forEach>
```

- `begin` から `end` まで、`var` に指定した変数に値を入れながら繰り返す（Javaの `for` 文に近い）。
- 必要に応じて `step` 属性で増分（何個飛ばしで回すか）も指定できる。

**② データ構造の要素を参照しながらの繰り返し**

```jsp
<c:forEach var="user" items="${userList}">
    <p>${user.name} さん</p>
</c:forEach>
```

- `items` に配列やList、Mapなどのコレクションを指定すると、その要素を1つずつ `var` に入れながら繰り返す（Javaの拡張for文 `for (User user : userList)` に近い）。
- `List<User>` のようなオブジェクトのListを渡した場合、`${user.name}` のようにEL式でプロパティ（getterメソッド）にアクセスできる。

> 💡 補足
> `begin` / `end` を使う「回数指定」は固定回数のループ（例：ページネーションの番号表示など）に向いており、`items` を使う「要素参照」はDBから取得した検索結果一覧（`List`や`ResultSet`をつめたコレクションなど）をテーブル表示する場面でよく使う。
> また `varStatus` 属性を使うと、現在のループ回数（`count`）や添字（`index`）、最初/最後の要素かどうか（`first` / `last`）なども取得でき、交互に背景色を変える（縞模様の表）といった実装にも応用できる。
