## Webアプリケーション終了時

- `destroy`メソッドはサーブレットが破棄される前に呼び出される
- インスタンス変数の値をファイルに書き出す
- インスタンスで共有していたDB接続の切断処理を行う

## メモ

`init`メソッド・`destroy`メソッドは`HttpServlet`クラスの親クラスである`GenericServlet`クラスに定義されている。

## サーブレットのライフサイクルとメソッド

| 初期化時 | リクエスト時 | 終了時 |
|---|---|---|
| `init()` | `doGet()` / `doPost()` | `destroy()` |

---

## サンプル

```java
@Override
public void destroy() {
    // 後始末処理（ファイルへの書き出し・DB切断など）
    if (logWriter != null) {
        logWriter.close();
    }
}
```

> [!NOTE]
> `destroy()`は`init()`と同じく**1回だけ**呼び出される。サーバー停止やアプリケーションの再デプロイ時に実行され、リソースの後始末（ファイルクローズ・DB切断など）を行うタイミングとして使う。
