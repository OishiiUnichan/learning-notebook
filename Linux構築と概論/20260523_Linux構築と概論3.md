# Gitをつかうメリットについて

1. バージョンが煩雑になる
    
    →自動でver管理、最新版も分かる
    
2. 作業ファイルのやり取りが面倒
    
    →コマンド1つで出来る
    
3. 上書き保存の危険性が高い
    
    →上書き保存防止&分担した修正箇所のマージ
    

# Gitの仕組み①

1. 自分と共有の作業場所がそれぞれ存在する
    
    自分の作業場所は基本的に上書きされることもないし、他人の環境も上書きできない
    
2. 自分と共有の作業場所のファイルのやり取りは「Git」を使っておこなう
    
    基本的に共有環境を通す
    
3. 作業内容をスナップショットのように場所ごと全て保存する
    
    「いつ」「どこのファイルの」「どこを」「どのように変更したか」という状況ごと、すべて保存する
    

# 集中型vs分散型

従来のver管理：リモートとローカルのみ

Gitのバージョン管理：Git上にリモートでおいてローカルでも管理できる
