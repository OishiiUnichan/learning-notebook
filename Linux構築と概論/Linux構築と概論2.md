## Linuxコマンド
コマンドの基本形は　コマンド　オプション　引数

### 疎通確認
```bash
ping IP or URL
```

### 一般権限のユーザ作成（管理者アカウントのみ）
```bash
useradd ユーザ名
passwd 7文字以上
```

### グループの作成（管理者アカウントのみ）
```bash
groupadd　［グループ名］
```
- 作成済みのユーザの情報を変更
    ```bash
    usermod -G ［グループ名］［ユーザ名］
    usermod -aG　で複数グループに所属
    ```
- ユーザがグループに所属しているかの確認
    ```bash
    groups ［確認したいユーザ名］
    ```

---

### システムを終了：**rootでしか実行できない**
```bash
shutdown ［オプション］［時間］
```
［オプション］ -r（再起動）、-h（停止）  
［時間］now（ただちに）、+10（10分後）   

---

### ディレクトリ移動
```bash
cd ［移動先ディレクトリ名］
```
/ ルートディレクトリ  
~ ホームディレクトリ  
. カレントディレクトリ  
.. 1つ上のディレクトリ  

### 現在地の確認
```bash
pwd（Print Working Directory）
```

### ディレクトリの操作
作成
```bash
mkdir　［フォルダ名］
```
削除
```bash
rmdir　［フォルダ名］
```
オプション  
-i　消す前の確認  
-r　完全無言消去（空である必要性が無い）  

### ファイルの操作
移動
```bash
mv　［ファイル名］　［フォルダ名］
```
コピー
```bash
cp　［ファイル名］　［新しいファイル名］
```
同じフォルダに違う名前でコピー
```bash
cp ［ファイル名］［フォルダ名/ファイル名］
```
削除
```bash
rm　［ファイル名］
```
---

### テキストエディタ
```bash
vi ［ファイル名］※存在しなければ新規作成
```
viエディタ上で  
```bash
i　編集

:w　上書き保存

escキー　抜ける

:q　vi終了

:q!　上書きせずに終了
```
マニュアルでオプションの確認
```bash
man　［コマンド名］
```
オプションは1文字で指定したいときは「-が1つ」、単語で指定するときは「—が2つ」

ヘルプコマンドについて
```bash
—help　はコマンドのオプション一部のみ表示される
```
---

### パーミッションについて

ファイル・ディレクトリの一覧表示

```bash
ls ［オプション］ ［ファイル名　または　ディレクトリ名］
```
-a　すべてのファイル・ディレクトリの表示  
-l　ファイルの詳細の表示  
-S　ファイルサイズの大きい順に並び変え  

### ファイルのパーミッションについて
```bash
d rwx rwx r-x. 2 test01 test01   6  5月 23 14:12 sample

d = ディレクトリ
rwx = 所有者の権限
rwx = 所有グループ
r-x = その他

r = read （読み込み）
w = write （書き込み）
x = eXecute　（その他）
```

### ディレクトリの所有者にグループを設定する
```bash
chgrp グループ名 ファイル名orディレクトリ名
```
### ディレクトリのパーミッションを設定する
```bash
chmod アクセス権 ファイル名orディレクトリ名
```
+…権限の追加、-…権限の削除  
r…読み取り許可、w…書き込み許可、x…実行許可
