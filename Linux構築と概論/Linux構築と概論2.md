Linuxコマンド

コマンドの基本形は　コマンド　オプション　引数

疎通確認

ping IP or URL

一般権限のユーザ作成（管理者アカウントのみ）

useradd ユーザ名

passwd 7文字以上

グループの作成（管理者アカウントのみ）

groupadd　［グループ名］

- 作成済みのユーザの情報を変更
    
    usermod -G ［グループ名］［ユーザ名］
    
    usermod -aG　で複数グループに所属
    
- ユーザがグループに所属しているかの確認
    
    groups ［確認したいユーザ名］

システムを終了：**rootでしか実行できない**

shutdown ［オプション］［時間］

［オプション］ -r（再起動）、-h（停止）

［時間］now（ただちに）、+10（10分後）

ディレクトリ移動

cd ［移動先ディレクトリ名］

/ ルートディレクトリ

~ ホームディレクトリ

. カレントディレクトリ

.. 1つ上のディレクトリ

現在地の確認

pwd（Print Working Directory）

ディレクトリの操作

作成

mkdir　［フォルダ名］

削除

rmdir　［フォルダ名］

オプション

-i　消す前の確認

-r　完全無言消去（空である必要性が無い）

ファイルの操作

移動

mv　［ファイル名］　［フォルダ名］

コピー

cp　［ファイル名］　［新しいファイル名］

同じフォルダに違う名前でコピー

cp ［ファイル名］［フォルダ名/ファイル名］

削除

rm　［ファイル名］

vi ［ファイル名］※存在しなければ新規作成

viエディタ上で

### パーミッションについて

ファイル・ディレクトリの一覧表示

ls ［オプション］ ［ファイル名　または　ディレクトリ名］

-a　すべてのファイル・ディレクトリの表示

-l　ファイルの詳細の表示

-S　ファイルサイズの大きい順に並び変え

ファイルのパーミッションについて

```bash
d rwx rwx r-x. 2 test01 test01   6  5月 23 14:12 sample

d = ディレクトリ
rwx = 所有者の権限
rwx = 所有グループ
r-x = その他

r = read （読み込み）
w = write （書き込み）
x = eXecute　（その他）
```

### ディレクトリの所有者にグループを設定する

chgrp グループ名 ファイル名orディレクトリ名

### ディレクトリのパーミッションを設定する

chmod アクセス権 ファイル名orディレクトリ名

+…権限の追加、-…権限の削除

r…読み取り許可、w…書き込み許可、x…実行許可
