★ 変数とは？
☆ Pythonで変数を使うには？

補足１　変数のデータ型について
Java
データ型は最初に固定して決める形式を採用している　←静的型付
→変数の型を事前に決めてから、値を格納する。

Python
データ型はプログラムが実行するときに決まる。　←動的型付
変数が値に格納されると、変数の方が決まる。

補足２　定数について
Pythonには、定数を定義するためのキーワードは用意されていないため、基本的にはすべて変数である。
定数の定義は、慣例的なルール（定数名：大文字の英字）によってのみ成り立っている。
→　標準的な命名規則：PEP8に記載

※上記のルールを守らなくてもプログラムが動かないということはないが、
変数と定数を識別しやすくするための暗黙の了承としての採用を推奨。

    SyntaxError: invalid decimal literal
2. アンダースコアから始まる名前　←使用を控える
    特殊な用途で利用されることが決まっている

★ print()関数で数値に説明を加える　←　出力地の意味も分かりやすくしよう
［スクリプト］kakugen.py
［補足］文字列の出力について
    - JSと同様に、文法上、一重引用符、二重引用符に違いはない
    - ［注意］Javaには違いがある　→　一重引用符：文字、二重引用符：文字列
  
print()関数の使い方
［書式］
`print(値1,値2,値3)`　→　引数の値が連続（連結）して出力される
※値：数値、文字列、変数を指定可能（データ型の混在：許容）

［スクリプト］nenrei.py
メモ1.変数が数値でも、文字列でも、連結間に空白が入る？
`print(値1,値2,値3,sep="")`　← sep:区切り文字の指定
※空文字指定（規定：「空白」文字）

メモ2.必ず改行される
`print(値1,値2,値3,end="")`　← end:文末出力文字の指定
※空文字指定（規定：「改行」文字）
［スクリプト］print-end.py
