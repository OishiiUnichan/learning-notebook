	１－１	プログラミングやPythonについて

		[ p.002 ] ★ プログラミングとは？
		  python	：スクリプト言語（その他：php、JavaScript など）
				『スクリプト言語』 ⊆ インタプリタ言語 ↔ コンパイラ言語：Java
				【 特徴 】
				・ 比較的容易に記述や実行できる言語の総称。厳密な定義はない。
				　→ 記述や実行の際に必要な情報の一部を省略する仕様になっている。
				　　[ 例 ] データ型の宣言無しで変数を使用できる、など。
				　→ 開発者自身が省略された情報を把握しておく必要がある。
				・ 比較的小規模開発向け。大人数での開発には不向き。↔ Javaとの違い

		[ p.003 ] 私たちの側が的確な指示を出さないことには、思い通りに動いてくれない。
				→ プログラムは思った通りには動かない。書いた通りに動く。


		[ p.003 ] ★ プログラミングを学ぶとどんな良いことがあるのか？
		● プログラミングによって仕事を自動化できる。
		　[ Excel VBA ]　マクロ言語：Visual Basic for Application( VBA )
						↓
		[ 2017年12月 ]　Excelにpython搭載、マイクロソフトが検討
				https://www.publickey1.jp/blog/17/excelpython.html
		[ 2023年 8月 ]	プレビュー版の公開
		[ 2023年 9月 ]	正式提供（一般提供）

		[ メモ ]　python in Excel	VS	マクロ
		　python in Excel ）	Excelのセルや関数内でPythonを実行できる機能
						主な用途：データの分析
						→ Excelの数式バーで直接コードを記述、実行できる。
			[ 制限事項 ]	PythonはMicrosoftクラウドで実行されるため、インターネット接続が必要になる。
						→ ローカル環境でのPython実行はできない
						→ Microsoft 365の Business or Enterpriseプラン

			Excelマクロ	）主な目的：Excelの操作の自動化
						　→ 専用の開発ツール「VBE」でコーディングする
										　└ Visual Basic Editor


		● 論理的思考力（ロジカルシンキング）を培うことができる。
			→ 2020年度から始まった小学校におけるプログラミング学習の必修化
			　（ プログラミング言語の習得が目的ではない！ ）


		● 問題解決のためのスキルを向上させることができる。
			→ プログラミングで最も難しい点は、アルゴリズムをどうするかを決めること。
			　 そして、それをできるだけ単純化すること（ Bill Gates ）


		[ p.004 ] ★ プログラミング言語「Python」とは？
			　　※ Google社が主に開発に利用している3大言語：Java、C++、Python

		Python ）
		・ 開発 時期			： 1991年（ Java:1995年 ）
		・ バージョン			： 3.x系（2.x系：サポート終了 [2020-01-01] ）
		・ 特　徴				： 文法がシンプルで読みやすい、書きやすい。
							　 → 「インデント」が重要な役割を担う！
						　	　 → Pythonで扱うデータは、すべて「オブジェクト」の構造になっている！
		・ 他の言語と一番違う点	： 人工知能を作りやすい言語
							　 以前から人工知能の研究で利用されている。
							　 機械学習やディープラーニング（深層学習）専用のライブラリが
							　 用意されている、なぢ人工知能を作りやすい環境が整っている。
