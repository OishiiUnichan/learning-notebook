［p.071］ ☆ 何もしない「pass」文
- pass文はJavaでの空文（；）に相当する。
  - 何も実行しない文で文法的には処理文が必要だが、何もやることはない時などに使う。
  - ［参考］スッキリわかるJava入門　p.641 code17-8

- ブロックの存在材料
- Python）インデント
- Java）｛｝：中括弧、波括弧
※「if:」ブロックでも「else:」ブロックでも空（何も記述しない）状態は許されていない
→構文エラー
※実装を後回しにしたい場合や、何もしないことを明示したほうがコードの意図が分かりやすくなる場合などに「pass」文を利用する

［p.071］ ☆ 単文のif構文について（=省略形のif構文／インデント不使用）

［構文例］
`if 条件式: 処理文`
［状況］
処理文が1文のみ（単文）

［余談］Pythonには「Switch」文は存在しない？
［理由］Pythonには「switch」文が実装されない理由［公式ドキュメント］
→　if-else-else-else の繰り返しで簡単に同じことができます。
switch文の構文に関する提案がいくつかありましたが、範囲判定をするべきか、
あるいはどのようにすべきかの合意は（まだ）得られていません。

※if文を駆使することで同様の処理が行えるため、議論こそあったようだが、
実装はされなかったようである。
- Python 3.10からはswitch文と同様の構文の「match」文が導入されている。
  - ［特徴］多言語の「switch」文と似た書式で記述できる［2021/10月から利用可能］参照［p.157］

［Java］
switch(value){
    case'A':
        処理文A;
        break;
}

［Python］
match value:
    case 'A':
        処理文A
    case 'B':
        処理文B
