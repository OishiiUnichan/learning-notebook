［p.075］ ★ 範囲付き繰り返しのfor構文について
Python：ループ変数を使わずに記述する（変数名は任意）

```Python
for 編巣名 in (反復可能な) オブジェクト:
    処理
```

［比較］Java:for構文はループ変数と継続条件を使って記述する
［通常のfor構文］`for(int i = 0; i < 10; i++);`
［拡張for構文］`for(int i:(反復可能な)オブジェクト){処理}`

※Javaの拡張for構文に相当し、リストなどの反復可能なオブジェクトの要素が順番に変数に代入され、処理が行われる。
→ すべての要素に対して処理が繰り返される

［p.076］ ☆ 1から10まで足すといくつ？
- range()関数：数列を生成する反復可能なオブジェクトを返す
1. range(end)
2. range(start,end)
3. range(start,end,step)

- ［基本］range()関数は、start以上end未満の数列をstep刻みで生成する(3)
- stepが省略されると増分は1になる(2)
- startが省略されると0始まり(1)

［p.083］☆ 繰り返しで「else」ブロックを使う場合
elseブロックはJavaでは条件分岐「if文」のみ使用可能だが、Pythonでは繰り返し構文でも使用可能

- elseブロックが処理される条件：（while文の場合）繰り返し条件が偽の場合
  - while-else.py
- breakで繰り返しを抜けなかったとき（=異常終了した時）
  - while-else2.py

※上記はfor文でも発生する。そのため、for文にもelseブロックが用意されている
