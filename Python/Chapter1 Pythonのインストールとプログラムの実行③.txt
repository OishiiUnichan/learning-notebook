	１－３	Pythonの対話モードについて

		[ p.012 ] ★ 対話実行モード（ REPL ）とは？
		　・コンパイラ　言語	： プログラムの実行前に、実行形式に翻訳（コンパイル）が必要な言語（ Java など ）
		　・インタプリタ言語	： プログラムを逐次実行できる言語（ Python など ）
												　 ---┬----
				[ メモ ]	PythonもJavaと同じようにプログラム実行時にファイルがバイトコードに変換され、
						Pythonの仮想マシン「PVM（Python Virtual Machine）」に引き継がれて実行される。														これらの処理は、Python内部で自動的に行われるため、外部からは見えない仕様になっている。

			REPL（ Read - Eval - Print Loop ）：プログラミング言語の実行環境の１つ。
			[ メモ ] ６行目：	Python「にも」REPLがあります。
						→ REPLは、Python特有の機能ではない！
						[ 例 ] Windows：コマンドプロンプト、Mac：ターミナル　など
						　※ JavaにもJDK９でREPL導入された（「JShell」コマンド）

		[ p.013 ] ☆ WindowsでREPLを実行する
			・ 動作環境：コマンドプロンプト or PowerShell（コマンドプロンプトの後継）
			・ 起　　動：検索ボックスにして、「cmd」or「powershell」と入力
			・ 開　　始：pythonコマンド[図1-3-3][参考][Java] jshellコマンド
			・ 終　　了：quit() / exit()					 /exit
				[ メモ ] 関数　→　キーワード
							　ver.3.13以降、()不要でも動作する。
		[P.015] ★ REPLを電卓として使ってみよう
			　 ※ PowerShellでも簡単な四則演算ならば可能である！

		[P.016] ☆ 計算結果「3.0」の謎
			・整数同士で割り算すると、既定では小数点表示になる！？
			　（ Python3では、整数型（int型）→ 実数型（float型）に自動型変換される ）
			　→ Python2では、逆に既定では小数点以下が切り捨てになる！
						（ Javaと同じ仕様で、暗黙の型変換は生じない ）
			　 ★ ３系で仕様が変更された。
