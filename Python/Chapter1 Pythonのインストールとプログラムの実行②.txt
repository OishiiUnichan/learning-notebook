	１－２	Pythonのインストール

		[ p.006 ] ★ Pythonのインストール概要
		・ Pythonは、マルチOSに対応している。
		[ Linux系OS ] Pythonはインストール済であることが多い。[ p.011 ]
			 → CentOS Linux7	）[ コマンド ] Python   -V	→ Python 2.7.5
			 → Ubuntu 16.04.3	）[ コマンド ] Python3 -V	→ Python 3.5.2
			※ Python２、３の両方がインストールされている場合、
			　 既定では、	python3	のコマンド名で　Python3　が、
						python	のコマンド名で	Python2	が起動するようになっている。
			[ Windows ] 公式サイトからインストーラをダウンロードして実行する。

		[ P.006 ] ★ Pythonのダウンロード
				　→ https://www.python.org/downloads/

		・ 最新版）ライブラリなどが未対応の可能性がある。
			〇 2026/08/05）3.14. 7	（ ← 3.14.0：2025/10/07 ）：[ 職業訓練 ]
			✕ 2026/03/03）3.12.13	（ ← 3.12.0：2023/10/02 ）：[ テキスト ]
			✕ 2026/04/20）2.  7.18	（ ← 2.  7.0：2010/07/03 ）：[ ver.2 - 最新版 ]

		※ 【 訓練校（学習環境）での使用バージョンの選定 】
			・通常は、最新版夜も安定版（書籍の使用バージョン）を採用
			　→ 書籍使用のライブラリが最新版に対応していない可能性があるため。
			　◎ Pythonは旬な言語であるため、職業訓練では『最新版』を採用する。
			・ 通常の学習用途では64bit版よりも32bit版を採用
			　→ 処理に大量のメモリを必要とするプログラム（大容量のデータ分析など）を
			　　 作成しない限り、32bit版のほうがメモリの使用量を抑えられる。
			　◎ Windows 10 May 2020 Updateから32bitなんの提供終了に伴い、職業訓練では『64bit版』を採用する。

		[ p.007 ] ★ Windowsでのインストール方法
		[ 図1-2-3 ]
			・ □ Use admin Privileges when installing py.exe
				→ [ 訓練機 ] ユーザー権限で使用しているため、インストールの途中で管理者のパスワードが要求される。
				[ メモ ] py.exe : ver.3.3から登場した「pythonランチャー」という機能を呼び出すコマンド。
				[ 特徴 ]	・ パスを通さなくても、Pythonのスクリプトを実行できる。
						・ 複数のバージョンのPythonがインストールされている環境で、バージョンを指定して実行できる。
						・ バージョンを指定してライブラリをインストールできる。

			・ ■ Add python.exe to PATH
				　→　任意のディレクトリからコマンドが実行できるように、その実行ファイルの保管場所を登録しておく。
				　　　（俗にいう、「パスを通す」という。）

			・ Customize installation
				→ [ Advanced Options ] 画面の [ Customize install location ] を設定する。
 				→ [ 訓練機 ] アプリはユーザー直下のProgramFilesで一元管理する。
				　 [ 設定例 ] C: \ Users \ [ am or pm ] \ ProgramFiles \ Python \ Python314
