Ch04-5 正規表現について

［p.198］★ 正規表現とは？
文字列内で文字の組み合わせを照合するために用いられる書式文字列（パターン）

- 正規表現は、ある文字（メタ文字）に特別な意味をもたせる
- メタ文字を組み合わせることで、複雑な条件を表すことができる
  
前提
- メタ文字以外の文字は、それ自身の正規表現になる
- 正規表現で使う基本的なメタ文字［p.201～204］

［p.198］☆ Pythonで正規表現を使おう
※正規表現のパターンは、通常の文字列表記ではなく、new String記法（R"・・・"）が推奨される
→　エスケープ文字の￥記号は正規表現でも特別な意味で使われる　p.203
→　raw String記法を使うことで、エスケープ文字の￥よりも正規表現の￥を優先させることができる

☆ 正規表現の命令
【関数】
- match/search（pattern,string）
  - （共通）引数patternに正規表現を指定し、引数stringに文字列を指定する
  - search()関数は、文字列の中から正規表現と一致する「部分列」を検索する
  - match()関数は、文字列の「先頭」から正規表現とマッチングするかを調べる。先頭文字が正規表現と一致しなければマッチング失敗となる。
  - （共通）マッチングに成功した場合、matchオブジェクト、失敗した場合Noneを返す。

［その他］
findall（pattern,string）：p.202参照
compile(pattern)：p.203参照

【メソッド】
- matchオブジェクトの主なメソッド
  - group(): パターンにマッチしたグループを返す
  - groups(): パターンにマッチした、すべてのグループの一覧を返す
  ［例］p.204参照
  - start():一致した文字列の開始位置ｓを返す
  - end():一致した文字列の終了位置eを返す
  - span():一致した文字列の範囲をタプル（s,e）で返す

☆繰り返し

＋：直前の正規表現の１回以上の繰り返し

［注意］｛ｍ、 ｎ｝のように、第２引数の前にスペースがあると正しく動作しない

☆ 最小単位の繰り返し
- 正規表現は最長一致を基本とする
- 繰り返しパターンの末尾に？をつけると「最短一致」になる
＊？：直前の正規表現の０回以上の繰り返し
＋？：直前の正規表現の１回以上の繰り返し
？？：直前の正規表現の０回もしくは１回の繰り返し
｛ｍ、ｎ｝？：直前の正規表現のｍ回以上ｎ回以下の繰り返し

［REPL］findall()関数について
- 文字列中でパターンマッチした文字列を要素とするリストを返す
- パターンマッチしない場合は空リストが返される

☆ 文字集合の指定［・・・］
［］：［］内に指定した文字のどれかと一致

短縮記法
- \d：数字
- \D:\d 「数字」以外と一致
- \w:英数字とアンダースコアと一致
- \W:\w　英数字とアンダースコア以外と一致
- \s:空白文字　と一致
- \S:\s　空白文字意外と一致

［REPL］compile()関数について
特定の正規表現をオブジェクトとして生成する
そのため、何度も同じ正規表現を記述することなく、効率的に文字列の検索や置き換えなどを実行できる

［書式］
`オブジェクト名=re.compile(正規表現)`
※正規表現をコンパイルして繰り返し使えるようにすることで、効率的な処理を実行することができる

※単語の揺らぎを考慮したい場合に有効

★内包表記の種類
4種類👉括弧の種類で使い分け
1. リスト内包表記［・・・］👉［式for変数inイテラブル］
2. 集合型内包表記｛・・・｝👉｛式for変数inイテラブル｝
3. 辞書型内包表記｛key:value・・・｝👉｛キー：式for変数inイテラブル｝
4. ジェネレータ式（・・・）→（式for変数inイテラブル）

［注意］タプル内包表記は存在しない
リストには要素を追加することができるが、タプルには要素を追加することはできない。
動的に中身を組み立てていく内包表記の動作プロセスそのものが、タプルの「要素を追加できない」という性質とかみ合わないため、
タプルの内包表記は用意されていない。
