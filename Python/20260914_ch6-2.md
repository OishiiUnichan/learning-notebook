ch6-2 継承について

★ 継承（インヘリタンス）とは？
- 継承は簡単に言うとクラスに「親子関係」をもたせる機能である
- 子クラス（派生クラス）は親クラス（基底クラス）の性質を受け継ぐことができる
- 一般的なプログラミング言語の場合、引き継ぐ性質は定義されたインスタンス変数やメソッドになる
  - ただし、Pythonの場合はインスタンス変数の継承は行われない。継承される要素は、クラス変数とメソッドだけなので要注意。
  - ちなみに初期化メソッドも継承される。

［p.286］☆ 継承の記述方法
［書式］クラスの継承：基底クラスはclass宣言の丸括弧で指定する

```python

class 派生クラス名(基底クラス名):
    """派生クラスの定義"""

```

［メモ］
- オブジェクトの生成が関数の呼び出すと同様の形式であったことから基底クラスの指定は引数に指定する形式になっている
- 暗黙の継承
  - PythonもJavaと同様に、objectクラスを継承している
- super: Pythonでは組み込みクラスであり、クラス名に()をつけるとオブジェクトの生成が起きる。
        つまり、super()を記述することで、基底クラスのメソッドを探索して呼び出してくれる臨時の「プロキシ（代理）」オブジェクト」をその場で生成していることになる。

［比較］［Java］
親クラスのオブジェクトの呼び出しは「super」であり、「super()」は親クラスのコンストラクタの呼び出しになる。

［メモ］thisやsuperは厳密にはキーワードであるが、変数と同様にふるまう。
一方、コンストラクタもメソッドの一部であるため、呼び出しには()が必要である。
Pythonはオブジェクト生成の記述が関数の呼び出し形式であるため、()があることで自身のインスタンスを引数で受け取る設計を維持している

- `super().__init__()`と記述することで、基底クラスの`__init__()`を呼び出すことができる

★ メソッドのオーバーライド
派生クラスで基底クラスのメソッドと同名のメソッドを定義することができる。
これを「オーバーライド(override)」といい、上書き(overwrite)を無視する。

オーバーライドしたメソッドから基底クラスのメソッドを呼び出すときは、super()を使う→`super().メソッド()`
                                                                                👆基底クラスのメソッドを呼び出すキーワード

［スクリプト］override-test2.py
→基底クラスのメソッドを実行させることも出来る
    メソッドの第一引数（self）にはオーバーライドしたメソッドのselfが渡される

★ 多重継承について
- 1つのクラスを継承することを「単一継承」、複数のクラスを継承することを「多重継承」と呼ぶ
- Pythonは多重継承をサポートしているので、◎括弧内に複数のスーパークラスを指定することができる

［書式］多重継承してクラスを定義
```python
class 派生クラス名（基底クラス名１，基底クラス名２，・・・）:
    """派生クラスの定義"""
```
他の多くのプログラミング言語では、多重継承をサポートしていない場合もあります（Javaなど）

［理由］
複数の基底クラスで同名のメソッドが定義されていた場合、どちらかのクラスで定義されているメソッドが使えなくなる
→多重継承を安全に利用できる方法が必要

☆ 多重継承の優先順位
- 単一継承の場合、クラスの階層は木構造になるので、適用可能なメソッドの検索はルートをたどるだけで済む
- 多重継承の場合、クラスの階層がグラフになるため、適用可能なメソッドに到達する経路は複数存在する可能性がある
  - ３つの規則［1.左優先、2.深さ優先、3.合流性］

1. 多重継承に指定された左側のクラスが最も優先される
   1. `class クラス名（A,B,..Z）:`と定義した場合、優先順位はA→B→…→Zとなる
2. 基底クラスが他のクラスを継承している場合は、深さ優先となる
3. あるクラスから基底クラスをたどり、複数の経路で到達できるクラスを「合流点」という

合流則：［スクリプト］multi-iht2.py
メソッドの探索で合流点にぶつかると、そこで探索を中断して次の経路を探索する
最後の経路で合流点に到達したら、それ以降の基底クラスを探索する
