※ファイルオブジェクトは反復可能なオブジェクト（イテラブル）なので、for構文またはnext()関数で１行ずつ読み込むことができる。

［スクリプト］for-lines.py、find.py

［紹介］入出力用の主なメソッド
【読み込み】
- read(size)：sizeバイト読み込んで文字列にして返す。sizeを省略するとファイル全体を読み込む。
- readline()：１行読み込んで文字列にして返す（改行含む）
- readlines()：ファイルのすべての行を読み込んでリストに格納して返す

【書き込み】
- write(str)：文字列strをファイルに書き込み、書き込んだ文字数を返す
- writelines(x)：リストxに格納された文字列をファイルに書き込む

［p.188］★ Pythonのオブジェクトや変数を保存しよう
［メモ］JSON
- データ構造を保持して、テキストデータとやり取りするための書式１つ
- データ構造を保持しているとプログラミングでデータの取得が可能になる

［例］
```json
[
    {
        "日本語":"犬","英語":"dog"
    },
]

```

- JSのオブジェクトで構成されているため、JSで記述したプログラムで扱うことができる
  - JS以外でも「JSON」をパース（解析）して自身のデータ構造として取り扱う言語が増えている

［p.188］jsonモジュールで用意されている主な関数
1. pythonのデータ構造をJSON形式に変換（エンコード）する関数
   - dump：Pythonのデータ構造をファイルに保存するための関数
   - dumps：Pythonのデータ構造を文字列に変換するための関数

JSON形式の文字列データ　<--json.dumps()-->pythonオブジェクト(list/dict)<--json.dump()-->JSON形式のファイル

2. JSON形式をPythonのデータ構造に変換（デコード）する関数
   - load：ファイルをPythonのデータ構造で読み込むための関数
   - loads：文字列をPythonのデータ構造に変換するための関数

JSON形式の文字列データ　<--json.loads()-->pythonオブジェクト(list/dict)<--json.load()-->JSON形式のファイル

［スクリプト］json-io.py
