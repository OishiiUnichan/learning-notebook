Chapter 3-7 例外処理について

★ 例外処理とは？
- 正しく記述されたプログラムには全くエラーが発生しない、という保証はない
  - 条件が整っていない（アクセス権なし、ネット回線の不調など）場合、エラーが発生し、動作が中断される
  - 予期されるエラーに対して事前に対処する方法 = 例外処理

☆ エラーが起きたらプログラムが終了してしまう問題
［例］０除算　→　Pythonでは0で値を割ることは許されていない（ZeroDivisionError）

［比較］
Java）整数型の場合はPython同様エラーになる。実数型の場合は「Infinity」という値を返す。

［p.151］★ エラーを補足する - try - except 構文
［書式］
```Python
try:
    処理
except エラーの種類 as 変数 :
    エラーが起きたときの処理
```

［解説］
1. エラーの種類として「Exception」を記述するとシステム終了系以外のほぼすべての一般的なエラーが捕捉される
   - なお、省略した場合はシステム終了系のエラーも捕捉されるため、アプリが終了できなくなる不具合の原因になる
2. 変数を指定することで、エラー内容を取得できる。そのためデバッグやログ出力が容易になる。


☆ 特定のエラーだけを捕捉する
※一般的にはエラーごとに区別して対応する処理を場合分けする。

- エラーの種類を特定して、異なる対応をする場合（複数のexcept句を記述、上から順に査定する）
  ［書式］except エラーの種類１：
        # エラーの種類１に対応した処理
         except エラーの種類２：
        # エラーの種類２に対応した処理

- エラーの種類を指定するが、同じ対応をする場合（論理和とみなして記述）
  ［書式］except（エラーの種類１，エラーの種類２）：
          # エラーの種類１，エラーの種類２に対応した共通処理

  ［注意］（）で囲う必要あり！
  無）SyntaxError:multiple exception types must be parenthesized

- エラー情報を出力したい場合は、例外オブジェクトを任意の変数に格納する
  ［書式］except エラーの種類 as 変数名：
          print(変数名)


☆ エラーの発生の有無に関わらず必ず最後に実行したい

［書式］
```python
try:
  # 何かしらの処理
except:
  # エラーが発生したときの祖yリ
else:  #elseブロックも使用可能
  # 正常終了した後に行う処理
finally:
  # エラー発生の有無に関係なく行う処理（後処理）
```

★ エラーを発生（報告）させる
［書式］
```python
raise エラーの種類（メッセージ）
```

［比較］
