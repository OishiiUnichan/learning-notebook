ch 04-7 デコレータについて

★ デコレータとは？
関数の処理を「装飾」する仕組み
関数の実行前後に任意の処理を付け加えることができる
👆サーブレットのフィルタに相当する機能

［書式］デコレータ関数の定義
```python
def デコレータ名(func):                     ←ある関数の処理内容を関数オブジェクトとして引数で受け取る

    # 関数内で関数を定義
    def wrapper (*args,**kwargs):         ←ある関数の実引数を可変長引数で受け取る

        # 前処理
        res = func(*args,**kwargs):       ←引数として受け取った関数オブジェクトを実行する

        # 後処理
        return res
    
    # 関数内関数のオブジェクトを返す
    return wrapper
```

［書式］ある関数にデコレータを適用
```python
@デコレータ名           ←デコレータ名を変えるだけで下記の関数実行前後に色々な処理を実行させることが出来る

def 関数名(仮引数リスト):

    # 関数の定義
    return 戻り値
```

［コラム］☆ デコレータを何に使ったらいいのか？
［例］
自作関数
実行ログの自動取得
Webサイトからデータを取得する関数に対して、
    webサイトのデータがすでに取得済みの場合、キャッシュからデータを取得
    取得していない（キャッシュが無い）場合、webサイトからデータを取得
    ※上記を自動判別させることが可能
特定の範囲のデータを受け取る関数の場合
    データをその範囲に自動的に整えるデコレータの作成
    文字コードを自動的にユニコードに直すデコレータの作成

既存関数にも有用である
※デコレータを利用することで、既存関数の処理の前後に自分自身で、処理を付け加えることができる

1. デコレータを使うことで、ライブラリとして提供されている関数を呼んだときに『自動的』に実行される処理を付加することができる
