［p.059］ ★ 条件分岐 if構文の使い方
［書式］
```Python
if 条件式:
    # 条件式がTrueの処理
else: 
    # 条件式がFalseの処理
```

※条件式を満たさない場合の処理が不要ならば、「else:」の記述は省略可能
※なお、真偽値の頭文字は大文字なので要注意［p.036 予約語］

［p.061］ 標準的な規約（PEP8）←インデントはスペース4文字推奨

※インデントを行う際には、スペース記号とタブ文字を使うことができる
→同じブロック内でスペースとタブの混在は許されない（エラーになる）

※タブは文字であり、コンパイルの段階でスペースに置き換えられる
→Pythonでは、タブとスペースを混在させるとエラーになるため、タブはスペース4文字扱いではない、と推察できる
