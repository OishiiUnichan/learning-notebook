## 2. レイアウト編［p.028］

### ★通常フロー
  - WebページにHTML要素がレイアウトされる際に従うルールを「フロー」と呼ぶ。  
   「フロー(Flow)」とは「流れ」という意味であり、WebページにHTML要素がレイアウトされていくときに、各要素がページに流れ込むように配置されていく様子を表している。
  - ブロック要素は上から下へ配置されていき、インライン要素は左から右へ配置されていく。
   
### レイアウトのために通常フローから外れる
HTML要素が規定でしたがう「通常フロー」では、思い通りにWebページをレイアウトすることは難しい。  
サイズを指定できるブロック要素は上から下にしか並ばず、横に並ぶインライン要素はサイズが指定できない。  
後悔されているWebページのように様々なレイアウトを実現するためには、<ins>通常フローから外れる</ins>必要がある。

#### ★フロート（floatプロパティ）
「float（浮かせる）」は、通常フローというページレイアウトの「流れ」に対して「浮いている（流れから外す）状態」を実現することである。  
フローとさせた要素は通常フローには従わず、右や左の指定された位置に浮かび、それ以降の要素はその周りに回り込むように理アウトされる  

 ［設定例］2-6.css 30行目
 ```HTML
 セレクター{float: left};
 ```

 フロートの回り込みを解除する場所はブラウザにはわからないため、後続の要素への影響を防ぐためには<ins>解除</ins>が『必要』になる。  
　　→clearプロパティで指定  
回り込みを解除する要素に`clear: both;`を指定することで回り込みを解除する。  

> [!TIP]
> floatプロパティはclearプロパティとセットで使用すること
