## メディアクエリ
CSSではメディアクエリを使って端末のビューポートの幅に応じて書き分ける。  
　→　プログラミングのif文に相当する手法

［書式］［例］3-1.css
```CSS
/* ウィンドウの幅が1000px以下のとき */
@media only screen and (max-width:1000px) {
	.job div {
		width: calc(50% - 20px);
		height: calc(50% - 20px);
	}
}
```

★解説
 @media <ins>only</ins><sub>①</sub> <ins>screen</ins><sub>②</sub> and <ins>(max-width)</ins><sub>③</sub>  
1. only  
  onlyを使うと、指定した条件に対応していないデバイスを対象外にできる。  
  メディアクエリに非対応の古いブラウザがスタイルを読み込まないように互換性を確保する目的で使用されていたが、最近のブラウザで適用されることはないので、記述不要

2. screen  
  端末の種類の指定
    - all：すべてのデバイス
    - print：プリンタ
    - screen：プリンタ以外のすべてのデバイス（PC、スマホ、タブレットなど）
      - 省略可能で、規定値は「all」

3. max-width　←　指定サイズ以下、　min-width　←　指定サイズ以上  
  画面切り替えサイズを「ブレイクポイント」と呼び、目的に合わせて調整する


> [!TIP]
> モバイルファーストの観点で開発する場合、CSSは基本的にスマートフォン用に記述し、最後にデスクトップ用のCSSで必要な部分を上書きする手順になる。
>
> ```CSS
> @media (min-width: ???px ){上書きしたいスタイルの指定}
> ```
