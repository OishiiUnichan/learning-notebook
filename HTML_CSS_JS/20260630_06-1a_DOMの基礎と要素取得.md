## ★DOM

JSでは  
Webブラウザを構成する要素BOM(Browser Object Model)だけではなく、  
Webページを構成する要素DOM(Document Object Model)も、  
操作対象(オブジェクト)として扱うことができる。

JSでWebページの内容を変更するためには、<ins>事前に操作対象となる要素を「オブジェクト」として取得</ins>しておく必要がある

<details>
<summary>メモ</summary>

### BOM と DOM の操作範囲

ブラウザにおける **BOM (Browser Object Model)** と **DOM (Document Object Model)** の関係を図にすると以下のようになります。BOMはブラウザ全体を扱うより大きな概念で、その中に「文書(ページ内容)」を扱うDOMが含まれます。

```
┌─────────────────────────────────────────────────────────┐
│                  window (BOM のルート)                    │
│                                                           │
│  ┌──────────────┐  ┌──────────────┐  ┌────────────────┐ │
│  │  navigator   │  │   location   │  │     history     │ │
│  │ (ブラウザ情報) │  │ (URL操作)     │  │ (履歴操作)        │ │
│  └──────────────┘  └──────────────┘  └────────────────┘ │
│                                                           │
│  ┌──────────────┐  ┌──────────────┐  ┌────────────────┐ │
│  │    screen    │  │  localStorage │  │  alert/confirm  │ │
│  │ (画面情報)     │  │ /sessionStorage│ │ /setTimeout 等  │ │
│  └──────────────┘  └──────────────┘  └────────────────┘ │
│                                                           │
│  ┌───────────────────────────────────────────────────┐  │
│  │              document (DOM のルート)                 │  │
│  │                                                     │  │
│  │   ┌───────┐     ┌───────┐     ┌───────┐            │  │
│  │   │ <html>│ ─── │ <head>│     │ <body>│            │  │
│  │   └───────┘     └───────┘     └───┬───┘            │  │
│  │                                   │                 │  │
│  │                 ┌─────────────────┼───────┐         │  │
│  │                 │                 │       │         │  │
│  │             <div>...</div>   <p>...</p>  <a>...</a> │  │
│  │                                                     │  │
│  │  → タグ・テキスト・属性などページの中身を木構造で表現      │  │
│  └───────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────┘
```

### 操作範囲の比較

| 項目 | BOM | DOM |
| :--- | :--- | :--- |
| 扱う対象 | ブラウザ自体(ウィンドウ・タブ・履歴・URLなど) | HTML文書の構造・内容 |
| ルートオブジェクト | `window` | `document`(`window.document`) |
| 主なプロパティ/オブジェクト | `navigator`, `location`, `history`, `screen`, `localStorage` | 各種要素ノード(`<div>`, `<p>` など) |
| 主な操作例 | ・URL取得/変更 (`location.href`)<br>・ページ遷移履歴操作 (`history.back()`)<br>・ブラウザ情報取得 (`navigator.userAgent`)<br>・ポップアップ表示 (`alert()`) | ・要素取得 (`getElementById`)<br>・要素生成/削除 (`createElement`, `remove`)<br>・スタイル変更 (`element.style`)<br>・イベント処理 (`addEventListener`) |
| 標準化状況 | 仕様が統一されておらず、ブラウザ実装に依存する部分がある | W3C/WHATWGにより標準化されている |

### 包含関係のポイント

- `document` は `window` のプロパティの一つであり、**DOMはBOMに内包される**形になっています。
- つまり「BOM = ブラウザという外枠の操作」「DOM = その中の文書(ページ)の操作」という関係です。
- `window.document.getElementById(...)` のように、実際にはBOM経由でDOMにアクセスしている形になります。

## 要素の取得

1. 操作対象となる要素に、id属性を設定する
2. documentオブジェクトのgetElementById()メソッドの引数にid名を指定する

［書式］

```js
変数名 = document.getElementById("ID名");
```

<details>
<summary>［確認］6-1.html</summary>

```html
<!DOCTYPE html>
<html>
<head>
	<meta charset="utf-8">
	<title>Web D&P 6-1</title>
	<script src="6-1.js"></script>
</head>
<body>
	<input type="button" onclick="oshite1()" value="押してください">
	<div id="color">ブルー</div> <!--対象となる要素のコンテンツを変更したい-->

    <!--追記-->
    <script>
        //対象要素をオブジェクトとして取得
        let divElem = document.getElementById('color');
        //取得したオブジェクトの内容の確認
        console.log(divElem);
        //オブジェクトとして取得していることの確認
        window.alert(divElem);
    </script>
</body>
</html>
```
