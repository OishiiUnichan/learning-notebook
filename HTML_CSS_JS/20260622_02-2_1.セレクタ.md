## ★セレクタ［表2.1］
セレクタはスタイルを適用す要素（場所）を指定しているが、

- 単純にすべての要素に適用する（①）だけではなく、
- ある条件に一致する要素（☆）や特定の属性を持つ要素（②）にだけ

適用することも出来る。

### ①要素セレクタ
→要素を指定すると、ページ内のその要素すべてにスタイルを適用する。

☆セレクタのグループ化  
　→　複数の要素に同時指定する場合、セレクタをグループ化できる。

［例］h1、h2要素に適用
```html
h1,h2{color:red;}
↑カンマ区切りする
```

☆子孫セレクタ  
　→　要素の子要素（さらにその子要素（孫要素））すべてにスタイルを適用できる。

［例］ul要素の子要素であるli要素だけに適用
```html
ul_li {color:red;}
↑_=空白区切り
```

☆疑似クラス  
　→　要素がの特定の状態にあるときだけ、指定したスタイルを適用できる。  

    ※疑似クラスを使えば、ユーザーが操作した結果、その状態に該当するCSSを指定することができる。
    - ：focus（焦点をあてたとき）　［例］a:focus {color: green; }
    - ：hover（マウスを重ねたとき）　［例］a:hover{color: yellow; }
    - ：active（クリックしたとき）　［例］a:active{color: red; }

> [!TIP]
>a要素では、疑似クラスを組み合わせて指定する場合がある。  
>その場合、疑似クラスもあとから設定した値が優先される。  
>つまり、上記の順番で指定しないと、正しい（意図した）動作にはならない。

### ②id属性とclass属性
セレクタがhtml要素しか指定できないと、同じhtml要素は全て同じスタイルになってしまう。  
特定のhtml要素を指定するためにはid属性（A）とclass属性（B）で指定ができる。
1. id属性（グローバル属性）：html要素に固有のIDを与える属性  
        ［イメージ］学生の学籍番号に相当し、その学校（HTMLドキュメント）に同じIDを有する学生（html要素）は１人しかいない。
    
2. class属性（グローバル属性）：複数の要素を同一扱いする属性  
    ［イメージ］学校のクラスの概念に相当し、同じクラスには複数の学生（html要素）が所属できる。    
    ※（１）1つのhtml要素にid属性とclass属性を同時に指定することも出来る。
    

［例］2-4.html、2-4.css
```html
<!DOCTYPE html>
<html>
	<head>
		<meta charset="utf-8">
		<title>Web D&P 2-4</title>
		<link rel="stylesheet" href="2-4.css">
	</head>
	<body>
		<p>IT関連の職業</p>
		<p class="job" id="programmer">プログラマー</p>　←（１）idとクラスを同時に指定している。
		<p class="job">システムエンジニア</p>
		<p class="job">WEBデザイナー</p>
		<p class="job">ゲームクリエイター</p>
	</body>
</html>

```

```css
p {
    font-size: 30px;
}

.job {
	font-size: 15px;
}

#programmer {
	color: white;
	background-color: blue;
}

［書式］要素セレクター#id属性
ただし、一般的には要素セレクターは省略される。
```

※（２）また、クラス属性値はスペースで区切ることによって、複数指定することも出来る。

```html
<ul>
	<li clas="class02 class03">（２）</li>
</ul>
```
