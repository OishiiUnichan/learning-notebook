## 関数

**［書式］**

```javascript
function 関数名（仮引数リスト）{ // 仮引数にvarやletの記述は不要
    // 処理内容
    [return 戻り値;] // 戻り値が不要な場合は省略可能
}
```

---

### ★変数のスコープ

※変数を宣言した場所と「`let`」「`var`」どちらで宣言したかによる

**［ポイント］**

- 関数内で宣言した変数：その関数の中だけで使用できる（関数スコープ）
- `let` で宣言した変数：同じブロックの中だけで使用できる（ブロックスコープ）

**［例］**

```javascript
<script>
    // let、varに関係なく、script要素内のどの場所でも使用可能（グローバル変数）
    let s = 値;
    var t = 値;

    /* let … ブロックスコープ（ローカル変数）
     * var … どこでも使用できる（グローバル変数）（ブロックスコープを持たない）
     */

    if (条件) {
        let x = 値;
        var y = 値;
    }
    // 制御文の外では、変数xは使用不可だが、変数yは使用可能である。

    /* let, var … 関数スコープ
     * 変数i … ブロックスコープ、変数c … ブロックスコープ、変数d … 関数スコープ
     */
    function abc() {
        let a = 値;
        var b = 値;
        for (let i = 0; 条件; i++) {
            let c = 値;
            var d = 値;
        }
    }
    // 制御文の外では、変数i、cは使用不可だが、変数dは使用可能である。
</script>
```
