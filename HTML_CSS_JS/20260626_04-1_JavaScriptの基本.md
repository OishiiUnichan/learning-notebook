### 2. オブジェクト（BOM：Browser Object Model）

JSはブラウザで動作し、ブラウザを操作するための言語。そのブラウザを構成している各要素を「オブジェクト」として管理（BOM）し、さまざまなメソッドやプロパティが定義されている。

> [!NOTE]
> Javaと異なりオブジェクトは設計済みかつ、責務も定義済みである。

**［例］**

- **ブラウザ本体：`window` オブジェクト**
  - ユーザ通知：`alert('通知する文字列')`
  - データ入力：`prompt('入力ガイド'[,'初期値'])`

- **表示領域：`document` オブジェクト**
  - ブラウザにデータ出力：`write('出力するデータ')`

- **コンソール：`console` オブジェクト**
  - コンソールにデータ出力：`log('出力するデータ')`

  > [!NOTE]
  > Javaの「`System.out.println()`」に相当する

<details>
<summary>［作業］ブラウザの開発ツール＞コンソールから実際に表示させる</summary>

1. `window.alert('こんにちは');`
2. `window.prompt('お名前を入力してください');`
3. `console.log('こんにちは');`

</details>

## ★記述場所

| 番号 | JavaScriptの記述方法 | CSSの記述方法 | 特徴・記述場所 |
| :--- | :--- | :--- | :--- |
| 1 | **イベントハンドラ属性**（p.087） | **① style属性** | HTMLタグに直接、属性値として記述する。 |
| 2 | **script要素** | **② style要素** | head要素またはbody要素の中に記述する。 |
| 3 | **外部ファイル**（拡張子「.js」）<br>※script要素のsrc属性で指定 | **③ 外部ファイル**（拡張子「.css」）<br>※link要素のhref属性で指定 | 外部ファイルを読み込んで適用する。 |

> [!NOTE]
> 一般的には`</body>`の直前に記述する（表示優先）。
>
> → head要素内に記述するとbody要素内の処理を行う前にJSの記述を処理する（外部ファイルの場合はファイルを読み込む）ため、表示に時間を要することになる。

---

scriptタグの属性を使って、レンダリングの処理と以下のことができる。

- **非同期実行（`async`）**  
  JSの処理を非同期にしたり、対象の読み込み後、すぐに実行する。  
  なお、レンダリングの処理が終了していない場合は中断される。

  ```html
  <script src="sample.js" async></script>
  ```

- **遅延実行（`defer`）**  
  JSの処理を遅らせたりできる。

  ```html
  <script src="sample.js" defer></script>
  ```

これら属性を使用することで、  
head要素内に記述してもレンダリングの動作に悪影響を及ぼさずに、  
body要素内で記述した時と同じ結果が期待できる。

> [!TIP]
> Webページを表示する前にJSの処理を実行させる必要がある場合は、head要素の中に記述しておく必要がある。

<details>
<summary>💡 余談：script要素の解釈ルール</summary>

> [!NOTE]
> script要素はHTMLのルールではなく、JSのルールでブラウザが解釈するため、body要素やhtml要素の <ins>外側</ins> に記述しても問題なく動作する。

**［参考］標準化団体**

| 言語 | 標準化団体 |
|------|------------|
| HTML | WHATWG |
| CSS  | W3C |
| JS   | <ins>ECMA</ins> International |

ECMAは当初は略語だったが、現在は略語ではなく正式名称（固有名詞）となっている。

</details>

> [!WARNING]
> **［p.048］（1）body内にプログラムを直接定義 ［4-1.html］**
>
> ```html
> document.write('文字列');
> ```
>
> ブラウザに文字列を表示するメソッド（Javaの `System.out.println()` に相当）。
>
> ブラウザのレンダリングに悪影響が出たり、DOMへの影響などを考慮して「強く非推奨」とされている。  
> 今回はJS学習のために使用するが、通常は以下の方法を採用する。
>
> 1. `textContent` プロパティや `innerHTML` プロパティを使う
> 2. `insertAdjacentHTML()` を使う

<details>
<summary>💡 scriptタグに不要な記述</summary>

CSSの `style` タグと同様に、`script` タグにも下記の記述は不要である。

1. **`type="text/javascript"`**  
   → スタイルシートといえば「CSS」と同様に、ブラウザで動作するスクリプト言語といえば「JavaScript」である。

2. **HTMLのコメントの中にコードを記述する**  
   → CSSに非対応なブラウザはほぼ皆無　＝　JSに非対応なブラウザもほぼ皆無

</details>

## ★関数（メソッド）

**［p.048］**
- （２）head内で関数を定義して、関数を呼び出す
- （３）JSファイルを定義し、ファイルの中にある関数を呼び出す

スクリプト言語が短い記述で動作するためには、<ins> 本来記述すべきコードを省略 </ins><sub>①言語仕様に含める、②関数として定義する</sub>している。  
したがって、スクリプト言語には数多くの関数（メソッド）が用意されている。
