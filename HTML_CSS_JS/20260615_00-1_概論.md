## Webページを形作る3つの基本言語の役割と特徴の比較

［作成のポイント］言語の役割を越えない：それぞれの役割内で実装する

| 項目 | HTML | CSS | JavaScript |
| --- | --- | --- | --- |
| **役割** | ページの骨組み・構造を作る | ページの見た目・デザインを整える | ページに動き・機能を付ける |
| **言語** | マークアップ言語 | スタイルシート言語 | プログラミング言語 |
| **例（家）**| 柱や壁（構造） | 壁紙や扉、窓（内装） | 自動ドアや家電（設備） |
| **用途** | ・文章や見出しの作成<br>・画像やリンクの用意<br>・入力フォームの設置 | ・文字色やサイズ変更<br>・背景色や余白設定<br>・レイアウト調整 | ・ボタンクリックで動作<br>・ポップアップの表示<br>・画像のスライド |
| **難易度** | ★☆☆<br>（比較的簡単） | ★★☆<br>（覚えれば出来る） | ★★★<br>（少し複雑） |
