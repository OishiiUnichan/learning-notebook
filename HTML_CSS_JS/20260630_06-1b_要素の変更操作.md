## 要素内の文字列/HTML要素の変更

［文字列］

- textContentプロパティ）`取得した要素.textContent = '変更後の文字列'`

［HTML要素］

- innerHTMLプロパティ）`取得した要素.innerHTML = '変更後のHTML要素'`

<details>
<summary>［確認］6-1.js</summary>

```js
//変更
function oshite1() {
  let f = document.getElementById("color");
  let colorName = window.prompt("青をカタカナで入力してください");
  if (f.innerHTML == "ブルー") {
    f.innerHTML = "ホワイト";
  } else {
    f.innerHTML = colorName;
  }
}
```

</details>

> [!TIP]  
> 文字列のみの表示(出力)はセキュリティと性能(高速)の観点から、textContentが推奨される

## 要素内のCSSの変更

### 1. styleプロパティでstyle属性を取り扱うオブジェクトを取得する

［書式］

```js
変数名 = 取得した要素.style
```

<details>
<summary>［確認］6-2.html</summary>

```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="utf-8" />
    <title>Web D&P 6-2</title>
    <link rel="stylesheet" href="6-2.css" />
    <script src="6-2.js"></script>
  </head>
  <body>
    <input type="button" onclick="oshite2()" value="押してください" />
    <div id="color">ブルー</div>
    <!--追記-->
    <script>
      //対象要素をオブジェクトとして取得
      let divElem = document.getElementById("color");
      //取得した要素のstyle属性を取り扱うオブジェクトの内容の確認
      console.log(divElem.style);
      //オブジェクトとして取得していることの確認
      window.alert(divElem.style);
    </script>
  </body>
</html>
```

</details>

### 2. 変更したいCSSのプロパティ名がそのままCSSStyleDeclarationオブジェクトのプロパティ名になる

［書式］

```css
変数名.CSSプロパティ名 = '変更後の値';
```

> [!WARNING]  
> <b>プロパティ名はキャメルケースで指定する！</b>  
> JSではハイフンは使用できない記号であるため、CSSプロパティ名から「-」を削除し、次の文字を大文字で記述する。

［例］1つの単語はそのまま採用する

- left → left
- color → color

連結単語（ケバブケース）はキャメルケースに変更する

- background-color →　backgroundColor
- font-size → fontSize

> [!NOTE]
>
> - キャメルケース：最初の単語以外の文字の先頭を大文字
>   - 変数名、メソッド（関数）名 など
> - コンスタントケース：すべて大文字、単語をつなげる場合はアンダースコア
>   - 定数名、グローバル変数名 など
> - パスカルケース：文字の先頭を常に大文字
>   - クラス名 など
> - スネークケース：文字の単語間にアンダースコア
>   - DBのカラム名、フォルダ名・ファイル名 など
> - ケバブケース：文字の単語間にハイフン
>   - HTMLの属性名、CSSのプロパティ名、URL など

> [!WARNING]  
> **CSSの値の変更について**  
> 今回紹介した「要素、style、CSSプロパティ名」は各要素の『style属性』を操作するJSの記述である

［確認］  
ブラウザの開発者向けツールの［Elements］タブで対象のHTML要素の属性の変更を確認できる。

［紹介］  
『style要素』を確認する記述には`getComputedStyle()`メソッドを使用する。
