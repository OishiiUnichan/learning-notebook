### A.HTML編

※構成要素のタグおよび属性に関しては『[とほほのHTML入門](https://www.tohoho-web.com/html/index2.htm)』を参照

**［確認項目］**  
- ユーザビリティやアクセシビリティの向上：自動フォーカス、音声読み上げに対応
  - ラベルによる関連付け　…　`<label>`要素とfor要素

- フォームの基本構成部品  
  - テキストボックスとテキストエリア　…　`<input>`要素とvalue属性 
  - ラジオボタンとチェックボックス type="radio" , type="checkbox"
  - セレクトボックス　…　`<select>`要素、`<option>`要素とvalue属性

- 入力情報の送信、JSの実行
  - ボタン　…　`<input>`要素 / `<button>`要素
    - type="button" / 単なるボタンとして使いたいときはbutton
    - type="submit" / 送信ボタンにしたいときはsubmit
    - type="reset" / formタグで挟み込んでいるときにのみ有効

フォームのデータ送信には、Formタグのaction属性とmethod属性が必要になる。  

［メモ］method属性（送信方法）とは？  
　→　サーバーにデータを送信する形式を指定する属性  
　→　属性値は「GET」or「POST」の二択  
　　※フォームの入力パラメータは、  
  - GET指定の場合：URLの引数として渡される
  - POST指定の場合：HTTP通信のボディデータとして送信される

### B. JS編
#### valueプロパティ
- テキストボックス、テキストエリアに入力した文字列
- チェックボックス、ラジオボタン、セレクトボックスのvalue属性値

［書式］
```js
変数名 = 取得した要素 . value;
```

> [!WARNING]
> 外部から入力されたデータは、基本的に「文字列」として扱われる。  
> 数値として扱いたい場合は、perseInt()関数や、parseFloat()関数で変換する必要がある。

> [!NOTE]
> **入力制限について**  
> 
> ①type属性
> 　→　type属性を工夫することで利用者に入力制限を課すことができる。  
> ［例］type="number"  ←数値専用の入力ボックス  
> ［確認］6-3.html　←type属性値をtext→numberに変更する  
> ［メモ］設定値）password：伏字、date：日付
>
> ②pattern属性
> 　→　属性値に正規表現ができる（細かな入力パターンの指定が実現可能）
> ［例］　pattern="\d{3}"　←数字３桁のみ入力許可

#### checkedプロパティ
- チェックボックス、ラジオボタンのON/OFF  
［書式］
```js
変数名 = 取得した要素.checked;
    → true = ON　、false = OFF
```
