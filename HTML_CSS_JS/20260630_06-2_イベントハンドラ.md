## ★イベントハンドラ［p.087］［表6-1］

JSを正しく動作させるには、操作対象である要素に「実行時機」を指定しておく必要がある。  
対象要素にCSSを指定する「style」属性が用意されているように、JSを実行する時機を指定する「属性」が用意されている。

［書式］

```
イベントハンドラ = 'JSのコード'
```

［比較］

```
CSS） style = 'CSSのスタイル宣言'
```

> [!NOTE]  
> イベントハンドラの属性値にJSのコードを直接記述することは可能である。が、HTMLとの親和性が損なわれるため、関数の呼び出しが一般的である。

### 代表的なイベントハンドラの例

| イベントハンドラ | 発火タイミング |
| :--- | :--- |
| `onclick` | 要素が押下されたとき |
| `onmouseover` | 要素にマウスカーソルが重なったとき |
| `onmouseout` | 要素からマウスカーソルが離れたとき |

## ★イベントリスナー

Q. CSSと同様に、JSのコードを外部ファイルに切り離すには？  
A. HTMLとJSを完全に分けて管理するには、イベントハンドラを使用せず、イベントリスナーを使用する必要がある。

［書式］

```js
取得した要素.addEventListener("イベント", "関数名");
```

1. イベント  
   関数を呼び出す時機を指定するキーワード  
   基本的にはイベントハンドラの接頭辞「on」を取り除いた用語になる  
   ［例］onclick → click

2. 関数名  
   関数を呼び出すわけではないため、関数名末尾の()は不要である

> [!NOTE]  
> ［メモ］関数名は引用符で囲まない？  
> JS（含めたスクリプト言語の多く）は、関数を定義すると関数名と同じ変数名が使用できるようになり、その変数に関数の処理内容がオブジェクト（関数オブジェクト）として格納されている。  
> そのため、イベントリスナーを登録する際の第2引数は、正確には「関数名」ではなく、「関数オブジェクト」（変数）を指定していることになる。
