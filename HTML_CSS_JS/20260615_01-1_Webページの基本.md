## 【Webページの基本】

☆Webサイトの仕組み（World Wide Web：通称「WWW」）  
　→世界中に張り巡らされたコンピュータの通信網  
　　→コンピュータ同士の通信規約：HTTP（HypreTextTransfarProtocol)  

（HTTP通信）URL（Uniform Resource Locator）にて、Webサーバを特定し、Webページを要求［p.002］  
　　ブラウザを通して、URLから、Webサーバへリクエストする  
　　Webサーバが、HTMLデータを、Webページの画面にレンダリングして、レスポンスを返す  

**［HTMLデータの形式］ハイパーテキスト**   
　→リンクを埋め込むことの出来るドキュメント  
 　　リンク：ドキュメントに埋め込まれたURL  

※ハイパーテキストに情報を埋め込むためには、コンピュータが理解できるようにルールに則ってWebページを記述する必要がある

→Webページの記述：HTML（HyperTextMarkupLanguage）

## 【補足】［p.002 - 図 1.1］

### ☆ホスト名、ドメイン名、サーバー名？
［例］https://news.yahoo.co.jp/  
→サーバ名（ホスト名：news＋ドメイン名：yahoo.co.jp）   
→FQDN ：「**Fully Qualified Domain Name**」の略。日本語では「完全修飾ドメイン名」  
［注］「ホスト名≒FQDN」「ドメイン名≒FQDN」で表現する場合もある。

#### ★ホスト名：ホストコンピュータの省略語（ネットワークの中心的な役割を果たすコンピュータ）
→　インターネットにおける「構造物」に相当する。意味のある名前をつける。上記の例の場合、『ニュース』サイトであることが分かる。

#### ★ドメイン名：インターネットにおける「住所」に相当素。
→　重複登録することは出来ない  
→　商標などに違反しない限り早い者勝ち

※ドメインは「．（ドット）」で区切られた形式となっている。  
　最後のブロックが「トップレベルドメイン」、その前が「セカンドレベルドメイン」・・・と階層的に管理されている。  
［例］yahoo.co.jp  
　　jp→トップレベル、co→セカンドレベル、yahoo→サードレベル

> [!TIP]
> Javaはドメイン名をパッケージ名に推奨している。
>［参考］スッキリわかるJava入門 第４版　第６章［p.241］

## HTML （Hyper Text Markup Language）
→プログラミング言語ではなく、マークアップ言語に分類  

Hyper Text：相互につながるWeb用のドキュメント  
通称：「HTMLファイル」、「HTMLドキュメント」  
　　→「HTML」というマークアップ言語で記述されており、ブラウザによって人間の読みやすい形に整形される。  

整形前の状態（ソースコード）はブラウザの機能で確認可能である。  
［見本］はじめてのWebデザイン&プログラミング  
[https://www.morikita.co.jp/books/mid/085721](https://www.morikita.co.jp/books/mid/085721)  
　→　余白を右クリック　＞　ページのソースを表示  

HTMLファイルには、Webページの内容となる文章（テキスト）を記述し、読み込みたい画像などの置いてある場所を記述する。  
テキストの構成要素は、マークを付けて表現するため「マークアップ」言語と呼ばれる所以である。  
HTMLの学習は、このマークの種類と使い方をひととおり覚える作業になる。  
　→名称：タグ、補足情報：属性
