## ★jQuery[p.089]

JSを少ない記述で簡単に使えるようにまとめられたコード集  
　→ 最初からある程度の形を用意<sub>類似機能：関数の定義</sub>しておくことでコーディングの手間を省くことができる。

### 準備

コード集であるため、読み込ませておく必要がある。

#### 方法1

1. 公式サイトからjQueryファイルをDLしてインポートする
2. jQueryを使いたいファイル内に下記のコードを記述する

```js
<script src="https://code.jquery.com/jquery-4.0.0.min.js"></script>
```

#### 方法2

Web上のjQueryファイルを読み込む。使いたいファイル内に下記のコードを記述する。

```js
<script src="https://code.jquery.com/jquery-4.0.0.min.js"></script>
```

> [!NOTE] memo
> VScodeに拡張機能が存在する。  
> jQuery Code Snippets

### 基本の型

```js
jQuery(無名関数の定義);
```

※関数名は外部から呼び出す場合に必要になる。定義した関数はjQueryで使用するため、関数名は必要ない。

[書式]無名関数

```js
jQuery(function () {
  // ここにメインの処理を記述 };
});
$(function () {
  /**
        一般的に「jQuery」の記述個所は「$」で簡略される
        * 使用例：6-8.html */
});
```

JSのコードをきちんと記述するのではなく、ある規則に従って簡潔な記述ができる。

## ★jQueryオブジェクト.メソッド

［書式］

```js
jQuery(function () {
  //［CSSの場合］
  $("セレクタ").メソッド("引数"); // セレクタ{プロパティ:値};
});
```

※jQueryの中身は下記の3つの要素で構成されている。

1. jQueryオブジェクト：セレクタで要素を指定
2. メソッド：動作の指定
3. 引数：指示の指定
4. 

**［紹介］**
| メソッド | 機能 | 参考 |
| -------- | -------------------------------------- | ------------------- |
| .text() | 要素の文字列の取得・書き換え | textContent |
| .html() | 要素のHTMLの取得・書き換え | innerHTML |
| .css() | CSSプロパティの変更 | CSSStyleDeclaration |
| .on() | イベント発生時に実行する関数の割り当て | addEventListener() |
