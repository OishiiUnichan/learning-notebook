## ★CSSの記述場所［p.20-21］

CSSの記述場所は3種類ある

1. インラインスタイル（style属性）
2. 内部スタイルシート（style属性）
3. 外部スタイルシート（CSSファイル）

<hr>

### 1. インラインスタイル（style属性）：【用途】表示確認
ここのhtml要素にスタイルを直接適用する方法。対象となるhtml要素に「style属性」（グローバル属性）を桑う。

［書式］［例］2-1.html

```html
<!DOCTYPE html>
<html>
	<head>
		<meta charset="utf-8">
		<title>Web D&P 2-1</title>
	</head>
	<body>
		<p style="font-size: 30px ">フォントサイズは30ピクセルです。</p>
	</body>
</html>

```

> [!TIP]
>  style属性はグローバル属性なので、すべての要素で使用可能である。
> - インラインスタイルは特定のhtml要素にstyle属性を直接記述するので、セレクタに該当する記述は不要
> - style属性値として、スタイル宣言を1行で記述する
> - プロパティが1つだけのときは、セミコロンの省略が一般的である

### 2. 内部スタイルシート（style要素）：【用途】検討（試行錯誤）
head要素（or body要素）内にstyle要素で指定する。
    
［例］2-2.html
```html
    <!DOCTYPE html>
    <html>
	<head>
		<meta charset="utf-8">
		<title>Web D&P 2-2</title>
		<style>
			p { font-size : 30px; }
		</style>
	</head>
	<body>
		<p>フォントサイズは30ピクセルです。</p>
	</body>
</html>
```

 >[!TIP]
 > ［p.20　抜粋］  
    > 以前はstyleタグの中にtype属性や`<!-- -->`の記述が必要でしたが、HTML5以降は不要となりました。
    >
    >［補足］以前は「スタイルシート＝CSS」ではないが、現在のWebページにおけるスタイルシートは「CSS」の一択になっているため、HTML5以降はstyleタグに「style属性は不要」になっている。［参考］`type=”text/css”`  
    >［紹介］DSSSL、JSSなど
    >
     >また、style要素を使ってHTML文書の中にCSSを記述する場合、その内容をHTMLのコメントでくくることができる。
    >
    >［以前］CSSの部分がHTMLのコメントになり、CSSに対応していないブラウザでCSSの宣言の表示を防いでいた。
    >
    >［現在］現在のブラウザでCSSに対応していないブラウザはほぼ無い状況なため、HTMLのコメントによる記述は不要になっている。  
        


1. 外部スタイルシート（CSSファイル）  
→　拡張子を「.css」としたCSSファイルを作成し、HTMLドキュメントから読み込む形式  
　 ※複数のHTMLドキュメントから同じCSSファイルを読み込んで
    - デザインに統一感を持たせたり
    - 目的に合わせたCSSをファイル単位で管理できる

などの利便性のある形式で、CSSは一般的にこの方法で運用する。

※CSSファイルの1行目には文字コードを指定するための「@charset “UTF-8”;」の記述を推奨する。
※CSSファイルの読み込みはhead要素に記述した「link要素」で記述する。
        
> [!TIP]
> link要素の本来の役目は、外部リソースの参照である。そのあめ、読み込めるファイルはCSSファイルに限らない。  
> ［例］2-3.html
> ```html
>  <link rel="stylesheet" href="2-3.css" />
> ```
        
> [!TIP]
> - rel属性：外部ファイルの種類や関係を指定
> →　CSSファイルの場合、属性値は「stayleseet」を指定
> - href：外部ファイルのURLを指定
>［注意］p.021
> 外部スタイルシートを指定したうえで、同じスタイル宣言をインラインスタイルで指定した場合、後者が優先される
