## ★フレックスボックス（flex）
親子要素の関係にある子要素の配置を柔軟に指定することができる。  
フレックスボックスの利用には、横並びにしたい要素の「親要素」に、displayプロパティ`display: flex;`を設定する。

> [!NOTE]  
> 親要素を「コンテナ」、子要素を「アイテム」と呼ぶ。

［例］3-4.html　11行目  
　→　親要素に「container」というclass名を付けておく

［例］3-4.css　31行目  
　→　containerクラスのdiv要素に「`display: flex;`」を記述する。  
　→　「`flex-flow: row;`」でアイテムが横並びになる。  
　→　「`flex-flow:column;`」でアイテムが縦並びになる。

## floatとflexの比較

| 項目 | △ floatプロパティ | ◎ フレックスボックス |
| :--- | :--- | :--- |
| **設定対象** | ふるまいを変えたい**要素自体**に設定する。 | アイテム要素の**親要素（コンテナ）**に設定する。 |
| **イメージ** | 下線を運行する「船団」 | 河川の一部を堰き止めた「プール」 |
| **目的** | 要素を左または右に浮動させ、回り込ませる。<br>→ テキストを画像などの周りに回り込ませる。 | 要素への柔軟な配置（横並び、縦並びなど）<br>→ Webページのレイアウトを組む。 |
| **解除の成否** | 後続の要素への影響を防ぐため、解除が **『必要』** 。 | 親要素内に影響が生じるため、解除は **『不要』**。 |
| **補足・詳細** | clearプロパティを設定しない限り、floatプロパティの設定は継続される。 | 配置の設定はアイテム要素のみに適用される。 |
