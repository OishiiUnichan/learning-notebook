## 【CSSによる装飾とレイアウト】

（従来）～HTML4.01  
多くのWebページがレイアウトや装飾をテーブルや要素の属性で行っていた。  

（現状）HTML5～  
見た目を制御する属性は原則すべて廃止され、CSSで定義するように統一されている。

## 【CSSとは】
「Cascading Style Sheet」の略で「スタイルシート」と呼ばれることもある。  
※目的はWebページの見栄えを整えること。

htmlの要素や色の大きさ、余白、配置、アニメーションなど、CSSで設定できる項目は数多くある。

それらの項目を最初からすべて覚えていく、ということは現実的ではないので、ここでは基本ルールを覚えて、インターネット検索で対応できるようになることを目標とする。

## ★CSSの基礎
【基本的な記法】［p.021　図2.3］
```html
セレクタ{　　　　　　←セレクタ）スタイルを適用する対象を指定する
	プロパティ：値；　←プロパティ）適用するスタイルの種類を指定する
｝
プロパティと値をひとまとめに「スタイル宣言」と呼ぶ
```

［例］
```html
h1 {
	color:red;
}

h1要素の色を赤くする
```

> [!NOTE]
> 「プロパティ」は日本語に訳すと「属性」である。HTMLにも「属性」という用語がある。  
> 日本語の解説では、CSSのほうは「プロパティ」と表記される。  
> 英語では、HTMLのほうの属性は「attribute（アトリビュート）」（静的、先天的）で追加情報の付与とし、CSSのほうの属性は「property」（動的、後天的）で見栄えの制御とニュアンスが異なる。  
> 
> ---
> ★ちなみに…JavaScriptのオブジェクトにも「プロパティ」はあるが、これは状態の管理・操作である。なお、1つの対象に対して複数のプロパティを設定することも出来る。  
> 同じプロパティが存在する場合は、より後の設定が優先（上書き）される。  
> 
> ［例］
> ```html
> h1{ 
>   color: white; 　　　　　　/*変更*/
>   background-color: blue;　/*追加*/
>   background-color: red;　/*上書*/
> }
> ```
