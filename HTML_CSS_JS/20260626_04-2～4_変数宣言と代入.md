## ★基本文法

開発当初は「LiveScript」と呼ばれていたが、当時注目を浴びていたJavaの成功にあやかって「JavaScript」と名前を改めただけあって、Javaの<ins> 記述ルール </ins>と似通っている点の多い言語である。

> [!WARNING]
> 記述ルールは似通っているが、両言語の仕様は全く異なる。

**［例］変数宣言**

|        | Java                                             | JavaScript                                       |
| :----- | :----------------------------------------------- | :----------------------------------------------- |
| 型付け | 静的型付け                                       | 動的型付け                                       |
| 説明   | 変数宣言時に、事前に型を決める。型は不変である。 | 代入時に都度、変数の型が決まる。型は可変である。 |

> [!WARNING]
> **var ［p.050］**  
> 変数をしていするための「var」は、
> - 同じ変数名が複数あってもエラーとして検知されなかったり、
> - ブロックスコープに対応できない、などの  
> 
> 意図しないバグが発生しやすい仕様となっている。最近の書籍では見かけることは少なくなったが、過去の書籍や記事には登場していることが多く、注意が必要である。  
> 「var」は明確に非推奨とは言えないが、前述の理由からなるべく「let」や「const」を利用することをお奨めする。  
> 「let」：再代入できるが、再宣言は出来ない。  
> 「const」：再代入も、再宣言も出来ない。  
> いずれもうっかり同じ変数名で書き換えてしまう前にエラーとなるので、バグに気づきやすくなる。  
> 再代入の必要が無ければ極力「const」を使うとよい。

## 算術演算子

> [!WARNING]
> インクリメント/デクリメント演算子には、Javaと同様に前置と後置がある。

**［例］コンソール画面に続けて入力して確認してみる。**

```javascript
let num = 0;

// ［前置］
console.log(++num); // 1

// ［後置］
console.log(num++); // 1
console.log(num);   // 2
```

## 比較演算子

> [!WARNING]
> JSには、`==` と `!=` のように、型の異なる値同士を比較する際に自動で型変換を行う演算子がある。  
> 便利に思えるかもしれないが、予期せぬ動作を引き起こす原因となることがある。

**［例］**

```javascript
console.log(0 == '0');    // true
console.log(false == ''); // true
```

<details>
<summary>［確認］型変換</summary>

| 変換前 | 変換後 | 関数 | 例 |
| :--- | :--- | :--- | :--- |
| 数値・真偽値 | 文字列 | `String()` | `String(0)` → `"0"` |
| 数値・文字列 | 真偽値 | `Boolean()` | `Boolean(0)` → `false`<br>`Boolean('')` → `false` |
| 文字列・真偽値 | 数値 | `Number()` | `Number('0')` → `0`<br>`Number(false)` → `0` |

</details>

---

**［解決策］**  
厳密等価演算子 `===` と `!==` を使う。これらの演算子は、比較の際に型変換を行わず、より予測可能な動作が得られる。


**［例］**

```javascript
console.log(0 === '0');    // false
console.log(false === ''); // false
```
