アプリケーション開発ではデータの集合を処理することが多いが、これまで学習した定数や変数は1つのデータしか取り扱えない。  
→ たいていのプログラミング言語にはデータの集合体を扱うための <ins>データ構造</ins> が用意されている。JSでは **配列** と呼ばれている。  
　→ データ構造：コレクション：データをまとめて格納するデータ構造の総称  
　　JSでは以下のコレクションがある

- 配列 ← JavaのListに相当
- 連想配列 ← JavaのMapに相当

> [!NOTE]
> JSの配列はJavaのコレクションの1つであるリストに相当する。  
> → 要素数は「可変」長であり、要素の追加・削除ができる。

## ★配列の生成方法

### 1. new演算子

- 引数なし  
  `let array0 = new Array();` // 要素をもたない空の配列
- 引数あり  
  `let array1 = new Array(5);` // 要素5の配列  
  `let array2 = new Array(1,2);` // 配列[1,2]

> [!WARNING]
> - 引数が1つのときは配列の要素「**数**」を指定したことになり、その要素の数の配列が生成される。
> - 引数が2つ以上のときは配列の要素を指定したことになり、その要素をもつ配列が生成される。  
> ※引数の数により挙動が変わるため、非推奨とされる場合がある。

### 2. リテラル

- 要素なし  
  `let array0 = [];` // 要素をもたない空の配列
- 要素あり  
  `let array1 = [5];` // 配列[5]  
  `let array2 = [1,2];` // 配列[1,2]

※リテラルの方が簡素で一般的に分かりやすいため、リテラルを使用する方が一般的であり、new演算子の使用は<ins>特定の要件がある場合</ins>に限られる。

> ［例］  
> 1つずつ要素を入れて配列長を都度拡張していくよりも、最初にまとめて確保しておいた方が処理速度は速くなる。

### 3. 文字列 → 配列

例 5-3.js

```js
var str = 'Fukuoka,Saga,Nagasaki';
var ary = str.split(',');
document.write('ary[0]=' + ary[0] + ', ary[1]=' + ary[1] + ', ary[2]=' + ary[2]);
// 出力結果
// ary[0]=Fukuoka, ary[1]=Saga, ary[2]=Nagasaki
```

Stringオブジェクトの`split()`メソッドの引数に<ins>区切り文字</ins>を指定する

**［参考］** 文字列 ← 配列

例 5-4.js

```js
var ary = ['Fukuoka', 'Saga', 'Nagasaki'];
var str = ary.join(':');
document.write('str = ' + str);
// 出力結果
// str = Fukuoka:Saga:Nagasaki
```

配列オブジェクトの`join()`メソッドの引数に<ins>連結文字</ins>を指定する

## ［補足①］空要素を持つ配列

JSでは、要素が空である配列を作成することも可能である。  
［例］ `let array = [1, ,3]` // [1,empty,3]

**［メモ］** 要素が無い表現について

- `empty` ：暗に要素が空であるという表現として使われる。emptyという値は存在しない。
- `null` ：明示的に要素が空である、と表現したい場合に使われる値
- `undefined` ：要素が未定義である、と表現したい場合に使われる値。emptyを参照すると、undefinedになる。

また、new演算子で要素数を指定して配列を生成した場合、すべての要素のデフォルト値は空になる。

［例］

```js
let array = new Array(3);
console.log(array);    // [empty, empty, empty]
console.log(array[0]); // undefined
```

## ［補足②］配列へのアクセス

Javaと同様、添え字は0から始まり、括弧で添え字を指定する。  
存在しない添え字にアクセスすると `undefined` となる。

［例］

```js
let array = [1,2,3]
console.log(array[3]) // undefined
```

配列への代入も同様に行える。

［例］

```js
let array = [1,2,3]
array[1] = 5; // 2番目に5を代入
console.log(array) // [1,5,3]
```

［注意］配列を定数として定義しても、要素は定数ではないので変更可能である

［例］

```js
const array = ['dog','cat'];
array[0] = 'rabbit'; // 書き換え可能
console.log(array)   // ['rabbit','cat']
array = ['taro','jiro'] // 書き換え不可
// Assignment to constant variable.
```

※配列そのものを別のデータで上書きしようとするとエラーになる。  
　→ Assignment to constant variable.

## ［補足③］配列の要素数

`length` プロパティで調べることができる。

```js
console.log([1,2,3].length); // 3
```

`length` プロパティに値を設定することで、配列の要素数を変更できる。

［例］

```js
let array = [1];

// 配列を長くする
array.length = 3;
console.log(array); // [1, empty, empty]

// 配列を短くする
array.length = 2;
console.log(array); // [1, empty]
                    // 余計な要素は削除される
```

また、配列の要素はメソッドでも変更できる。

［例］

```js
let array = [1];

// 末尾要素の追加(push)
array.push(2); // 末尾に2を追加
console.log(array); // [1, 2]

// 末尾要素の削除(pop)
array.pop(); // 末尾の要素を削除
console.log(array); // [1]

// 先頭要素の追加(unshift)
array.unshift(0); //先頭に「０」を追加
console.log(array); // [0, 1]

// 先頭要素の削除(shift)
array.shift(); //先頭の要素を削除
console.log(array); // [1]
```

ちなみに、途中の要素の追加と削除には `splice()` を使用する。

［書式］

```js
配列.splice(添え字, 0/1, 挿入する要素);
```

第1引数：挿入/削除する場所  
第2引数：0 → 挿入、1 → 削除
