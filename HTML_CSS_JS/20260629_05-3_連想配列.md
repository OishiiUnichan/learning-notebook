## ★［連想］配列の生成方法［p.070］
連想配列の要素の値をキーで管理する　→　`{キー:値,キー:値...}`  
配列の要素の値は添え字で管理する　→　`{値,値...}`  
※括弧の種類の違いに注意する  

---

### 1.new演算子
```js 
let obj0 = new Object(); //要素をもたない空の連想配列  

// 要素の追加  

// ブラケット記法  
obj0['age'] = 21; // 連想配列 ['キー'] = 値

//ドット記法
abj0.name = '太郎'; // 連想配列 . キー = 値
                    (オブジェクト.プロパティ)

//出力
console.log(obj0); //{name:'太郎',age:21}
```

※配列と同様にブラケット記法が使用できるが、ドット記法も使用できる。  
そのため、連想配列を「オブジェクト変数」、キーを「プロパティ」と呼ぶ場合もある。  

### 2.リテラル
```js
let obj0 = {}; //要素をもたない空の連想配列  

// 要素の追加  

obj0['age'] = 21; // 連想配列 ['キー'] = 値
abj0.name = '太郎'; // 連想配列 . キー = 値
console.log(obj0); //{name:'太郎',age:21}

※上記コードは1行でも表現できる

let obj0 = {name:'太郎',age:21};
console.log(obj0); //{name:'太郎',age:21}

```

> [!WARNING]
> 配列と同様、連想配列を格納する変数を「const」で宣言してもキーの追加や上書きは可能である。  
> 　→ キー自体は定数ではない。  
> 　→ 「定数そのもの」への代入は不可。
>
> ```js
> let obj2 = {name:'太郎',age:21};
> obj2['name']= '次郎';
>console.log(obj2); // 〇{name:'次郎',age:21}
> obj2 = {name:'三郎',age:18}; //✕
> ```

## ★複雑なオブジェクト
オブジェクトの値には、配列や別のオブジェクトを指定することも出来る。  
アプリケーションのデータの格納先としてオブジェクトを使う場合には、通常は［p.072］5-10.jsのような複雑な構成になる。  

オブジェクト全体としては複雑であるが、個々のプロパティの値は単なる数値や文字列、配列、オブジェクトである。  
１つずつ取り出したり、if文で条件分けしたりして処理していけばよい。
