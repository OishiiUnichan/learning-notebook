## 【HTMLの要素の分類】
※旧仕様ではタグを2要素に大別していた。  
　→　「ブロック要素」、「インライン要素」  
新仕様では上記の分類ではなく、「コンテンツモデル」と呼ばれる7つのカテゴリに分類している。  
　→　HTML要素は1つまたは複数のカテゴリに分類される。ただし、どのカテゴリにも属さない要素もある。

なお、旧仕様の分類は、新仕様の分類を理解するうえで有用であるため、用語自体は廃止されているが、ここで紹介しておく。

<hr>

### 1.ブロック要素
見出し・段落・表など、文書を構成する基本となる要素。  
　→　1つのブロック（かたまり）として認識される。  
　→　ブラウザでは前後に改行が入る。  
［例］  
　　h1、p、table、ul、ol、dl　など  
　　区画作成用のタグ：`<div>`　← CSS、JS用のタグ

### 2.インライン要素
文章の一部として扱われる。  
　→　ブラウザでは前後に改行が入らず、文章の一部として表示される。  
［例］  
　　a、img、br　など  
　　範囲選択用のタグ：`<span>`　←　CSS、JS用のタグ


#### ［表2.3］
- コンテントのサイズ（width）  
    高さを内容によって自動的に決めたい場合、`height:auto;`のように記述する。  
　→ autoは省略可能

- 余白、緩衝帯（padding、margin）  
  プロパティの値：上、右、下、左の順に指定
    - 値が１つ：上下左右を指定
    - 値が２つ：上下、左右を指定
    - 値が３つ：上、左右、下を指定
    - 個別指定も可能：top、bottom、left、right

#### ［表2.4］
- 境界線（border）  
    borderの値：太さ、種類、色の順に指定  
    種類）
    - none：非表示（色が重なる場合、他の値を優先）
    - hidden：非表示（色が重なる場合、こちらの値を優先）
    - solide：1本線
    - double：2本線
    - groove：立体的に窪んだ線
    - ridge：立体的に隆起した線
    - inset：上と左が暗く、下と右が明るく、窪む
    - outset：上と左が明るく、下と右が暗く、隆起する
    - dash：破線
    - dotted：点線
