## 1.HTML操作

［例］6-9.html/6-9.js

```js
jQ
$(function() {
	$('#msg').html('スタートしました。');
});

---

JS
//innnerHTML
document.addEventListener('DOMContentLoaded', function() {
    // id="msg" の要素を取得して変数 msg に入れる
    let msg = document.getElementById('msg');

    // textContent を使って文字を書き換える
    msg.textContent = 'スタートしました。';
});

---

//textContent
document.addEventListener('DOMContentLoaded', function() {
    // id="msg" の要素を取得して変数 msg に入れる
    let msg = document.getElementById('msg');

    // innerHTML を使って、太字のタグを入れて書き換える
    msg.innerHTML = '<strong>スタートしました。</strong>';
});
```

## 3.イベント処理［p.091］

［書式］

```js
$(function(){
    $('セレクタ').on('イベント名', 無名関数 ()
});
```

［JSとの比較］

```js
要素オブジェクト.addEventListener("イベント名", 無名関数);
```

- イベント名：発生するイベントを指定
- 無名関数：イベント発生時に実行したい処理を記述
