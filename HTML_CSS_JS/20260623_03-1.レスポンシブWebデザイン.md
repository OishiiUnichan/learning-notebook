## レスポンシブWebデザイン
ユーザビリティを確保しながら、様々な端末や機器のサイズに対応してWebページをうまく描画するためのWebデザインの手法である。  
　→　コンテンツをタブレット、スマホ、テレビ、腕時計のどれで表示しても自動的に画面に合わせることが可能になる。

### ★端末の画面サイズとWebページの表示サイズの関係
［p.038］  
画面解像度：端末の実際の画面の広さ（単位：px）  

> ［例］  
> PC：1920px x 1080px  
> スマホ：2532px x 1170px  

［？１］物理的な端末サイズはPC＞スマホなのに、なぜpx数はスマホの方が大きいのか？  
　→　px数とは：画面を構成している最小サイズの粒（四角）のことで、その1粒を1pxと呼ぶ。

［回答］1pxの大きさは具体的に決まっていない。従来の1px内にもっと細かな表示が出来るようになっている。

> [!NOTE]
> 従来の1px内に表示する倍率を「デバイスピクセル比（DPR）」と呼ぶ。  
> 端末ごとに数値が異なるため、端末サイズにピクセル数が比例しないことになる。

［？２］異なる端末で表示に差が生じないように、複数のピクセルで構成する<ins>１つの疑似的なピクセル（＝CSSピクセル）</ins>を設定する。  
　→　CSSピクセル：Webページのサイズを画面の解像度のピクセルではなく、CSSピクセルをさいようすることにより、デバイスピクセル比が変わっても表示のサイズを一定に保つことができるようになる。

  ```HTML
  <meta name="viewport" content="width=device-width, initial-scale=1">
  ```
  この記述をhead要素に入れることにより、端末のブラウザは表示サイズとして画面解像度のピクセルではなく、CSSピクセルを参照するようになる。
