```java
package code16_02_01;

import java.util.ArrayList;
import java.util.Iterator;

public class Main {

    public static void main(String[] args) {
        // ① リストの準備
        ArrayList<String> fruits = new ArrayList<>();
        fruits.add("apple");
        fruits.add("banana");
        fruits.add("cherry");

        // ② イテレータを取得
        Iterator<String> it = fruits.iterator();

        // ③ 要素の取り出し（ループ処理）
        while (it.hasNext()) {
            String fruit = it.next();
            System.out.println(fruit);
        }
    } // mainメソッドの閉じカッコ
} // Mainクラスの閉じカッコ
```

## ArrayListとLinkedListの違い

---

### 構造のイメージ

**ArrayList**

```
インデックス: [0]    [1]     [2]
              apple  banana  cherry
              メモリ上に連続して並んでいる
```

**LinkedList**

```
apple  →  banana  →  cherry
  ↑次の要素への「矢印（参照）」を持っている
```

---

### 得意・不得意

| 操作 | ArrayList | LinkedList |
| --- | --- | --- |
| **取得** `get(i)` | ✅ 速い | 🐢 遅い |
| **末尾に追加** `add()` | ✅ 速い | ✅ 速い |
| **途中に挿入・削除** | 🐢 遅い | ✅ 速い |

---

### なぜそうなるの？

**ArrayListの取得が速い理由**

```
get(2) → インデックスで直接アクセスできる
[apple][banana][cherry]
                 ↑ 一発でアクセス
```

**ArrayListの挿入が遅い理由**

```
index1に挿入する場合、後ろを全部ずらす必要がある
[apple][banana][cherry]
        ↓
[apple][NEW][banana][cherry]  ← ずらす処理が発生
```

**LinkedListの挿入が速い理由**

```
矢印の向き先を変えるだけでOK
apple → banana → cherry
        ↓
apple → NEW → banana → cherry
  矢印を付け替えるだけ！
```

**LinkedListの取得が遅い理由**

```
get(2)の場合、先頭から順番にたどる必要がある
apple → banana → cherry
  1       2        3   ← 順番にたどらないといけない
```

---

### どちらを使うべき？

| 状況 | 使うべきリスト |
| --- | --- |
| 取得・参照が多い | **ArrayList** |
| 途中への挿入・削除が多い | **LinkedList** |
| とりあえず迷ったら | **ArrayList** |

---

### まとめ

```
ArrayList   → 取得が速い・挿入削除が遅い
LinkedList  → 取得が遅い・挿入削除が速い

迷ったら → ArrayList で問題ない
```

> 実務でも**ArrayListが使われることがほとんど**です。LinkedListが必要になる場面は限られています！
