# 8.3 クラス定義による効果

subject: Java
day: 2026年4月23日
memo: インスタンスの概念

---

1. 定義したクラス（設計図）に基づいて、インスタンス（モノ）が生成できる
2. 生成したインスタンスを入れる専用の変数（箱）の型が利用できる
    
    →現実世界で例えると、同じ設計図から製造された複数の同一製品は専用の箱に入れて他の製品と区別して取り扱う。
    

［例］

野球のバット、テニスラケットなどはそれら専用のケースに入れて持ち運びする。

テニスラケットの収納ケースに野球のバットは入れないのと同じこと。

※クラスを定義すれば、Javaで利用可能な型（クラス型）の種類が増えることになる。

- インスタンスの取り扱いは、リテラルの場合と同様、変数に入れて利用する
    
    →同じクラス（設計図）で生成されたインスタンス（モノ）を変数名（箱の名前）で区別するため。
    
    ［例］
    
    小学生の運動靴の持ち運びのように、靴入れ専用の袋に各自の名前を記入して他者と区別する。
