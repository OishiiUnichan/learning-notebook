# 式評価：計算処理(p716.付録C.3)

３つの原則に従って処理する

**①置換の原則：式を計算結果に置き換えながら処理を進めていく**

**②優先順位の原則：演算子によって処理の優先順位が定められている**

a=5+2*5　←a=5+(2*5)のため……
a=5+10
a=15

※式のグループ化
　式を（）で囲み、グループにすることでその部分の演算を他より先に実行できる

**③結合規則の原則：優先順位が同じグループに属する演算子の場合、処理する方向が定められている**

a=b=c
→a=(b=c)←（）が先に処理
→b=c,a=b

```jsx
桃＝果物＝梨
先に最終結果の「果物＝梨」を処理する
果物＝梨、桃＝果物
```

### １）算術演算子：四則計算を行う演算子

- 優先順位：＊、／、％＞＋、ー
- 結合規則：どちらも左→右に処理（評価）される

※整数除算の結果は整数（商）になる
　9/2=4.5　ではなく　9/2=4　余り1
　もし、小数で結果を出したい場合には、片方を小数表記する
　9.0/2=4.5
商はまた、剰余が負にならない最大の自然数としても定義される

※＋演算子は文字列の連結でも適用
　→足せるものは足す、足りないものは連結

### 代入演算子）変数に値を代入する演算子

- 優先順位：演算子の中で最も低い
- 結合規則：右→左へ処理

※＝演算子は等号ではなく、代入の操作
※演算を行いながら代入する演算子もある←複合代入演算子
　→変数の値更新でよく使われる
　例）＋＝
　a+=2　と　a=a+2は同じ

### インクリメント（＋＋）／デクリメント（ーー）

1のみ増減させる演算子

- 優先順位：演算子の中でもっとも高い
- a++ + 50 （（演算子）後置インクリメント）：左→右に評価
「**今の値を先に使ってから**、後で1を足す」 という動きをします。

手順1： 今の a（10）を計算に使う。 10 + 50 = 60
手順2： その後、a を 11 に増やす。
結果： 計算結果は 60
- ++a + 50 （（演算子）前置インクリメント）：右→左に評価
「**先に1を足してから**、その値を使って計算する」 という動きをします。

手順1： 先に a を 11 に増やす。
手順2： 増えた後の a（11）を計算に使う。 11 + 50 = 61
結果： 計算結果は 61

どちらの式でもaの値は更新されているのでa=11ではある
