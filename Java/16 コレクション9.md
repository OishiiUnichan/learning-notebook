Javaのコレクションフレームワークにおける「Map（マップ）」について解説します。

これまでに学習した「配列」や「List」が値を一列に並べて管理するのに対し、Mapは「2つの値をセット」にして管理する非常に便利な道具です。

---

## 1. ペアを格納するデータ構造（キーと値）

Mapは、「キー（Key）」**と**「値（Value）」という2つのデータをペアにして格納するデータ構造です 。
よく「辞書」や「電話帳」に例えられます 。

- **キー (Key)**： 検索するための「見出し」です（例：英単語、社員番号）。Map内で重複することはできません。
- **値 (Value)**： キーに紐付いた「中身」です（例：日本語訳、社員名）。こちらは重複しても構いません。

---

### インスタンス化の書き方

## 2. HashMapクラスの利用とインスタンス化

Mapを利用する際、最も一般的に使われるのが **`java.util.HashMap`** クラスです 。

「左側（型）をインターフェースである `Map`、右側（実体）を具象クラスの `HashMap`」にする多態性（ポリモーフィズム）を活かした書き方が定石です 。

```java
// String型のキー と Integer型の値 を持つMapを生成
Map<String, Integer> movieRatings = new HashMap<>();
```

- **`<String, Integer>`**： キーと値、それぞれの型を指定します（ダイヤモンド演算子）。intなどの基本型は使えないため、Integerなどのラッパークラスを指定します 。

---

## 3. Mapの中身を1つずつ取り出す

Mapには、Listのような「0番目、1番目」という添え字（インデックス）の概念がありません 。 そのため、中身をループで取り出すには工夫が必要です。最も一般的なのは **`keySet()`** メソッドを使う方法です。

### 全要素を取り出すコード例

```java
// データの追加（putメソッドを使用）
movieRatings.put("千と千尋", 5);
movieRatings.put("リング", 4);

// 1. すべての「キー」をセット（集合）として取り出す
Set<String> keys = movieRatings.keySet();

// 2. 拡張for文で、キーを1つずつ使って「値」を取り出す
for (String key : keys) {
    int rating = movieRatings.get(key); // キーを渡して値（評価）を取得
    System.out.println(key + "の評価は" + rating + "です");
}
```

## 💡 講師からのヒント

以前、HashSetの学習時に「重複を許さない」という特徴を学びましたよね 。 Mapの「キー」も内部的にこのSetの仕組みを使っているため、**同じキーで `put` しようとすると、古い値が新しい値で上書きされる**  という性質があります。

```java
package code16_07;

import java.util.HashMap;
import java.util.Map;

public class Main {
	
	public static void main(String[] args) {
		Map<String,Integer> prefs=new HashMap();
		prefs.put("京都府", 255);
		prefs.put("東京都", 1261);
		prefs.put("熊本県", 181);

		int tokyo = prefs.get("東京都");
		System.out.println("東京都の人口は"+tokyo);

		prefs.put("熊本県", 182);
		int kumamoto = prefs.get("熊本県");
		System.out.println("熊本県の人口は"+kumamoto);
		
		int kyoto = prefs.get("京都府");
		System.out.println("京都府の人口は"+kyoto);

		
		prefs.remove("京都府");

		for (String key : prefs.keySet()) {
			int value = prefs.get(key);
			System.out.println("今登録されている"+key + "の人口は、"+ value);
		}
		
	}

}

```
