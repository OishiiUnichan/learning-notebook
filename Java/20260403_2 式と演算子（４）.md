# 命令実行の文

処理内容は「メソッド」で管理されている。
その「メソッド」は「クラス」で管理されている。
さらに、その「クラス」は「パッケージ」で管理されている。

```jsx
package myproject.study; // ① パッケージ（一番外側の箱）

public class Greeter { // ② クラス（二番目の箱）

    // ③ メソッド（具体的な「処理」を書く最小単位の箱）
    public void sayHello() { 
        System.out.println("こんにちは！");
    }
}
```

**②Mathクラス（[汎用］数値処理）**のrandomメソッドを利用する

　→random()メソッドは0以上1未満の『**小数**』を発生する。

※整数乱数を発生させる場合は、適当に整数倍して、int型にキャスト（=変換）する

```java
// 0.0 以上 1.0 未満の乱数（例: 0.552...）
double d = Math.random(); 

// 10倍して 0.0 以上 10.0 未満にする（例: 5.52...）
double d10 = d * 10; 

// 【キャスト】int型に強制変換（小数点以下を切り捨てる）
int num = (int)d10; 

System.out.println(num); // 結果は「5」になる

int randomNumber = (int)(Math.random() * 10); // 0から9までの整数
```
