# 継承とコンストラクタ

子インスタンスの多重構造が構築される過程

①親インスタンスの生成（親クラスの情報がメモリに展開）

②子インスタンスの生成（子クラスの情報がメモリに展開）

③子コンストラクタの実行（newされた直後に自動実行）　←　親コンストラクタが明示されてなくても「super()」暗黙的に**先に動作する**

［注意］上記は「引数のない」コンストラクタの動きである［👇code10-10］

## 引数のあるコンストラクタの場合

- 実引数を渡す作業指示は「子」コンストラクタに記述するしかない
- ［規則］すべてのコンストラクタは、その『先頭』で必ず継承元クラスのコンストラクタを呼び出さなければならない
    
    →継承元クラスのコンストラクタの呼び出し（依頼）
    
    ```java
    ［書式］
    super(実引数リスト)；
    ［参考］
    this（実引数リスト）；　←自身のクラスの別コンストラクタの呼び出し
    ```
    
    →上記は絶対的なルールであるため、呼び出しが記述されていなくてもコンパイラによって自動的に挿入されて実行される。
    
    ※呼び出しが明記されていない場合は「引数なし」で継承元のクラスのコンストラクタを呼び出すことになる。その場合、継承元のクラスに引数無しのコンストラクタがないとエラーになる［参照：code10_11］
    

［対策］

1. 継承を**利用**する（継承先のクラス作成する）側の立場［１０章視点］
    
    継承先のクラスのコンストラクタにおいて、継承元のクラスのコンストラクタの呼び出しを明記する。
    
2. 継承を**準備**する（継承元のクラスを用意する）側の立場［１１章視点］
    
    継承元のクラスのコンストラクタにおいて、引数なしのコンストラクタを用意しておく。
