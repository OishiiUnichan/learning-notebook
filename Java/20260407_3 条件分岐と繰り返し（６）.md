# 構造化定理

順次・分岐、繰り返しの制御構造を組み合わせれば、どんな複雑なプログラムでも作成可能。

→　ある制御構文の中に別の制御構文を含めることができる。

→　このような多重構造を「入れ子」「ネスト」という。

例２）繰り返し構文に分岐構文をネスト

→　２つの中断方法

①**break文：全体の繰り返しを「ストップ」する**

例）探索プログラム（多次元方程式の解etc）など

②**continue文：現在の繰り返しを「スキップ」する**

例）抽出プログラム（数列から５の倍数を取り出すetc）など

→　繰り返し処理を続けることで無限ループさせる
