# 8.4 インスタンスの利用方法

subject: Java
day: 2026年4月23日
memo: インスタンスの利用方法、new演算子

---

オブジェクトを設計したクラスに基づいて、プログラムを実行するクラス（main()メソッドを含むクラス）を作成する

1. インスタンスを作成し、
2. 生成したインスタンスを動かす

※Eclipseで物語（神様）クラスを作成する場合、必ず登場人物クラスを**事前**に用意しておくこと。

事後だとEclipseの機能でつじつまが合うようにimport文が自動挿入されるため。

①-1 インスタンスの作成［コード8-11］

［書式］

`クラス型　変数名　＝　new　クラス名（）；`

```
Hero h = new Hero();
　宣言　　インスタンス化　
　　　　↑初期化
```

1. この設計図をもとに、
2. newで新しくインスタンスを生み出す
3. 生み出したインスタンスを変数に格納

①-2 インスタンスのフィールド利用

［書式］

`変数名.フィールド名＝値`

値をどこの属性に格納するのか

```
h.name="ミナト";
```

②インスタンスのメソッド呼び出し　→指示を出す

［書式］

`変数名.メソッド（）；`

どこの操作を呼び出すのか

```
h.shit(5)
「勇者」に「５秒座れ」と指示を出す。
```

### 手続き型プログラミングの利用

- main()メソッドに下記の文を記述
    1. 変数宣言の文　←最初にまとめておく
    2. 計算の文　←計算の文と命令実行の文を
    3. 命令実行の文　←互い違いに記述していく

### ★オブジェクト指向プログラミングの利用

1. オブジェクト指向の設計（登場人物のクラス）
    
    属性フィールド宣言操作メソッド宣言
    
2. オブジェクトの操作（物語（神様））のクラス
    
    インスタンスの作成→new演算子を使用
    
    　　　　　　　　　→「変数名.フィールド名」と記述して使用
    
    インスタンスの操作→「変数名.メソッド名」と記述して使用
