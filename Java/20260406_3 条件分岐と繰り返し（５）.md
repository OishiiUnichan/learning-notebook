# for文

繰り返す回数を指定して、繰り返し処理を実行する

```java
for (１．初期化処理；２．繰り返し条件；３．繰り返し回数の更新)

１．初期化処理：最初に1回だけ実行される文（おまじないみたいなものか？）
２．繰り返し条件：指定した回数を条件とする
３．繰り返し回数（ループ変数）の更新
```

### ［補足１］ループ変数

繰り返し回数を格納する変数

#### ルール

①変数名は自由指定できるが、慣習的にi以降の１文字が使用される
②ループ変数のスコープは、ブロックの中でのみ有効
　※複数のfor文を使用しても、for文の処理が完了していたら同じ変数名は使用可能

例）１つめのfor文
`for(int i = 0; i <10; i++){[ブロック]}`

２つめのfor文

`for(int i = 0; i <10; i++){[ブロック]}　　　←変数名を変えてもいいし、`

`for(int i = 0; i <10; i++){[ブロック]}　　　←変数名を変えなくてもよい`

### ［補足２]for文の３つの要素について

for文の（）内の３要素は、処理の流れの中で記述されていたら、必ずしも（）内でまとめる必要はない。
※ただし、セミコロンは省略できない
　→コンパイラが要素の省略か不足か判断がつかないため

```java
例）
for(; i<10; i++)　←初期化の省略
※繰り返し条件を省略すると無限ループになるので到達不能コードとなる

-----
		for(;i<3;) {　//ループ変数を初期化しない
			System.out.println("\n現在"+ (i++ +1) + "週目→");			
		}//更新処理をまとめる

		System.out.println("\n最終回数は"+ i);	
		//↑ブロック外でも変数は使えるが、無限ループの場合はエラーとなる

}
```
