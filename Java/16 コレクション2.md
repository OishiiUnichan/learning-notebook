## ArrayListの主要メソッド一覧

---

### 📥 要素を格納する

### `add()`

```java
points.add(10);        // 末尾に追加
points.add(1, 99);     // index1の位置に挿入
// [10, 99, 80, 75]
```

### `set()`

```java
points.set(0, 999);    // index0の要素を999に上書き
// [999, 80, 75]
```

> `add`は**追加**、`set`は**上書き**
> 

---

### 📤 要素を取り出す

### `get()`

```java
int x = points.get(0);  // index0の要素を取得
System.out.println(x);  // → 10
```

---

### 🔍 リストを調査する

### `size()`

```java
int n = points.size();
System.out.println(n);  // → 3（要素数）
```

### `isEmpty()`

```java
points.isEmpty();  // 空ならtrue、要素があればfalse
```

### `contains()`

```java
points.contains(80);   // 80が含まれていればtrue
points.contains(999);  // なければfalse
```

### `indexOf()`

```java
points.indexOf(80);  // 80が何番目か → 1
                     // 存在しない場合は → -1
```

---

### 🗑️ 要素を削除する

### `clear()`

```java
points.clear();  // 全要素を削除 → []
```

### `remove()`

```java
points.remove(1);      // index1の要素を削除
points.remove(Integer.valueOf(80));  // 値80の要素を削除
```

> ⚠️ `remove(80)` と書くと**index80**として解釈されるので、値で削除したい場合は `Integer.valueOf(80)` が必要
> 

---

### 全体イメージ

```java
ArrayList<Integer> points = new ArrayList<>();
points.add(10);   // [10]
points.add(80);   // [10, 80]
points.add(75);   // [10, 80, 75]

points.get(1);      // → 80
points.size();      // → 3
points.contains(80);// → true
points.indexOf(75); // → 2
points.set(0, 99);  // [99, 80, 75]
points.remove(1);   // [99, 75]
points.clear();     // []
points.isEmpty();   // → true
```

## ダイヤモンド演算子 `<>`

---

### そもそも何？

`<>` の形が菱形（ダイヤモンド）に見えることから**ダイヤモンド演算子**と呼ばれます。

**Java 7から導入**された省略記法です。

---

### 比較してみる

```java
// 旧来の書き方
ArrayList<Integer> points = new ArrayList<Integer>();

// ダイヤモンド演算子を使った書き方
ArrayList<Integer> points = new ArrayList<>();
```

右辺の `<Integer>` が `<>` に省略できます。

---

### なぜ省略できるの？

左辺で `ArrayList<Integer>` と宣言しているので、

Javaが右辺の型を**自動で推論**してくれるからです。

```java
ArrayList<Integer> points = new ArrayList<>();
//       ^^^^^^^^                           ^^
//    ここで型が決まってる          だから省略OK
```

これを**型推論**といいます。

---

### もっと複雑な型だと省略の恩恵が大きい

```java
// 省略なし（長い！）
HashMap<String, ArrayList<Integer>> map = new HashMap<String, ArrayList<Integer>>();

// ダイヤモンド演算子（スッキリ！）
HashMap<String, ArrayList<Integer>> map = new HashMap<>();
```

---

### まとめ

|  | 内容 |
| --- | --- |
| 記号 | `<>` |
| 意味 | 右辺の型を左辺から推論して省略 |
| 導入 | Java 7以降 |
| メリット | コードが短くなり、可読性が上がる |

> 現代のJavaでは `new ArrayList<>()` と書くのが**一般的なスタイル**です。
>
