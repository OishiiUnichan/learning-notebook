※ オブジェクト指向の３大概念（［P.278］［図7-18 ]）

|  | 炊飯器に例えると… |
| --- | --- |
| カプセル化（１３章） | 直接温度管理（設定）できないようにする。
温度管理は保温機能や炊飯機能で行う。 |
| 継承（１０，１１章） | 炊飯器は炊飯のみだが、保温機能を付け加えると炊飯ジャーになる。 |
| 多態性（１２章） | 「炊飯」ボタンを押すと仕込まれているメニューによって、
さまざまな調理（炊き分け、パンを焼くなど）が可能になる。 |

### 〇三大機能

- カプセル化：柔軟性・保守性の向上
- 継承：再利用・拡張性の向上
- 多態性：再利用・拡張性の向上
