**if- else if - else構文**

①複数記述可能

→　上から条件判定していく

例.

```java
if(h >= 170){
	size = "L";
	}
	else if(h >= 155){　　　//170未満に決まってる
		size = "M"
		}
		
	else{...}
```

×ｈ　＜１７０　＆＆　ｈ　＞＝　１５５　//わざわざ指定しない
（１）修正箇所は少なくする
（２）数学的表現と混同しない

```java
int score = 75;

if (score >= 90) {
    // 条件A：90点以上　＝がついてるので90を含む
    System.out.println("評価：秀");
} 
else if (score >= 70) {
    // 条件B：70点以上（90点未満の人だけがここに来る）
    System.out.println("評価：良");
} 
else if (score >= 50) {
    // 条件C：50点以上（70点未満の人だけがここに来る）
    System.out.println("評価：可");
} 
else {
    // それ以外（50点未満）
    System.out.println("評価：不可");
}

System.out.println("判定終了");
```

# 【switch構文】

変数の値の大小関係の比較（条件式）ではなく、（if構文：条件分岐）

**変数の値自体で処理の流れを決める構文**

```java
java12以降

switch (変数) {
    case [値],[値] -> {
	    処理文;
	    };
    case [値] -> {
	    処理文;
	    };
    case [値] -> {
	    処理文;
	    };
    default -> {
	    処理文;
    };
}
```

```java
伝統的な記法

switch (変数) {
    case [値]:
    case [値]:
	    処理文;
	    break;
    case [値]:
	    処理文;
	    break;
    case [値]:
	    処理文;
	    break;
    default:
	    処理文;
    }
```

伝統的な記法について…
　教科書の書き方「ｃａｓｅ１，２：」の1行で使うことはできない。
　改行してラベルを並べること

①変数の型）整数値、文字列、文字

×　Long型：32bit環境に対して最適化されており、旧プログラムの動作保証のため未対応

×　小数：計算誤差が発生し、正しい値にならない場合がある

×　真偽値：switch文ではなく、if文を使用すればよい

②ラベル）caseラベルに変数の値を指定する（case：）

なお、該当する値がない場合は、defaultラベルを指定する
末尾は区切りのコロンをつける（：）
文末のセミコロンではない
※ラベルに処理ストッパーの役割はない

③break文）switch文を抜ける（＝処理を終了させる）場合には、break文が必要

※break文がなければ、順次構造に従い次のラベルの処理文が実行される。

ただし、うまく活用する例もある
例）共通処理を行う

```java
→クイズで表記ゆれを考慮して正解にする
　case “りんご”：
　case “リンゴ”：
　case “林檎”：
　　System.out.println(”正解です”);
```

例）確立を調整する

```java
→大吉よりも吉の出る確率を上げる
	case 2:
	case 3:
	case 4:
		System.out.println(”吉です”);
```

## ［ 新版］【Java12】

１）アロー演算子

case/defaultラベルを「ラベル　値　ー＞｛処理文｝」の形式で表す

アロー演算子ではラベル末尾のbreak文は不要となる

２）case値の複数列記：旧版表記では不可

caseラベルにカンマ区切りで値を列記できる

旧版のように、caseラベルを列記する必要はない

```java
java12以降

switch (変数) {
    case [値],[値] -> {
	    処理文;
	    }
```

```java
伝統的な記法

switch (変数) {
    case [値]:
    case [値]:
    }
```

３）switch式

switch文が式として表現できる。

→　処理文の中でswitch文を記述できる。
　　なお、switch式では値を返さないパターンがあってはいけないので、デフォルトラベルは省略不可。

［参考］　同様の機能はif文にも存在する

三項条件演算子（？：）

型　変数名　＝　条件式？真の値：偽の値；

```java
String s = age > 18 ? “成人”：”未成年”；
```

変数ageの値が18より大きい場合、変数sには「成人」が代入され、それ以外の場合には「未成年」が代入される
