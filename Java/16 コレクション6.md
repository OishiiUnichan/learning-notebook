```java
package code16_02_02;

import java.util.Iterator;
import java.util.LinkedList;
import java.util.List;

public class Main {

	public static void main(String[] args) {
		// ① List<String>型 の 変数 names を作る
		// ② 右側は LinkedList の実体を作る
		List<String> names = new LinkedList<String>();

		// さっき決めた「変数名 names」に対して追加する
		names.add("湊");
		names.add("朝香");
		names.add("菅原");

		// イテレータも String型 に合わせる
		Iterator<String> it = names.iterator();
		while (it.hasNext()) {
			String n = it.next();
			System.out.println(n);
		}
	}

}

```

## `List<String> names = new LinkedList<String>();` の解説

---

### この書き方の構造

```java
List<String>  names  =  new LinkedList<String>();
  ↑左辺                      ↑右辺
「インターフェース型」で     「実際のオブジェクト」は
受け取っている               LinkedList
```

---

### ListとLinkedListの関係

```
List（インターフェース）
  ├── ArrayList
  └── LinkedList   ← 今回はこれ
```

`List` は**設計図（約束事）**、`LinkedList` は**その実装**です。

---

### なぜ左辺をListにするの？

後から実装を**簡単に切り替えられる**からです。

```java
// LinkedList → ArrayListに変えたい場合
// 右辺だけ変えればOK！
List<String> names = new LinkedList<String>();  // 変更前
List<String> names = new ArrayList<String>();   // 変更後
//  ↑左辺はそのまま
```

左辺を `LinkedList<String>` で宣言してしまうと…

```java
LinkedList<String> names = new LinkedList<String>();
// 後でArrayListに変えたくなったら左辺も変える必要がある
// さらに他の場所でも型を使っていたら全部変える羽目に…
```

---

### 使えるメソッドについて

```java
List<String> names = new LinkedList<>();

names.add("湊");    // ✅ Listのメソッドなので使える
names.get(0);       // ✅ 使える
names.size();       // ✅ 使える

names.addFirst("X"); // ❌ LinkedList専用メソッドは使えない
```

> 左辺を `List` にすると、**Listが持つメソッドしか使えない**点に注意
> 

---

### まとめ

```
List<String> names = new LinkedList<String>();
    ↑                       ↑
インターフェース型で      実体はLinkedList
受け取ることで
後から差し替えやすくなる
```

|  | 説明 |
| --- | --- |
| `List` | インターフェース（約束事・設計図） |
| `LinkedList` | Listを実装したクラス |
| 左辺をListにする理由 | 後から実装を切り替えやすくするため |

> この書き方は**プログラムの柔軟性を高める**Javaの定番スタイルです！
