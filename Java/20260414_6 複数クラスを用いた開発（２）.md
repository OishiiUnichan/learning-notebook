# 名前空間

プログラムをクラスで部品化すると分業しやすいメリットがあるが、クラス名が衝突するデメリットもある←使える名前の数（名前空間）には限りがある

Javaでは原則、識別子の名前の衝突は許されていない

→　クラス、メソッド、変数など開発者が自由に名前をつけることができるプログラムの構成要素

**ただし**

クラス名に限っては、パッケージが異なれば同じ名前が使用可能になる

→　完全限定クラス名で区別できるため

#### 注意

パッケージ名が衝突すると、完全限定クラス名(FQCN)でも区別できなくなる

#### 回避策

 推奨 インターネットのアドレスを前後逆順にしてパッケージ名に使用する

社内の衝突は社内で解決できるため、社外の衝突を避けることが大事。

ex) google.com → com.google

print.class.int(1,2,3);←これだと衝突するかも！

なので…

com.google.class.int(1,2,3);
