Javaのコレクションフレームワークにおける「Set（セット）」について解説します。

`java.util.HashSet` は、数学の「集合」をイメージすると非常に分かりやすいクラスです。リスト（List）とは異なる独特の性質を持っていますので、ポイントを絞って説明します。

---

## 1. HashSet の主な特徴

`HashSet` は、大量のデータの中から「ある値が含まれているか」を高速に判定するのに適したクラスです。

- **重複した値を格納しようとすると無視される**
Setの最大の特徴です。同じ値を `add()` しようとしても、2回目以降は無視されます 。
    
    > **例：** 映画タイトル「リング」を2回追加しても、セットの中には1つしか存在しません。
    > 
- **set() / get() がない** 
Listのように「3番目の要素を取り出す（get）」や「5番目を書き換える（set）」という概念がありません 。
要素を指定して取り出す機能がないため、中身を確認するにはループで回す必要があります。
- **要素は順不同で取り出される**
 `HashSet` は、中身を保存する際の順番を一切保証しません 。
「赤、青、黄」の順で保存しても、取り出すときには「黄、赤、青」になる可能性があります 。

---

## 2. Set の実装バリエーション

Setには、用途に合わせていくつか種類があります。

| **クラス名** | **特徴** | **順序のルール** |
| --- | --- | --- |
| **HashSet** | 最も一般的で高速 | **順序はバラバラ** |
| **LinkedHashSet** | 入れた順番を記憶する | **追加した順**に並ぶ |
| **TreeSet** | 値の大きさで整列する | **自然順序付け**（昇順など） |

### 自然順序付け（TreeSet）

`TreeSet` を使うと、要素が自動的に並べ替えられます。これを「自然順序付け（Natural Ordering）」と呼びます。

- **数値：** 小さい順（1, 2, 3...）
- **文字列：** 辞書順（あ, い, う... / A, B, C...）

---

## 3. 中身を取り出す方法

`get()` が使えないため、中身をすべて表示するには以下の方法をとります。

### 拡張for文を使う方法

```java
Set<String> colors = new HashSet<>();
colors.add("赤");
colors.add("青");

for (String s : colors) {
    System.out.println(s); // 順不同で表示される
}
```

### Iterator（イテレータ）を使う方法

「次があるか？」を確認しながら1つずつ取り出す方法です 。

- `it.hasNext()`：次のデータがあるか判定 。
- `it.next()`：実際のデータを取り出す。

```java
package code16_04_01;

import java.util.HashSet;
import java.util.Iterator;
import java.util.Set;

public class Main {

	public static void main(String[] args) {
		Set<String> colors = new HashSet<>();
		colors.add("赤");
		colors.add("青");
		colors.add("黄");

		// ①Iterator（案内役）を呼び出す
		Iterator<String> it = colors.iterator();

		// ②「次があるか？」を確認しながらループする
		while (it.hasNext()) {
			String s = it.next(); // 中身を取り出す
			System.out.print(s);  // まず名前を出す

			// ③ここがポイント！「さらに次に値があるか」を確認する
			if (it.hasNext()) {
				System.out.print("→"); // 次がある時だけ矢印を出す
			}
		}
	}
}
```

```java
Set<String> colors = new HashSet<>();
colors.add("赤");
colors.add("青");
colors.add("黄");

int count = 0; // 何個目かを数えるカウンター
int total = colors.size(); // 全体の個数（3）

for (String s : colors) {
    count++; // 1つ処理するたびに増やす
    System.out.print(s);

    // 「今の処理数」が「全体の数」より小さい時だけ矢印を出す
    if (count < total) {
        System.out.print("→");
    }
}
```
