## オートボクシングとは

まず、このコードで重要な**前提知識**から整理する。

---

### ① プリミティブ型はObjectではない

Javaには2種類のデータがある。

```java
int x = 123;      // プリミティブ型（ただの数値）
String s = "abc"; // 参照型（Objectの子孫）
```

`Object[]`配列にはObjectの子孫しか入れられないため、**プリミティブ型はそのまま格納できない。**

---

### ② 昔は自作のラッパークラスが必要だった

```java
o[3] = new IntObj(123); // 自分でintを包む箱を作る必要があった
```

`int`をObjectとして扱うために、このような**自作のラッパークラス**が必要だった。

---

### ③ オートボクシングで自動変換される

Java5以降、プリミティブ型とラッパークラスを**Javaが自動で変換**してくれる。

```java
// オートボクシング：int → Integer（自動）
Object o = 123; // コンパイラが自動的に Integer.valueOf(123) に変換

// アンボクシング：Integer → int（自動）
int x = (Integer) o; // 自動的にintの値を取り出す
```

### 主な対応表

| プリミティブ型 | ラッパークラス |
| --- | --- |
| `int` | `Integer` |
| `double` | `Double` |
| `boolean` | `Boolean` |
| `char` | `Character` |

---

### ④ なぜ `IntObj` はJava9から非推奨？

| 時代 | 方法 |
| --- | --- |
| Java5以前 | `IntObj`のような自作ラッパーが必要 |
| Java5以降 | 標準の`Integer`＋オートボクシングで自動化 |

```java
// 現代のJavaではこう書ける
o[3] = 123; // そのまま書くだけでIntegerに自動変換される
```

---

### まとめ

```
オートボクシング  ： int     → Integer （自動でラップ）
アンボクシング    ： Integer → int     （自動で取り出し）
```

> **ポイント：** `IntObj`のような自作クラスを作らなくても、Javaが標準の`Integer`クラスへの変換を自動でやってくれる仕組みが**オートボクシング**。`Object[]`にそのまま`int`値を入れられるのはこのおかげ。
