オブジェクト指向プログラミングにおける開発者の仕事

1. オブジェクトの洗い出し
2. オブジェクトの設計（［属性］と［操作］を定義）
3. オブジェクトを生み出し動かす

一般にオブジェクト指向言語は二つに分類することができる。

1. オブジェクトベース←Self（１９８６年）：職人による一品生産
2. クラスベース←Java(１９９５年)：機会による大量生産

※オブジェクト指向言語の歴史

開発）Simula67→元祖）Smalltak-80（クラスベース）→普及）Java

☆用語の使い分け

|  | 役割 | イメージ |
| --- | --- | --- |
| クラス | 設計図、金型、鋳型 | もなかの金型 |
| オブジェクト | プログラムで動かす対象 | もなかの皮 |
| インスタンス | プログラムで動かす実体 | 餡入りもなか |
