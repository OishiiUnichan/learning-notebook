# 条件式

処理の流れを定める表現式（⇔算術式：算術演算子を使って演算する式）

### ①関係式：関係演算子（比較演算子）を使って表現した式

　　　　　　　オペランド同士の大小関係を表現する演算子
　　　　　　　※等しい：==（×＝：代入演算子）
　　　　　　　　異なる：！＝
　　　　　　　　以上・以下：＞＝、＜＝
　　　　　　　　「＝」は必ず右側にくる

#### →評価結果は真偽値（true or false）になる

**【注意】文字列の比較：演算子ではなく、メソッドで行う**

```java
×　対象の文字列　==　比較する文字列
// 正しい書式
**〇　対象の文字列　　　　　　　　　.equals(比較する文字列)
		↑変数に格納されてもよい　　　　↑文字列に対してのみ使用。それ以外のデータ型は演算子で比較**
```

［ メモ ］

文字列リテラルは、開発者が事前に用意することはできない。利用者が用意する必要がある　→ p.327

ただし、文字列リテラルを作成するための準備を整えておくことはできる。
その準備に、比較するための専用メソッドが用意されている。

→ 内容を比較するメソッド：equals（）

一方、文字列リテラル以外のリテラルは、開発者が事前に用意することができる。
そのため、汎用性のある比較演算子を用意することができる。

→ 存在を比較する演算子：＝＝

```java
public class Main {
    public static void main(String[] args) {
        String s1 = "おはよう";
        String s2 = "おやすみ";

        // メソッド（.equals）を使って比較する
        if (s1.equals(s2)) {
            // 中身が同じならここを通る
            System.out.println("同じ言葉です！");
        } else {
            // 中身が違うので、今回はここを通る
            System.out.println("違う言葉です。");
        }
    }
}
```

```java
int myMoney = 500;  // 自分の所持金
int itemPrice = 500; // アイテムの値段

// 数字は単純なので「==」などの記号（演算子）で直接比べられる！
if (myMoney == itemPrice) {
    System.out.println("ちょうど買えます！");
}

if (myMoney >= 1000) {
    System.out.println("リッチですね！");
}
```

### ②論理式：論理演算子（優先順位に注意）を使って表現した式

→　複数の関係式を使って条件を表現する。

論理積（AかつB）：&&（true：すべての関係式がtrueの場合）
　　　　　　　　　使用例）絞り込みの条件

論理和（AまたはB）：｜｜（true：いずれかの関係式がtrueの場合）
　　　　　　　　　使用例）回答・表記ゆれ

否定（Aではない）：！（条件式の評価を逆転させたい場合）
　　　　　　　　　使用例）否定を強調したい場合
　　　　　　　　　18歳以上ではない　＝　18歳未満

```java
コラム
条件式の短絡評価
	複数の関係式をすべて評価しなくても、ある時点で論理式の評価が決まれば
	残りの関係式の評価は行わない評価の方法
		→　＆、｜を２つ使用すると短絡評価になる
			※＆、｜が１つの場合、すべての式を評価する
```
