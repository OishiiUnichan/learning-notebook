# インスタンスの姿

- 継承先のインスタンスの姿
    
    →二重構造
    
    内側：継承元のインスタンス（親）
    
    外側：継承先のインスタンス（子）
    
- 継承先インスタンスのメソッド呼び出しの動作原理
    1. 継承先のインスタンスのメソッド（差分メソッド）で対応
    2. 継承先のインスタンスに該当するものがなければ、継承元に該当するメソッドで対応
    3. メソッドがオーバーライドされている場合、１と同様にオーバーライドメソッドで対応
        
        →継承元のインスタンスメソッドよりも、継承先のメソッドが優先される。
        
        ※継承先を継承元のメソッドより優先させたい場合、**super**キーワードを利用する
        
        ※this：自身のインスタンス
        
        　super：1つ内側のインスタンス
        
        →superより内側のインスタンスを指すキーワードは用意されていない。要は子から親までしか呼べない。
        
        ```java
        ［例］
        	public class SuperHero extends Hero{・・・}
        	　　　　　　　　 ↑this　　　　　　　↑super
        ```
        
        クラス宣言の「SuperHero」から、親が「Hero」であることはわかるが、Heroの親が存在するかは分からない。
        
        そのため、親の親インスタンスへのアクセスは不可能！
