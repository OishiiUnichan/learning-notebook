# while構文

条件を満たす間、繰り返し処理を実行する。

前置判定　while構文

処理を実行する前に実行するか判定する。（＝一回も実行しない可能性がある）

後置判定　do-while構文

処理を実行した後に、後続するかを判定する（＝１回の実行は保証される）
