# 計算の文とは

変数や値を用いたさまざまな計算処理をコンピュータに行わせるための処理文
※変数に値を代入することも計算の一種

①「オペランド（演算対象／演算記号以外）」と②「演算子（演算記号）」の２要素で構成

## **①オペランド**

- **リテラル**
数値や文字列などの具体的な値。表記方法によってデータ型が決まる
    - 数値系
        - 小数点なし　→　int型（基本）
        末尾にL：Long型として扱える
        - 小数点あり　→　double型（基本）
        末尾にF：float型
        ※末尾にDをつけるとdouble型と明示的に扱える
        
        ```jsx
        int age = 25;
        int型（整数）、age（変数）、25（リテラル）
        double hoge = 33.1;
        double型（小数）、hoge（変数）、33.1（リテラル）
        ```
        

```jsx
メモ
進数：位取り記法
２進数）コンピュータなどのデジタル機器内部で使用
１０進数）現代社会で主に使われている記数法
１６進数）主に４桁の２進数法表記を１桁で表すために使用
```

- **文字系**
    - 一文字（文字）　→　’’で囲む　→　char型、””で囲む　→String型
    - 複数文字（文字列）　→　””で囲む　→String型
    - 真偽値　→　true または false　→boolean型、””で囲む　→String型
    
    ```jsx
    char eto = '馬';
    char型（''で囲む）、eto（変数）、馬（一文字）
    
    String animal = "カモノハシ";
    String型（""で囲む）、animal（変数）、カモノハシ（複数文字）
    
    boolearn 
    
    ```
    

**※エスケープシーケンス**
　¥記号（\）と１文字の組み合わせで特殊な１文字（制御文字）を表現する
　①エスケープ：処理の中止、取り消し
　②シーケンス：順番に並んだ一続きのデータや手順

```jsx
\s	スペース(SPACE)
\t	タブ文字(TAB)
\n	改行(LF)
\"	ダブルクォーテーション("を表示)
\'	シングルクォーテーション('を表示)
\\	バックスラッシュ(\)
```
