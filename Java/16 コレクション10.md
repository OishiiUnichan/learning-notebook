### コメント付きソースコード

```java
package code16_08;

import java.util.ArrayList;
import java.util.List;

// 勇者クラスの定義
class Hero {
    public String name;
}

public class Main {

    public static void main(String[] args) {
        // 1. 勇者インスタンスを生成し、名前に「ミナト」を代入
        // 変数 h には「ミナト」の住所（参照）が入る
        Hero h = new Hero();
        h.name = "ミナト";
        
        // 2. 勇者型を格納できる ArrayList を作成（多態性を利用した宣言）
        List<Hero> list = new ArrayList<Hero>();
        
        // 3. リストに変数 h（住所）を保存する
        // リストの0番目には「ミナトの住所」がコピーされる
        list.add(h);
        
        // 4. 元の変数 h を使って名前を「スガワラ」に書き換える
        // 住所が指し示している先の「実体」が書き換わる
        h.name = "スガワラ";
        
        // 5. リストの0番目からデータを取り出して名前を表示
        // リストに入っている住所の先を見に行くと、すでに「スガワラ」になっている
        System.out.println(list.get(0).name); // 出力結果：スガワラ
    }
}
```

---

### なぜ出力が「スガワラ」になるのか？

以前学習した「本体は1つ、リモコンが2つ」という**参照**の仕組みがここでも働いています 。

1. **実体は1つだけ**： `new Hero()` で生まれた勇者の実体は、メモリ（ヒープ領域）の特定の場所に1つだけ存在します 。
2. **住所を共有している**： `list.add(h)` を実行したとき、リストに「ミナト」という文字が保存されるわけではありません。変数 `h` が持っている「実体の住所（リモコンの設定）」がリストの0番目にコピーされます 。
3. **連動する変化**： 変数 `h` を使って名前を書き換えると、同じ住所（実体）を指しているリスト内のデータも、当然その変化を反映した内容になります 。

「リストに放り込んだら、その時の状態が固定されて保存される」のではなく、「リストに住所をメモしただけなので、本人が変わればリストから見ても変わっている」という感覚で捉えるとスッキリしますね 。
