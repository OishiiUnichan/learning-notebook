# ★拡張for文

**データ構造（配列など）を回すための専用for文**

[ 書式 ]

```java
for （要素の型　任意の変数名：配列変数名）｛
	要素の型の変数を使用した処理；
	｝
```

[ 例 ]

```java
for(int score:scores){ //棚の引き出しから取り出した中身を箱に入れる
	処理文; //箱を使って処理する
	処理文; //箱から中身を取り出せる間、繰り返す
}
```

- 拡張for文）棚の引き出しを順番にすべて中身を使うことが前提

## [ 比較 ]

- 従来のfor文
    
    棚の引き出しを「指定して」中身を使うことが前提
    
    ```java
    for(int i = 0; i<配列変数名.length; i++){
    	配列変数名[i]を使用した処理;
    	}
    ```
    

> **使い分けについて**
拡張for文で書けるなら、必ず拡張for文で書く
> 
> 
> 
> **拡張for文**
> 使い時： 配列のすべての要素を順番に処理したいとき
> メリット： 記述がシンプルで、添え字（i）の数え間違いによるエラーが起きない
> 
> **普通のfor文（必要に応じて使用）
> 使い時：**
> ・特定の範囲だけ処理したいとき（例：後半の3つだけ）
> ・逆順に処理したいとき
> ・要素の中身を書き換えたいとき（scores[i] = 100; など）
> ・現在のインデックス番号（「今、何番目の処理か」）が必要なとき
> 
> **デメリット：** 記述が少し複雑で、i < scores.length などの条件式を書き間違えるリスクがある
> 

```java
public class Main {
    public static void main(String[] args) {
        // 従来のfor文
    	int[] scores = {20,30,40,50,80};
    	for(int i = 0; i<scores.length; i++) {
    		System.out.println(scores[i]);
    	}

    }
}
```

```java
public class Main {
    public static void main(String[] args) {
        // 拡張for文
    	int[] scores = {20,30,40,50,80};
    	for (int value:scores) {
    		System.out.println(value);
    	}

    }
}
```
