# 配列のメリット

△変数：関連ある複数のデータを個々の独立したデータとして扱う

〇ある一定のルールに従って複数のデータを１つの変数に格納して扱う

→　データ構造（４章配列、１６章コレクション）

### 配列

同一種類の複数データを並び順に格納するデータ構造

※[ イメージ ]

変数：箱
配列：棚

引き出し：要素
　　中身）各要素に格納できるデータ型は一種類のみ
　　　　　本棚には本のみ、食器棚には食器のみを補完する

数え方）０番目から数える。管理番号を「添え字（インデックス）」という。
　　　　０，１，２　配列は「３つ」あり、添え字は「２」

#### 配列の書き方

【準備】

Step1　配列変数の宣言（枠の準備）

```java
[書式]要素の型[] 配列変数名;
					int[] scores;
```

Step2　要素の作成と代入（引き出しを作成し、枠に当てはめる）

作成＝new演算子、代入＝代入演算子

```java
scores = new int[5];
		枠 ←　新しくint型の引き出しを５つ作成、当てはめる
```

    配列の要素数が格納されている変数
    
    →　配列を生成すると自動的に用意される変数
    
    ```java
    [利用方法]
    				配列変数名　.　length
    	　　　　どの棚　　の　引き出しの数を知りたいのか
    ※メソッドの呼び出しの場合と同様に、所属を明確にする
    ```
    

【利用】

- 要素の活用）
    - 記述
        - 要素の指定）配列変数名[x]
        どの棚の何番目の引き出しかを指定する
        ※x：添え字（０番スタート）
    - 初期値
        - 何もない状態を意味するリテラルが自動的に格納される
        数値型：０
        boolean型：false
        String型：null
        
        [ リテラルの仕込み ]
        
        1. 要素の型[] 配列変数名 =new 要素の型[] {値、値、値};

## 1.ループ変数を添え字に利用

1. ループによる全要素の利用
→　ループ変数と添え字を連動させて配列の要素を順に使用（配列を回す）
    
    ```java
    for(int i = 0; i<配列変数名.length; ++);{
    	配列変数名iを使用した処理;
    	}
    ```
    
2. ループによる集計作業
→　合計や平均の算出、条件に合った要素の抽出、など
    1. 集計結果を格納する変数（for文の外で宣言)は初期化が必要
    `int sum = 0;`
    2. 集計処理（工夫次第）（for文の中で実施）
    
    ```java
    for(int i = 0; i<配列変数名.length; ++);{
    	配列変数名[i]を使用した処理;
    	sum += 配列変数名[i]　　　//各要素を順に加算する処理
    	}
    ```
    
3. 集計結果の活用（for文の外で実施）
    
    ```java
    int avg = sum / 配列変数名.length;
    ```
    

## 2.ある配列の要素を添え字に利用

1. 添え字に対応した情報（ある配列の要素）の利用
    
    →　数値を格納した配列の要素をある配列の添え字に利用することも可能
    
    例）code4-12 etc
    
    ```java
    配列A = {0,1,2,3};
    配列B[0]=配列B[配列A[0]]
    ```
    
    ※ある配列の要素に数値が格納されていれば、ループ変数でなくてもその要素を添え字に利用できる
    

```java
public class Main {
    public static void main(String[] args) {
        // 1. データの配列（これが「中身」）
        String[] fruits = {"りんご", "みかん", "ぶどう", "バナナ"};

        // 2. 添え字に使うための配列（これが「指示書」）
        // 中身は「何番目のデータが欲しいか」という数値
        int[] order = {2, 0, 3, 1};

        System.out.println("--- 実行開始 ---");

        // ループを使って、order配列の数値を順番に取り出し、
        // それをfruits配列の添え字（インデックス）として使う！
        for (int i = 0; i < order.length; i++) {
            
            // order[i] で取り出した数字を、そのまま fruits の [ ] に放り込む
            String name = fruits[order[i]];
            
            System.out.println("order[" + i + "] の値は " + order[i] + " なので...");
            System.out.println("fruits[" + order[i] + "] を取得 → 「" + name + "」");
            System.out.println("--------------------");
        }
    }
}
```

このコードで起きてること（イメージ図）
order[0] を見ると 2 が入ってる。

その 2 を使って fruits[2] を見に行くと "ぶどう" が見つかる。

order[1] を見ると 0 が入ってる。

その 0 を使って fruits[0] を見に行くと "りんご" が見つかる。
