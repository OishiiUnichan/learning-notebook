## for文と拡張for文でのリスト取り出し

---

### 準備（共通）

```java
ArrayList<String> fruits = new ArrayList<>();
fruits.add("apple");
fruits.add("banana");
fruits.add("cherry");
// [apple, banana, cherry]
```

---

### 通常のfor文

```java
for (int i = 0; i < fruits.size(); i++) {
    System.out.println(fruits.get(i));
}
```

**動きのイメージ**

```
i=0 → fruits.get(0) → "apple"
i=1 → fruits.get(1) → "banana"
i=2 → fruits.get(2) → "cherry"
```

- `i` でインデックスを管理する
- `get(i)` で要素を取り出す
- **何番目か**が必要なときに使う

---

### 拡張for文

```java
for (String fruit : fruits) {
    System.out.println(fruit);
}
```

**動きのイメージ**

```
fruit = "apple"   → 表示
fruit = "banana"  → 表示
fruit = "cherry"  → 表示
```

- インデックスを意識しなくていい
- **全件処理**するだけなら圧倒的にシンプル

---

### どちらを使うべき？

| 状況 | 使うべきfor文 |
| --- | --- |
| 全要素をただ処理したい | **拡張for文** |
| 何番目かを使いたい | **通常for文** |
| 特定の位置に挿入・削除したい | **通常for文** |
| 逆順に処理したい | **通常for文** |

---

### 具体例：インデックスが必要なケース

```java
// 何番目かを一緒に表示したい
for (int i = 0; i < fruits.size(); i++) {
    System.out.println((i+1) + "番目: " + fruits.get(i));
}
// 1番目: apple
// 2番目: banana
// 3番目: cherry
```

拡張for文だとインデックスが取れないのでこういう場合は通常for文を使います。

---

### まとめ

```
全件処理するだけ　→　拡張for文（シンプル）
インデックスが必要　→　通常for文
```

基本は**拡張for文**を使って、インデックスが必要なときだけ**通常for文**に切り替えるのがおすすめです。
