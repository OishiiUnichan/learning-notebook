# オーバーロード

基本的には同じ名前のメソッドを複数定義することはできない

→　呼び出し先のメソッドが区別できないため

呼び出し先のメソッドが区別できれば、同じ名前で複数定義することができる

→　複数定義することを　オーバーロード（多重定義）　と呼ぶ

### オーバーロードできる条件

仮引数の構成（型、数、状況によっては並び順）が異なれば、同じ名前のメソッドを複数定義可能になる。

#### 注意１

戻り値の型や、修飾子が異なるだけではオーバーロード出来ない

→オーバーロードの可否は、呼び出し先メソッドが区別できるか否かによる
