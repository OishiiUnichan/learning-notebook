# 戻り値

呼び出し元のメソッドで利用するために戻される、呼び出し先のメソッドの処理結果（出力値）

### イメージ

戻り値なし

- やりっぱなしで構わない作業指示書
→　作業が終わったことさえ分かれば、具体的な成果物を受け取る必要がない
    
    例
    
    - 指示書の内容：会議室のホワイトボードを消しておいてください
    - 作業者の行動：ホワイトボードを消す
    - 作業者の結果：作業者は指示者の元に何も持たずに戻る　or　次の仕事にいく
    - 指示書の特徴：状態を変えることが目的

戻り値あり

- 結果の報告が必要な作業指示書
→　作業した結果をその後の判断や別の作業に使いたい
    
    例
    
    - 指示書の内容：自販機でコーヒーを1本買ってきてください
    - 作業者の行動：自販機でコーヒーを買う
    - 作業者の結果：作業者は指示者にコーヒーを渡す（コーヒーが戻り値）
    - 指示書の特徴：手に入れたコーヒーを使って、何に使うかを指示者が自由に決められる

# [ メソッドの定義 ]

public static [ 戻り値の型 ] メソッド名（引数リスト）｛

[ メソッドが実行されたときの処理 ]

return [ 戻り値 ]

｝

### メソッドの呼び出し

1種類しか受け皿は用意できない

戻り値の型　変数名　＝　メソッド（引数リスト）；

#### return文における注意事項

return文は戻り値を呼びし元に戻すだけではなく、処理の流れも戻すのでメソッドの処理も終了する。

そのため、return文のあとに処理を記述しても到達不能コードとなり、コンパイルエラーとなる
