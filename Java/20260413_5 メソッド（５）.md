# 引数や戻り値に配列を用いる

## ★基本型変数をメソッドの呼び出しで渡す

〇　呼び出し元の変数の内容（値）が、呼び出し先の引数にコピーされる

→値渡し

×　呼び出し元の変数のメモリの番地が、呼び出し先の引数にコピーされる

→参照渡し

※　呼び出し先で引数の内容を変更しても、呼び出し元の変数は変更されない

![val = value (値)](5%20%E3%83%A1%E3%82%BD%E3%83%83%E3%83%89%EF%BC%88%EF%BC%95%EF%BC%89/image.png)

val = value (値)

## ★参照型変数をメソッドの呼び出しで渡す

〇　呼び出し元の変数の内容（参照）が、呼び出し先の引数にコピーされる

→値渡し（参照の値渡し）

×　呼び出し元の変数のメモリの番地が、呼び出し先の引数にコピーされる

→参照渡し

※　呼び出し先で引数の内容を変更すると、呼び出し元の変数も変更される

→　結果、変数のメモリの番地を渡した場合と同じになる

# コマンドライン引数

プログラム起動時に指定した追加情報（コマンドライン引数）は、Java仮想マシン（JVM）によって配列に格納され、main（）メソッド起動時に渡される

`public static void main(String[] args){}` 

1. コマンド操作：キーボードで文字入力してプログラムを実行する方式
    
    環境例：コマンドプロンプト（cmd）
    
    実　行：java パッケージ名 . クラス名　引数リスト
    
    クラス名であってファイル名ではないため、拡張子は不要
    
    引数リストは（）で囲まない
    
    実行例：java code05_15.Main 菅原 湊 朝香
    
2. メニュー操作
    
    環境例：Eclipse
    
    実　行：
