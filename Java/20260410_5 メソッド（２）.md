# 引数

メソッドを呼び出す際に、処理を実行するために必要な追加情報（入力値）

メソッドを…

定義する側：仮引数

利用する側：実引数

### メソッドの定義

```java
public static voi hello(String name){　　//引数の型も宣言する
																↑仮引数：名前は任意
	// 処理内容
	System.out.println(name +"さん、こんにちは");　//仮引数で処理構築する
	
}
```

### メソッドの呼び出し

```java
hello("湊");
//　　　↑実引数：メソッドの宣言で指定されている型に合わせる
				※引数不要でも（）は省略不可
```

※引数が『複数』ある場合

メソッドの宣言：仮引数を「、」区切りで列挙する

メソッドの呼び出し：実引数の指定は、仮引数の型と位置（数、順番）に合わせる

# 変数のスコープ

- ローカル変数
    
    メソッドブロックの中で宣言された変数
    ※仮引数もローカル変数
    
    ローカル変数はブロックの中でのみ有効
    →　変数のスコープ範囲はメソッドのブロックも制御構文のブロックと同じ
    
- ローカル変数の独立性
    
    異なるメソッドに属するローカル変数は、お互いに独立していて無関係
    →　同じ変数名を使用することが可能
