# 抽象クラス

※未完成な記述のあるクラスは、プログラムの実行で不具合が生じるため、登場人物のクラスはインスタンス化できないようにしておく必要がある

1. **［抽象メソッド］**
    
    →処理内容が確定できない未完成な記述があれば、**「abstract」修飾子**をつけて、その旨を伝える構文がある。
    
    ［書式］
    
    ```java
    public **abstract** 戻り値　メソッド名（引数リスト）**；**
    	詳細未定のため、ブロック（｛｝）は不要。代わりにセミコロン（；）が必要！
    ```
    
    ［注意］
    
    具象クラスには、抽象メソッドは宣言できない。
    
    →クラス宣言に「abstract」修飾子を付ける必要がある
    
2. **［抽象クラス］**
    
    →抽象メソッドを含むクラスは、「abstract」修飾子をつけて、その旨を伝える必要がある。
    
    ※抽象クラスをインスタンス化しようとするとコンパイルエラーになる
    
    ［書式］
    
    ```java
    public **abstract** class クラス名 {・・・}
    ```
    
    ※具象メソッドのクラスでも、インスタンス化を禁止したい場合には、「abstract」修飾子をつけて、抽象クラス化することも可能。
    
    →カスの日本語。メソッド自体が完成してる＝未確定の詳細情報が含まれていない、でも、インスタンス化したくないので抽象クラスとして扱う、ということ。
    
    ```java
    // １．メソッドの中身は全部書いてある（具象メソッド）
    // ２．でも、頭に「abstract」をつけて、このクラス自体のインスタンス化を禁止する！
    public abstract class Movie {
        String title;
    
        // 未確定の詳細情報のない「完成した」メソッド
        public void showTitle() {
            System.out.println("作品名：" + this.title);
        }
    }
    ```
    
    ◎抽象クラスにすることで、以下が可能となる
    
    1. インスタンス化を禁止できる
    2. 継承先のいずれかのクラスで抽象メソッドをオーバーライドさせることができる
