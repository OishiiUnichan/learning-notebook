# コマンドラインの紹介

通常、プログラム実行に必要なデータはプログラム実行後に必要なデータをキーボードなどの入力装置から入力してもらう。

```java
ex)
String data = new java.util.Scanner(System.in).nextLine();
```

利用者との手間をかけずに出力結果のみ知りたい場合にコマンドライン入力は有用である。

## 実例

- 電卓プログラム
- バッチ処理のログファイル解析
    
    一定期間や一定量たまったデータ、あるいは複数の処理タスクを特定のタイミングで一括して自動的に実行する手法。
    
    リアルタイム処理とは異なり、主に夜間やシステムのアイドルタイムに行われ、処理効率の向上、人為的ミスの削減、システム負荷分散に寄与する。
    

### 実行例

```java
java SearchTool [ファイル名] [検索キーワード] [出力先]
```

#### 解説

引数の役割分担）args[0]：入力元、args[1]：条件、args[3]：出力先

オプション引数）args.lengthをチェックすることで「３番目の引数があるときだけファイルに出力」といった柔軟な処理が可能。

#### 実用性

ログファイルの解析や、大量のテキストデータから特定の情報抽出etc
