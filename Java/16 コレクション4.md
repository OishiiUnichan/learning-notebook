## イテレータとArrayListの繰り返し処理

---

### イテレータとは？

リストの要素を**順番に取り出すための仕組み**です。

```
ArrayList: [apple, banana, cherry]
                ↑
           イテレータが指し示す位置を管理してくれる
```

---

### イテレータのメソッド

| メソッド | 意味 |
| --- | --- |
| `hasNext()` | 次の要素があれば `true` |
| `next()` | 次の要素を取り出して進む |
| `remove()` | 今の要素を削除する |

---

### イテレータの取得と基本的な使い方

```java
import java.util.ArrayList;
import java.util.Iterator;

ArrayList<String> fruits = new ArrayList<>();
fruits.add("apple");
fruits.add("banana");
fruits.add("cherry");

// イテレータを取得
Iterator<String> it = fruits.iterator();

// 要素の取り出し
while (it.hasNext()) {
    String fruit = it.next();
    System.out.println(fruit);
}
// apple
// banana
// cherry
```

**動きのイメージ**

```
it.hasNext() → true  / it.next() → "apple"
it.hasNext() → true  / it.next() → "banana"
it.hasNext() → true  / it.next() → "cherry"
it.hasNext() → false / ループ終了
```

---

### イテレータで要素を削除する

拡張for文やfor文でループ中に削除すると**エラーが起きます。**

イテレータの `remove()` を使うと安全に削除できます。

```java
Iterator<String> it = fruits.iterator();

while (it.hasNext()) {
    String fruit = it.next();
    if (fruit.equals("banana")) {
        it.remove();  // 安全に削除できる
    }
}
System.out.println(fruits);
// [apple, cherry]
```

---

### 3つの繰り返し処理まとめ

```java
// ① 通常for文
for (int i = 0; i < fruits.size(); i++) {
    System.out.println(fruits.get(i));
}

// ② 拡張for文
for (String fruit : fruits) {
    System.out.println(fruit);
}

// ③ イテレータ
Iterator<String> it = fruits.iterator();
while (it.hasNext()) {
    System.out.println(it.next());
}
```

---

### どれを使うべき？

| 状況 | 方法 |
| --- | --- |
| 全件処理するだけ | **拡張for文**（一番シンプル） |
| インデックスが必要 | **通常for文** |
| ループ中に要素を削除したい | **イテレータ** |

---

### まとめ

```
普段          → 拡張for文
番号が必要    → 通常for文
削除しながら  → イテレータ
```

> イテレータは少し書き方が複雑ですが、**ループ中の安全な削除**という場面で活躍します！
>

```java
package code16_02;

import java.util.ArrayList;
import java.util.Iterator;

public class Main {

	public static void main(String[] args) {
		ArrayList<String> names = new ArrayList<>();
		names.add("湊");
		names.add("朝香");
		names.add("菅原");

	//イテレータを取得		
	//「names」というリストから、イテレータを取得する
		Iterator<String> it =names.iterator();
		
	//要素を取得	
		while (it.hasNext()) {　
		//（1）ワッペンを貼れる引き出しはあるか？
		//ない場合→while文終了
		//ある場合は次の処理へ進む
		
		//(2)引き出しにワッペンを張って中身を取り出す
			String n = it.next();
			
		//(3)ワッペンを取るという処理実行
			System.out.println(n);
			//(4)次の引き出しを検討する（１）の処理に戻る
		}
	}
	
}
```
