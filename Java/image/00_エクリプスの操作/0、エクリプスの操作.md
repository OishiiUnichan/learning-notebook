**エクリプス操作手順**
①プログラムの「**物理管理フォルダ**」を用意する：ワークスペース
②プログラムの**「物理管理サブフォルダ」**を用意する：プロジェクト
　・ファイル＞新規＞Javaプロジェクト：命名規則はテキスト章番号[chap00]
　※1アプリ1プロジェクト
③プログラムの**「論理管理フォルダ」**を用意する：パッケージ
　・プロジェクト内「src」＞ファイル＞新規＞パッケージ
　　パッケージ命名規則：サンプルコードの見出し[code00-1]
④プログラム（クラス）作成
　ファイル＞新規＞クラス
　訓練のクラス命名規則：サンプルコードファイル名[Main]
　必要に応じてPublic static void main(String[] args)
　※頭文字は大文字にする
　※入力後、保存することで自動的にコンパイルされる
⑤プログラム実行
　作成ファイルを選択or表示
　実行→実行→Javaアプリケーション
