# Eclipseの操作方法

パッケージのコピペはサブパケを含めたコピーは出来ない。

1. パッケージエクスプローラの管理表時を切り替える
    
    パッケージ・エクスプローラ＞ビュー・メニュー（縦３点リーダ）＞パッケージ・プレゼンテーション＞フラット　を選択する
