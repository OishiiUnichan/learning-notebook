# 7.3 オブジェクト指向の全体像と本質

プログラミングする動機）現実世界で人がする仕事を自動化させること。

→ プログラムは、現実世界と無関係ではない。

［例］

両替商 	 → ATM
切符販売→ 自動販売機
日記帳　→ ブログ
冒険	 → RPG				

手続き指向）コンピュータに任せる指示書を作成する。

→「万能」型ロボットに指示を出す。

オブジェクト指向）プログラム（仮想世界）に関わる要素を洗い出す。

部品化のルール）登場人物の単位で、クラスを準備する。

→「専用」型ロボットを考案し、設計図を作成する。

オブジェクト指向におけるクラス　→　オブジェクトの『設計』図に相当する。

プログラムの実行

→① 設計図（クラス）をもとに人物（オブジェクト）を生み出す。

［例］「万能」型ロボットに設計図を渡し、「専用」型ロボットを作製する。

→② オブジェクト同士を『連携』させて、仕事をさせる。

［例］「万能」型ロボットが「専用」型ロボット同士を連携させて動かす。

## ☆オブジェクト指向の本質

現実世界の登場人物とその振る舞いを。コンピュータの仮想世界に取り入れること。
そのためには…

→ 手続きを考える必要はない。現実世界のモノの動きを観察して、準備すればよい。

［例］ 素人には子と細やかなな指示が必要だが、玄人には簡単な指示だけでよい。

→ どんな情報や機能を事前に持たせておけばよいのか、を考える！

→ プログラムを改訂・修正する場合、対応する部品の設計図（クラス）を手直しし、交換すれば容易に対応できる。

［例］「専用」型ロボットの情報や機能を追加修正したり、交換すれば、ロボット時代を交換する必要はない。

### 〇オブジェクト指向の本質

- 現実世界の登場人物とそのふるまいを、コンピュータ内の仮想世界で再現している。
