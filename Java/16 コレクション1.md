## ラッパークラスをArrayListに格納する

```java
package code16_01;

import java.util.ArrayList;

public class Main {
	
	public static void main(String[] args) {
		ArrayList<Integer> points = new ArrayList<Integer>();
		points.add(10);
		points.add(80);
		points.add(75);
		for (int i:points) {
			System.out.println(i);
		}
			System.out.println(=====);
		//明示的に型変換
		for (Integer i1:points){
			int i2 = i1.intValue();  //int型←Integer型
			System.out.println(i2);
	}
}
```

```java
ArrayList<Integer> points = new ArrayList<Integer>();
→基本型の情報は格納不可。
［対策］
　ラッパークラス（非推奨）や、オートボクシング機能の利用

	自動的に型変換する
		points.add(10);　　//基本型→参照型
		points.add(80);　　//int型→Integer型
		points.add(Integer.valueOf(75));　　//明示的に型変換
		
		自動的に型変換（オートアンボクシング）　//基本型←参照型
		for (int i:points) {　　　　　　　　　//int型←Integer型
			System.out.println(i);
		}
		System.out.println(=====);
		明示的に型変換
		for (Integer i1:points){
			int i2 = i1.intValue();  //int型←Integer型
			System.out.println(i2);
	}
}
```

💡

## コードの解説

このコードは **ArrayListに整数を格納して表示する**プログラムです。

---

### ポイント：`int` と `Integer` の違い

|  | `int` | `Integer` |
| --- | --- | --- |
| 種類 | プリミティブ型（基本型） | 参照型（クラス） |
| 例 | `int x = 5;` | `Integer x = 5;` |
| メソッド | 持てない | 持てる |

ArrayListは**クラスしか格納できない**ため、`int`ではなく`Integer`を使います。

---

### 明示的な型変換の部分

```java
for (Integer i1 : points) {
    int i2 = i1.intValue();  // Integer型 → int型
    System.out.println(i2);
}
```

`i1.intValue()` は **Integerオブジェクトから、中身のint値を取り出す**メソッドです。

```
Integer i1 = 80;   // オブジェクト（箱に入った80）
     ↓ .intValue()
int i2 = 80;       // プリミティブ（生の80）
```

---

### じゃあ最初のforループは？

```java
for (int i : points) {
    System.out.println(i);
}
```

こちらは `int` で受け取っています。実はJavaが裏で自動的に変換してくれています。

- `Integer` → `int` の自動変換 ＝ **アンボクシング**
- `int` → `Integer` の自動変換 ＝ **オートボクシング**

---

### まとめ

| ループ | やってること |
| --- | --- |
| 1つ目（`int i`） | Javaが**自動で**Integer→intに変換（アンボクシング） |
| 2つ目（`Integer i1`） | プログラマーが**明示的に** `.intValue()` で変換 |

**結果は同じ**ですが、2つ目は「何が起きているか」をあえて見えるように書いたコードです。
