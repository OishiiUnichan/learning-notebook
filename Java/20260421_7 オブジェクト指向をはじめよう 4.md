# 7.4 オブジェクトの責務

- オブジェクトの設計として、オブジェクトに責務（役割と責任）を割り当てる。

| 責務の内訳 | 設計図（クラス図） | クラス |
| --- | --- | --- |
| ①情報保持責任 | 属性：オブジェクトがもつ、あるいはもたせる情報 | 変数 |
| ②行動責任 | 操作：オブジェクトが行う、あるいは行わせる処理 | メソッド |

※属性や操作の内容は、開発者がオブジェクトを設計する際に決定する。

［例］［炊飯器 ] オブジェクトに炊飯後、保温機能が必要ならば、［炊飯器 ] クラスの属性として保温機能に必要な温度や時間を管理する変数は不要である。

- オブジェクトのふるまいやオブジェクト同士の相互作用は、mainメソッドや他のオブジェクトから、対象の行動責任に働きかけることで実現する。
