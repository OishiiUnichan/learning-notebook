## 1-11.html
- イメタグ `<img scr>`だと思ってた。  
  scr = screenって勝手に勘違いしてたが、`<img src>`が正しい。  
  **src** = source　ファイルのソースの略称だった。
  
- 略語の意味をついでにググッた  
  | 属性・タグ  | フルネーム               | 意味                   |
  | ----------- | ------------------------ | ---------------------- |
  | `src`       | Source                   | 素材の出どころ         |
  | `href`      | Hypertext Reference      | リンク先の参照先       |
  | `alt`       | Alternative              | 代替テキスト           |
  | `div`       | Division                 | 区切り・区画           |
  | `ul` / `ol` | Unordered / Ordered List | 順不同・順序付きリスト |
  
- valignが初見だったのでなにこれと思ってググった
  - **★Vertical Align（垂直方向の位置揃え）**  
    テーブルのセル内で内容を縦方向のどこに配置するかを指定する。  
    ```HTML
    <td valign="top">    ← 上揃え
    <td valign="middle"> ← 中央揃え（デフォルト）
    <td valign="bottom"> ← 下揃え
    ```
    HTML5では非推奨なので現在はCSSで書くのが正解。  
    
- img srcのwidthには単位不要
