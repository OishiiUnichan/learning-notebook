# MySQL接続手順とSHOWコマンド

## 接続手順
訓練校の時

1. 事前準備
	1. OracleのVirtualBox立ち上げる
	2. テラタームでSSH接続でログインする

2. MySQL接続
	1. 以下コマンドを入力する
		```SQL 
			date
			whoami
			hostname
		```
	2. DBに接続する
		```SQL 
			mysql -u ユーザ名 -p
		```
		パスワードを入力する  
		表示が「>mysql」になった場合、接続成功
		
	3. 使用するDBを選択する
		```SQL
			use DB名
		```
		以下メッセージが表示される
		```SQL
			Database changed
		```
3. SHOWコマンド 
	|コマンド|表示されるもの|
	|---|---|
	|SHOW DATABASES;|データB|
	|SHOW TABLES;|データE|
	|SHOW COLUMNS FROM テーブル名;|---|
	|SHOW INDEX FROM テーブル名;|---|
	|SHOW STATUS;|データB|
