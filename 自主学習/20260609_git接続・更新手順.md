
## 2回目以降の手順
毎回忘れる

### 1. リポジトリのフォルダに移動
```bash
cd リポジトリ名
```

### 2. 最新の状態に更新（念のため）
```bash
git pull
```

### 3. アップロードしたいフォルダをそこに置く
エクスプローラーやFinderで、リポジトリのフォルダ内にコピーするだけでOK。

### 4. あとはこの3コマンドだけ
```bash
git add .
git commit -m "コメント（何を追加したか）"
git push
```
# GitとローカルのSync手順

## GitHubが新しい場合（GitHubの内容をローカルに反映したい）

```cmd
cd リポジトリのフォルダ
git pull origin main
```

---

## ローカルが新しい場合（ローカルの内容をGitHubに反映したい）

```cmd
cd リポジトリのフォルダ
git add .
git commit -m "コミットメッセージ"
git push origin main
```

---

## 注意事項

### pushが弾かれた場合
GitHubとローカルで差分がある場合、pushが弾かれることがある。
その場合は先にpullしてからpushする。

```cmd
git pull origin main
git push origin main
```

### pullでコンフリクトが発生した場合
同じファイルの同じ箇所をGitHubとローカルの両方で編集していると発生する。

```cmd
git pull origin main
```

↓ コンフリクトが発生したファイルを手動で修正する

```cmd
git add .
git commit -m "コンフリクト解消"
git push origin main
```
