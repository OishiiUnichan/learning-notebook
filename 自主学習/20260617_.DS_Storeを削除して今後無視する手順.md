## .DS_Storeを削除して今後無視する手順

### ① すでにGitに登録された.DS_Storeを削除

```bash
git rm --cached .DS_Store
git rm --cached HTML_CSS/.DS_Store
```

### ② .gitignoreファイルを作成

```bash
echo .DS_Store > .gitignore
```

### ③ .gitignoreをコミット＆push

```bash
git add .gitignore
git commit -m ".DS_Storeを無視する設定を追加"
git push
```
