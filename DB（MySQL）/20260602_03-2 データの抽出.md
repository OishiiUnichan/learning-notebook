# 3-2 データの抽出

subject: DB
day: 2026年6月2日
memo: 3-2 データの抽出（SELECT）

---

【基本形】

```sql
SELECT カラム名リスト FROM テーブル名;　　　　　　　　←カラムの絞り込み
SELECT カラム名リスト FROM テーブル名 WHERE 条件式;　←レコードの絞り込み
```

1. カラム名の指定
    
    複数のカラムを表示させたい場合…カンマ区切りで列挙
    
    テーブルのカラムをすべて表示させたい場合…アスタを利用
    
2. 条件式
    
    比較演算子、論理演算子は５章で扱う
    
    対象を絞り込むためのWHERE句は、他のデータ操作言語でも使用できる［p.069］
    
    →とくに、更新、削除の操作では、**WHERE句の記述漏れは事故になる**ので要注意
    

※指定した列順　→　抽出される列順
