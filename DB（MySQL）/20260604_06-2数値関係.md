# 6-2数値関係

subject: DB
day: 2026年6月4日

SQLで数値の端数を処理するときは、主に **`ROUND`（四捨五入）**、**`TRUNC` / `TRUNCATE`（切り捨て）**、**`FLOOR`（床関数）**、**`CEIL` / `CEILING`（天井関数）** の4つを使うんだ。

特に、指定する「桁数（第2引数）」によってどこで処理されるかが変わるから、そこをイメージで掴むのがポイントだよ。

## 1. 桁数の指定イメージ（基本のキホン）

まずは、処理を行いたい位置（桁数）の指定方法をマスターしよう。小数点を `0` として、右（小数側）にいくとプラス、左（整数側）にいくとマイナスになるんだ。

```
 1  2  3      4  5  6
 ──┬──┬──  0 ──┬──┬──
  -2 -1        1  2  3
```

- **`0`**：小数第1位を処理して、**整数**にする
- **`1`**：小数第2位を処理して、**小数第1位まで**残す
- **`1`**：一の位を処理して、**十の位まで**残す

## 2. 主要な4つの関数と動き

### ① ROUND（四捨五入）

指定した桁数の「次の桁」が5以上なら切り上げ、4以下なら切り捨てる。

- **`ROUND(123.456, 1)`** ➔ **`123.5`** （小数第2位の「5」を四捨五入）
- **`ROUND(123.456, 0)`** ➔ **`123`** （小数第1位の「4」を四捨五入）
- **`ROUND(123.456, -1)`** ➔ **`120`** （一の位の「3」を四捨五入）

### ② TRUNC / TRUNCATE（切り捨て）

指定した桁数より後ろの数字を、文字通り「スパッと切り捨てる」関数だよ。

※データベースによって `TRUNC`（Oracle/PostgreSQLなど）か `TRUNCATE`（MySQLなど）か名前が違うので注意してね。

- **`TRUNC(123.456, 1)`** ➔ **`123.4`** （小数第2位以降をバッサリ）
- **`TRUNC(123.456, 0)`** ➔ **`123`** （小数をバッサリ）
- **`TRUNC(123.456, -1)`** ➔ **`120`** （一の位をゼロにする）

## 3. 整数に特化した2つの関数（CEIL と FLOOR）

この2つは桁数の指定ができなくて、**必ず整数を返す**関数なんだ。数直線（スケール）をイメージすると分かりやすいよ！

### ③ CEIL / CEILING（切り上げ / 天井関数）

現在の数以上の「最小の整数（天井）」に向かって数値を引き上げるよ。

- **`CEIL(123.1)`** ➔ **`124`**
- **`CEIL(-123.9)`** ➔ **`123`** （マイナスの場合は0に近づくよ）

### ④ FLOOR（切り捨て / 床関数）

現在の数以下の「最大の整数（床）」に向かって数値を引き下げるよ。

- **`FLOOR(123.9)`** ➔ **`123`**
- **`FLOOR(-123.1)`** ➔ **`124`** （マイナスの場合は0から遠ざかるよ）

> **⚠️ 注意：マイナスのときの `TRUNC` と `FLOOR` の違い**
> 
> 
> プラスの数のときはどちらも同じ動きに見えるけど、マイナスのときは結果が変わるんだ。
> 
> - `TRUNC(-123.9)` ➔ **`123`** （単純に小数を消す）
> - `FLOOR(-123.9)` ➔ **`124`** （より小さい整数へ移動する）

## まとめの一覧表

一目でパッと見比べられるように表にまとめたよ。

| **関数** | **元の数：123.456** | **元の数：-123.456** | **特徴** |
| --- | --- | --- | --- |
| **`ROUND(値, 1)`** | `123.5` | `-123.5` | 指定桁で四捨五入 |
| **`TRUNC(値, 1)`** | `123.4` | `-123.4` | 指定桁より後ろをゼロにする |
| **`CEIL(値)`** | `124` | `-123` | 大きな整数へ切り上げ（天井） |
| **`FLOOR(値)`** | `123` | `-124` | 小さな整数へ切り下げ（床） |

RAND関数

0以上1未満のランダムな数値を返す。

［確認］mysql > HELP RAND

［整数乱数の発生］

- FLOOR(RAND()*【設定値】);
    
    →設定値に10を入れると0～9の乱数が発生する
    
    　つまり、最大値は設定値-1となる
    
    したがって i ← R ← j の範囲内で整数乱数Rを取得するには、
    
    FLOOR(RAND()*(j-i+1)+ i )を使用する
    
    開始の値以上終了の値未満になる
