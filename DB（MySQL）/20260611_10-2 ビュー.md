# 10-2 ビュー

イメージ：戻り値が結果表である関数

- SELECT文による結果表を基に作成される「仮想的」なテーブル
    
    →　通常は「結合」した互いのテーブルから必要なカラムを抽出したテーブル
    
- ビューは、あらかじめ仕込まれたSELECET文の実行結果をみる機能であり、実行結果であるビューは参照するたびに新しく作成される
    
    →　言い換えれば、名前を付けて新しくSELECT文を保存する機能ともいえる
    
    →イメージ：関数を呼び出すたびに戻り値が生成される
    

※　通常のテーブルとの違い

- 通常のテーブルの情報：作成した時点での情報
    
    作成元のテーブルが更新される→自動更新されるわけではないので、都度更新が必要
    
- ビュー：実行するたびに内容が変わる（更新される）可能性のある仮想的なテーブル
    
    そのため、インデックスは作成できない
    
- ビューに対してWHERE句で条件付けも可能　←［リスト10-14］
    
    ビューを他のテーブルや他のビューと結合も可能　←［リスト10-15］
    
    ただし、**処理速度は低下する場合がある**
    

## 【ビューの作成】（イメージ：関数の定義）

［基本構文］

```sql
CREATE VIEW ビュー名 AS SELECT文;
```

［使用例］

```sql
リスト10-9
CREATE VIEW uriagedenwa

リスト10-8
CREATE VIEW uriagedenwa
AS
SELECT idur,uriage.company,charge,salesdate,tel
FROM uriage INNER JOIN jusho ON uriage.company=jusho.company;
```

【ビューの確認】

［書式］

```sql
SHOW TABLES;
```

## 【ビューの使用】

イメージは関数の呼び出し

［基本構文］

```sql
SELECT * FROM ビュー名;
```

- 作成→確認→利用のコマンド
    
    ```sql
    事前確認
    SHOW TABLES;
    
    ビューの作成
    CREATE VIEW uriagedenwa
    AS
    SELECT idur,uriage.company,charge,salesdate,tel
    FROM uriage INNER JOIN jusho ON uriage.company=jusho.company;
    
    作成後の確認
    SHOW TABLES;
    
    利用10-10
    SELECT * FROM uriagedenwa;
    
    利用10-14
    SELECT * FROM uriagedenwa 
    WHERE charge >= 200000 ORDER BY salesdate;
    
    利用10-15
    SELECT * FROM uriagedenwa 
    LEFT OUTER JOIN jusho
    ON uriagedenwa.company=jusho.company;
    ```
    

## 【ビューの更新】

［通常］参照する（SELECT文）目的で使用する。

［可能］更新する（INSERT、UPDATE、DELETE文）目的でも使用可能［リスト10-17］

→参照元にも影響が及ぶ辞め、取り扱い要注意。複数テーブルにまたがる更新は出来ない。

【確認】ビュー→参照元

```sql
SELECT * FROM uriage WHERE idur=2017090002;
UPDATE uriagedenwa SET charge=200000 WHERE idur=2017090002;
```

## 【ビューの削除】

※削除対象は

〇ビューのみ

✕参照元のテーブルには影響しない

［基本構文］

```sql
DROP VIEW ビュー名; ←DELETEではない
```

【確認】リスト10-20

```sql
SHOW TABLES;
DROP VIEW uriagedenwa;
SHOW TABLES;
```
