# 4-5 NULLという特別な値

### **NULL**

値を何も設定しないことを意味する値。文字列型ではないので、引用符では囲まない。未設定や未確定の状況の時に使用する。

［思い違い］売上金額：０←０円？

［設定不可］売上不可：””　←　日付の書式に存在しない

<aside>
💡

メモ［p.112］

テーブル作成時に「NULL」を許容しない設定も可能　→　［９章］

［使用例］

- INSERT文で追加や、UPDATE文で既存のデータを未設定に更新することができる。
- SELECT文でNULLを検索する場合、WHERE句で指定するが、その場合は比較演算子（＝）ではなく、IS演算子を使用する。

## コラム

#### 🔍 構造を確認する基本のSHOWコマンド

まずは、データベース全体やテーブルの構造を覗き見るときに外せない基本の4つ。

- **`SHOW DATABASES;`**
    
    サーバー内にあるデータベースの一覧をずらっと表示するよ。最初の一歩はだいたいこれ！
    
- **`SHOW TABLES;`**
    
    今選択している（`USE`している）データベースの中に、どんなテーブルがあるかを確認できるよ。
    
- **`SHOW COLUMNS FROM テーブル名;`**
    
    （または `SHOW COLUMNS IN テーブル名;`）
    
    指定したテーブルのカラム名、データ型、主キー（PRIMARY KEY）の設定、NULLを許容するかなどを一覧で確認できるよ。※ちなみに `DESCRIBE テーブル名;` でも同じことができるよ！
    
- **`SHOW CREATE TABLE テーブル名;`**
    
    そのテーブルが「どんなSQL文で作られたか」の定義を丸ごと表示してくれるよ。既存のテーブルと全く同じ構造のテーブルを作りたいときや、インデックスの設定を確認したいときにすごく便利！
    

## 🛠 設定や状態を確認する応用コマンド

データベースの管理やトラブルシューティングでよく使う、ちょっと一歩踏み込んだコマンド。

- **`SHOW PROCESSLIST;`**
    
    現在データベースで「どんなクエリが実行されているか」をリアルタイムで表示するよ。処理が重くて進まないときに、犯人のクエリを特定するのに大活躍するよ。
    
- **`SHOW VARIABLES;`**
    
    データベースのシステム設定（文字コード、ポート番号、キャッシュサイズなど）を一覧表示するよ。特定のキーワードで絞り込みたいときは、`SHOW VARIABLES LIKE '%char%';` のように使うのがコツ。
    
- **`SHOW STATUS;`**
    
    サーバーの稼働状態や、これまでにどれくらいクエリが実行されたかなどの統計情報を確認できるよ。
    
- **`SHOW INDEX FROM テーブル名;`**
    
    テーブルにどんなインデックス（索引）が張られているかを確認できるよ。検索速度を上げたいときのボトルネック調査に。
