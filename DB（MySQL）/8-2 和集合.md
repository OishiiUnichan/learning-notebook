# 8-2 和集合

［構文］

```sql
SELECT カラム名リスト FROM テーブル名1
UNION　[ALL]
SELECT カラム名リスト FROM テーブル名2;
```

※オプション）何も指定しない、あるいはDISTINCT→重複レコード除去

ALL→重複レコード含む

【確認】

```sql
SELECT idju,company,state,address FROM jusho
UNION （ALL）←ALLのオプションは()つけない
SELECT idur,company,state,area FROM uriage;
```

※上記の例では、重複レコードがないため、ALLオプションの有無に関係なく同じレコード数になる

［メモ］

DISTINCTオプションは、phpMyAdminでは動かない

→［構文エラー？］Unrecognized statement type.(near DISTINCT)

→実行時エラー無く動作するが、最初のSELECT文のみ実行。一方コマンドライン操作では問題なく実行される
