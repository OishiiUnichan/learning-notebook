# 12-2 トリガー

subject: DB
day: 2026年6月11日

---

テーブルに対して更新処理（INSERT、UPDATE、DELETE）が行われたとき、その処理を契機にして他のテーブルにも更新処理を行う仕組み

## 【登録】

［構文］

```sql
DELIMITER //　←仕込むSQL文の区切り文字と区別する
CREATE TRIGGER トリガー名 BEFORE/AFTER（1.タイミング） 対象の操作（2.イベント）
ON テーブル名 FOR EACH ROW(3.決まり文句)
BEGIN
実行したいSQL文;　←；でSQL文の終わりではない
END // ←// でSQL文を終える
DELIMITER;　←通常の区切り文字に戻す
```

［コマンドライン］記述：必要

［phpmyAdmin］記述：不要

→　実行ボタンをクリックすると、DBに接続→実行→切断　処理が走り、デリミタもリセットされる。

［解説］

1. タイミング：トリガーを発生させるタイミング。
    
    胃炎との発生前：BEFORE、発生後：AFTER
    
2. イベント：更新処理（挿入：INSERT、更新：UPDATE、削除：DELETE）
3. 決まり文句：FOR EACH ROW　レコード単位でトリガーを発生させる（記述：必須）

## 【確認】

```sql
SHOW CREATE TRIGGER トリガー名;
```

## 【削除】

```sql
DROP TRIGGER トリガー名
```

### 【作業】登録

```sql
DELIMITER //
CREATE TRIGGER jushotrigger AFTER DELETE 
ON jusho FOR EACH ROW
BEGIN
UPDATE uriage SET charge = 0 WHERE company = OLD.company;
END //
DELIMITER;

```

※UPDATE文では、「OLD」「NEW」キーワードで指定することで、更新されるデータの変更前後の値を取得することができる。

|---|意味|INSERT|UPDATE|DELETE|
|---|---|---|---|---|
|NEW|トリガー実行時の新しい値|〇|〇|✕|
|OLD|トリガー実行時の古い値|✕|〇|〇|

### 【確認】※横長→縦長に表示変更
```SQL
SHOW CREATE TRIGGER jushotrigger;
→
SHOW CREATE TRIGGER jushotrigger \G
```
