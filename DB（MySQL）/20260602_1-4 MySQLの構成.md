## 🔷 一般的なWebシステムの構成（大規模）

※ 複数用意する構成が一般的

**【社外】A. Webサーバー**

- 『Webサイト』
- 利用者 → （入出力） → Webサイト

↑↓ データの送受信

**【社内】B. アプリケーションサーバー**

- 『Webアプリ（Javaなど）』
- → （指示）SQL ↑

↑↓ SQL

**C. DBサーバー**（同一サーバーで実行）

- 『DBMS → → → データベース』
- 管理者 → （指示）SQL → DBMS → データベース
