### 6-4 日付および時間関数

標準SQLで定義されている主な日時関数は、以下の2グループに分類される。

**① 現在の日時を取得する関数**（[表6-4]）

> ※ 引数のカッコ `()` を付けない記述が標準SQLの仕様である。
> 

| 関数 | 取得内容 | 戻り値 |
| --- | --- | --- |
| `CURRENT_DATE` | 現在の「日付」 | DATE型 |
| `CURRENT_TIME` | 現在の「時刻」 | TIME型 |
| `CURRENT_TIMESTAMP` | 現在の「日付と時刻」 | TIMESTAMP型 |

```sql
SELECT CURRENT_DATE, CURRENT_TIME, CURRENT_TIMESTAMP;
```

**② 日時から要素を抽出する関数**（[表6-13]）

`EXTRACT`：日時データから年・月・日・時間などの特定要素を数値として切り出す。

```
書式：EXTRACT(要素 FROM 日時データ)
指定できる主な要素：YEAR・MONTH・DAY・HOUR・MINUTE・SECOND
```

```sql
SELECT EXTRACT(MONTH FROM CURRENT_DATE);
```

**各DBMSの独自拡張（よく使われる日時関数）**

| 処理内容 | MySQL / PostgreSQL | SQL Server | Oracle |
| --- | --- | --- | --- |
| 現在の日時の取得 | `NOW()` [p.160, 161] | `GETDATE()` | `SYSDATE` |
| 日時の加算・減算 | `DATE_ADD()` / `DATE_SUB()` [p.163] | `DATEADD()` | `+` や `-` の演算子 |
| 2つの日時の差分 | `DATEDIFF()` [p.164] | `DATEDIFF()` | `MONTHS_BETWEEN()` |
| 書式の変換（文字列化） | `DATE_FORMAT()` [p.165] / `TO_CHAR()` | `FORMAT()` / `CONVERT()` | `TO_CHAR()` |
