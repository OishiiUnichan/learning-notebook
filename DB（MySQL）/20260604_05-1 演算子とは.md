# 5-1 演算子とは

subject: DB

---

SQL文は、演算の結果を使用することができる。

→オペランド）演算の対象となる値

　演　算　子）式で実行する計算式の種類を指定する記号

### 【演算子の種類】

1. 算術演算子：値を計算する演算子
2. 比較演算子：値を比較する演算子　→　［訂正］p.115 表5-1　誤：=<、正：＜=
3. 論理演算子：複数の条件を組み合わせる演算子

※FROM句のないSELECT文（SELECT句のみのSELECT文）

→MySQLを含め、いくつかのDBMSで利用可能［例］p.327 `SELECT database;`
→用途：演算［５章］の結果や、関数［６章］の仕様確認などに利用

```sql
mysql> SELECT database();
+------------+
| database() |
+------------+
| ghexample  |
+------------+
1 row in set (0.00 sec)
```

> [!NOTE]
> ### SELECT DATABASES();とSHOW DATABASES;の違い  
> **「今自分がどこにいるか（1つの情報）」** を確認するのか、**「全体で何があるか（一覧）」** を確認するのかという大きな違いがある。

#### 🧭 一言でいうと？

- **`SELECT DATABASE();`**
    
    「いま自分がどのデータベースを選択（USE）しているか」を教えてくれるコマンド。
    
    （※ `databases()` ではなく、単数形の `database()` を使うよ！）
    
- **`SHOW DATABASES;`**
    
    「このサーバーの中に、どんなデータベースが存在しているか」の一覧をドバッと見せてくれるコマンド。
    

#### 🔍 詳しい違いと実行結果のイメージ

例えば、学校（サーバー）の中に「1組」「2組」「3組」という教室（データベース）があると想像してみてね。

### 1. SELECT DATABASE();

これは「私が今いるのは何組だっけ？」と確認するイメージ。

もし、事前に `USE class_1;` を実行して1組のデータベースに入っていれば、実行結果はこうなる。

```sql
mysql> SELECT DATABASE();
+------------+
| DATABASE() |
+------------+
| class_1    |
+------------+
1 row in set (0.00 sec)
```

> 💡 **ポイント：** まだ何も選択していない（どこにも `USE` していない）状態だと、結果は `NULL` になる。
> 

### 2. SHOW DATABASES;

こちらは「この学校には何組があるの？」と、全体の見取り図を見るイメージ。

自分がどこにいようが関係なく、アクセス権のあるデータベースが全部ずらっと出てくる。

```sql
mysql> SHOW DATABASES;
+--------------------+
| Database           |
+--------------------+
| information_schema |
| class_1            |
| class_2            |
| class_3            |
| mysql              |
+--------------------+
5 rows in set (0.00 sec)
```

## 🛠 まとめると

| **コマンド** | **返ってくるもの** | **例えるなら** |
| --- | --- | --- |
| **`SELECT DATABASE();`** | **現在の**データベース名（1つだけ） | 「いま、私はどこにいる？」 |
| **`SHOW DATABASES;`** | **すべての**データベース名（一覧） | 「ここに何がある？」 |

作業を始めるときに、まず `SHOW DATABASES;` で中身を確認して、`USE データベース名;` で中に入り、迷子になったら `SELECT DATABASE();` で現在地を確認する……という風に使い分けるのが定番
