# 8-3 内部結合(カラムの数を増やす結合)

※互いのテーブルに共通する、カラムの数を増やす結合になる

［構文①］（主副明確）FROM句のテーブル情報を拡張する形式

```sql
SELECT カラム名リスト FROM テーブル1　←主テーブル
INNER JOIN テーブル2　←副テーブル
ON テーブル1.カラム名1 = テーブル2.カラム名2
```

【確認】

```sql
SELECT * FROM uriage
INNER JOIN jusho
ON uriage.company = jusho.company;
```

![image.png](8-3%20%E5%86%85%E9%83%A8%E7%B5%90%E5%90%88/image.png)

［構文②］（主副不明）FROM句にテーブルを列挙し、WHERE句に結合条件を記述する形式

```sql
SELECT カラム名リスト FROM テーブル1,テーブル2 ←テーブル情報
WHERE テーブル1.カラム名1 = テーブル2.カラム名2　←結合情報
```

確認

```sql
SELECT * FROM uriage,jusho
WHERE uriage.company = jusho.company;
```

![image.png](8-3%20%E5%86%85%E9%83%A8%E7%B5%90%E5%90%88/image%201.png)

［メモ］構文②で結合条件が未指定の場合、自動的に交差結合になる

【確認】

```sql
SELECT * FROM uriage,jusho
-- WHERE uriage.company = jusho.company
;
```
