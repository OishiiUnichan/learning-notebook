### 6-5 列の別名

通常、計算式や関数などを使用した結果の列には、式と同じ名前が使用される。

→ どのようなデータを取り扱っているカラムかわかりにくい場合がある。

**ASキーワード**：カラム名に任意の別名をつける。

```sql
-- [リスト6-30]
SELECT *, ROUND(charge, -4)                  FROM uriage;

-- [リスト6-31]
SELECT *, ROUND(charge, -4) AS uriagegaisan  FROM uriage;
SELECT *, ROUND(charge, -4) AS 売上概算      FROM uriage;
```

### 6-7 関数を利用したデータの絞り込み

関数は戻り値に化けるため、SQL文の中でリテラル値を使用する場所で利用できる。

→ **SELECT句以外にも、WHERE句でのレコードの絞り込みにも利用できる！**

**確認：2017年の売上日のデータを抽出**（[図6-26]）

```sql
-- 演算子①
SELECT * FROM uriage
WHERE salesdate >= '2017-01-01' AND salesdate <= '2017-12-31';

-- 演算子②
SELECT * FROM uriage
WHERE salesdate BETWEEN '2017-01-01' AND '2017-12-31';

-- 独自関数
SELECT * FROM uriage
WHERE YEAR(salesdate) = 2017;

-- 標準SQL
SELECT * FROM uriage
WHERE EXTRACT(YEAR FROM salesdate) = 2017;
```
