### 7-1 重複の除去

SELECT文でWHERE句を指定して特定の列だけ抽出すると、同じ値のレコードが複数抽出される場合がある。

→ `DISTINCT` キーワードを使用すると、重複する値を除いたレコードを抽出できる。

> ※ SELECT文に用意されているキーワード。INSERT・UPDATE・DELETE文との併用は不可！
> 

**確認：売上金額100万円を超える会社を知りたい**

```sql
-- [リスト7-1] DISTINCTキーワード：無
SELECT [ALL] company FROM uriage WHERE charge >= 100000;     -- 16件
-- ※ ALL：規定オプション。通常は記述しない。

-- [リスト7-2] DISTINCTキーワード：有
SELECT DISTINCT company FROM uriage WHERE charge >= 100000;  -- 5件
```

### 7-2 データの並び替え

データは登録した順番に並んでいる。

→ 明示的に並べ替えて抽出したい場合は、`ORDER BY` 句を使用する。

```
書式（WHERE句の後に記述）：
ORDER BY カラム名 [ASC]  -- 昇順（キーワード省略可能）
ORDER BY カラム名 DESC   -- 降順
```

> ⚠️ カラム名は複数指定（カンマで区切って列挙）可能で、**左優先**。
> 
> 
> 順序を指定するキーワードは「直前」のカラム名にのみ有効！
> 

```sql
-- ❌ 意図しない指定の例
ORDER BY カラム名１, カラム名２ DESC
--       ↑昇順        ↑降順

-- ✅ 両方降順にしたい場合
ORDER BY カラム名１ DESC, カラム名２ DESC
```

**確認**

```sql
-- [リスト7-4]
SELECT * FROM uriage ORDER BY charge ASC;   -- 売上金額の昇順

-- [リスト7-5]
SELECT * FROM uriage ORDER BY charge DESC;  -- 売上金額の降順

-- [追加]
SELECT * FROM uriage ORDER BY company DESC, charge ASC;
-- → ① 会社名で降順、（同じ会社に対しては）② 売上金額の昇順
```

### 7-3 特定範囲のデータ抽出

```
書式：
LIMIT 件数               -- 先頭から指定した件数を抽出
LIMIT オフセット, 件数   -- オフセットで指定したレコードから開始して指定した件数を抽出
```

> ※ 先頭のレコードは「0」から数える！
> 
> 
> 実用的には、ORDER BY句と組み合わせて使用（ORDER BY句の後に記述）する。
> 

**確認：売上金額の上位3件を取得**

```sql
-- [リスト7-8]
SELECT * FROM uriage ORDER BY charge DESC LIMIT 3;
-- ※ 省略あるいはASCを指定すれば、下位3件を取得できる。
```

**10件ずつ抽出**（[p.183 コラム]）

> ⚠️ 指定条件に誤りあり
> 

```sql
SELECT * FROM uriage ORDER BY charge DESC LIMIT     10;
SELECT * FROM uriage ORDER BY charge DESC LIMIT 10, 10;
SELECT * FROM uriage ORDER BY charge DESC LIMIT 20, 10;
```

### 7-4 データの集約とグループ化

SELECT文では、レコードをグループ化したり、集計したりすることができる。

- ① 集約関数
- ② GROUP BY句

**① 集約関数**

対象のレコードをグループ化し、1つの結果として出力する関数。

| 関数 | 機能 |
| --- | --- |
| `SUM()` | 合計 |
| `AVG()` | 平均 |
| `COUNT()` | 個数 |
| `MAX()` | 最大 |
| `MIN()` | 最小 |

（[p.185 表7-1]）

**通常の関数との違い**

1. 引数はカラム名を指定する（`COUNT` 関数は例外で  なども指定可能）
2. 関数の特性上、**WHERE句には記述できない！** [後述参照]
3. 集計対象のカラム以外を SELECT文で取り出すカラム名に含めることはできない

```sql
-- ① SELECT COUNT(*), SUM(charge) FROM uriage;       → 1レコードで出力（件数同じ）
-- ② SELECT company, SUM(charge) FROM uriage;        → 出力レコード数が異なる（エラー）
-- ③ SELECT company, salesdate, YEAR(salesdate) FROM uriage;  → 件数同じ
```

> 📌 [メモ] SQL文②について、[p.186] では「実行こそできます」と記述されているが、
> 
> 
> 現状では実行できない（phpMyAdminでもコマンドライン操作 [Chapter 13] でも）。
> 
> 少なくとも現在のバージョンでは、他のDBMSと同様、実行できない。
> 

**② GROUP BY句**

特定の項目でグループ化する（まとめる）。

WHERE句の後、ORDER BY句の前に記述する。

```
書式：GROUP BY カラム名リスト（カンマで区切って列挙）
```

**確認**

```sql
-- [図7-18][リスト7-12]
SELECT company, SUM(charge) FROM uriage GROUP BY company;

-- [リスト7-13]
SELECT salesdate, SUM(charge) FROM uriage GROUP BY salesdate;
```

**集約後のデータを絞り込むには？**

| 句 | タイミング | 使用可否 |
| --- | --- | --- |
| `WHERE` 句 | 集約関数を実行する「前」の条件 | ❌ |
| `HAVING` 句 | 集約関数を実行した「後」の条件 | ✅ |

**SELECT文の実行順序**

| 順序 | 句 | 内容 |
| --- | --- | --- |
| 1 | FROM句 | テーブル指定 |
| 2 | WHERE句 | 条件指定 ← ❌ 集約関数は使用不可 |
| 3 | GROUP BY句 | グループ化 |
| — | （集約関数の実行） |  |
| 4 | HAVING句 | 集計後の絞り込み ← ✅ |
| 5 | SELECT句 | 検索 |
| 6 | ORDER BY句 | 並べ替え |

**確認**

```sql
-- [図7-22]
SELECT company, SUM(charge) AS 合計金額
FROM uriage
GROUP BY company
HAVING 合計金額 >= 200000;
```
